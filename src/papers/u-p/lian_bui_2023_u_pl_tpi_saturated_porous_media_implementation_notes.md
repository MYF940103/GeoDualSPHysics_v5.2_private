## Source paper

Yanjian Lian, Ha H. Bui, Giang D. Nguyen, and Asadul Haque, **"An effective and stabilised (u-pl) SPH framework for large deformation and failure analysis of saturated porous media"**, Computer Methods in Applied Mechanics and Engineering, 2023.

## 1. Core idea

This paper develops an efficient and stabilized single-layer SPH framework for saturated porous media using the **u-pl formulation**, where:

- `u`: solid skeleton displacement/motion;
- `p_l`: pore-water pressure.

Key contributions:

- fully coupled flow-deformation SPH;
- three-point integration (TPI) for pore-water pressure;
- reduced water-bulk-modulus time-step restriction;
- stabilization for negative excess pore pressure under dilative plasticity;
- validation using consolidation, footing, granular collapse, and retrogressive failure.

## 2. Assumptions

```text
saturated medium = solid skeleton + connected water-filled voids
solid grains and water are incompressible
isothermal process
no mass exchange
Terzaghi effective stress concept applies
```

## 4. Coupled equations

Momentum in effective-stress form:

```math
\rho\frac{dv_s}{dt}
=
\nabla\cdot\sigma'
-
\nabla p_l
+
\rho g
```

The pore-pressure equation contains:

```text
skeleton volumetric strain rate
Darcy diffusion / pressure dissipation
porosity change
permeability change
```

Representative form:

```math
\frac{dp_l}{dt}
=
K_l
[
\text{skeleton volumetric strain rate}
+
\text{Darcy diffusion}
+
\text{porosity terms}
]
```

## 5. Three-point integration (TPI)

TPI modifies the pore-pressure time integration so that the stable time step is not directly limited by the water bulk modulus in the same way as a fully explicit update.

Implementation requirements:

```text
previous pressure state
current pressure state
possibly predicted/intermediate pressure state
pressure-rate history
modified pressure update routine
```

This is more complex than a simple `p += dpdt*dt`.

## 6. Stabilization for negative pore pressure

The paper introduces a stabilization procedure for negative excess pore pressure generated by plastic dilation.

Implementation idea:

```text
limit or slow the rate of negative pore-pressure development when plastic dilation occurs
```

The paper uses a stabilization parameter around:

```text
beta = 0.04
```

This should only be active when plastic deformation is considered.

## 7. Required SPH operators

```text
corrected gradient of velocity/displacement
divergence of skeleton velocity
pore-pressure gradient
pore-pressure diffusion / Laplacian
porosity update
permeability update
```

## 9. Suggested CPU-first phases

### Phase 0: feasibility map

Check if the code already has pore pressure, porosity, permeability, and pressure output.

### Phase 1: explicit u-pl prototype

Add passive `p_l`, then a simple explicit `dp_l/dt` update.

### Phase 2: Terzaghi verification

Validate pore-pressure build-up/dissipation before large deformation.

### Phase 3: TPI

Add history storage and TPI update.

### Phase 4: negative pressure stabilization

Add stabilization for dilative plasticity cases.

### Phase 5: GPU port

Only after CPU verification.

## 10. Numerical stability issues

1. Explicit pressure update is strongly time-step restricted by `K_l`.
2. TPI requires correct history management.
3. Negative pore pressure during dilation can be unstable.
4. Global damping can smooth pressure but may affect mechanics.
5. Porosity and permeability must be bounded.
6. Pressure sign convention must be consistent with effective stress.
7. Boundary drainage/undrained conditions are essential.
