# TPI 孔压差异：同一离散 PPE 诊断

2026-09-07。本轮第一道门槛已完成：固定几何、常 n/k、非零指定源项，独立收敛 PPE 参考与真实 CPU 压力更新对比。**证据检查通过，不等于 TPI 精度验收通过。当前不能把 TPI 加入“等精度有效加速”比较。** 本文不将有限 Kw 的 PR 当作真值。

生产求解器源码本轮尚未修改；新增工具、报告和图位于本目录。PR 的 NoPen/角点边界还在下一道门槛，未启动新的整场滑坡或 Terzaghi，未覆盖历史结果。

## 1. 可以分清哪些来源

| 来源 | 本轮实际证据 | 可以得出的结论 |
|---|---|---|
| PR 与 TPI 的物理差异 | 参考完全来自当前 TPI 空间离散 PPE，不使用有限 Kw PR | 排除了“两个物理方程不同”对本轮误差的解释；不能据此量化之前 PR/TPI 孔压差中每项的占比 |
| 初始压力不相容 | 常源冷启动，42 个未知压力从零开始，PPE 参考非零 | 出现随迭代衰减的启动误差；零压力不是非零源 PPE 的相容初值 |
| 旧时间层不相容 | 当前压力为 PPE 解，只扰动 previous | 仍会产生暂态误差；只初始化当前压力不够 |
| 简单历史槽/预测校正接线错误 | 实际 Begin、压力预测、校正、previous 轮换、dt 历史在每步检查；保存帧再独立复算 | 本轮测试范围内没有发现这类接线错误；不包括运动、重排、复杂墙或全部机械重启 |
| 单次迭代与时间层 | 相容两层启动，改用线性/正弦源，仍明显滞后于同一 PPE | 不是仅靠相容初始化或消除 float 累计误差就能消失的误差 |
| 固定底墙 | 真实墙插值已消元到 W，并保留自耦合；也比较无墙截断图 | 固定底墙并非上述滞后的唯一来源；未据此宣称动态不透水或角点边界通过 |

## 2. 参考、实验与证据质量

四个矩阵：二维 Wendland/Cubic，各含无墙截断图与单底墙版本。每例 49 个土粒子，其中 42 个压力未知量、7 个顶部零压参考；底墙版本再加 7 个固定墙粒子。位置、logJ、n/k 冻结；n≈0.3，k≈0.001 m/s；源幅值 0.01 s⁻¹，空间形状 `1+0.2*cos(2*x)+0.1*z`。材料值实际从生产 float 输入读取，精确值和坐标见矩阵 JSON。

非零散度作为**外加压力方程源**，推进前显式冻结 logJ，故这是压力离散试验，不是“土体受压但体积不变”的完整物理算例。无墙侧边是截断邻接图，不冒充完整自由面；本轮也没有验收全耦合时间步上限。

每个构型 29 组：常源 α=0/0.5/1、三种历史启动；冷启动附加两档步数；线性/正弦源 α=0/0.5/1、40/80/160 步，均使用相容初始两层。物理标称窗 T=1 ms。Release 116 组和 Debug 116 组全部执行完成；每组保存 21 个时刻，每个构建 2436 帧。未保存中间步的接线由 C++ 全步最大值检查覆盖，不宣称保存了全部中间步原数组。

生产黑箱提取 `p_target=W*p_ex+b`。真实底墙 ghost 已消元进入 W；保留原始行分母以及 W 自耦合，不能再按消元后的对角重新归一化。参考求解 `(I-W)*q=b`：C++ 主元消去用于初始化，NumPy 独立密集解用于分析。

| 检查 | 最终结果 |
|---|---:|
| 独立 PPE 参考最大后向归一化残差 | 3.33e-16（门槛 1e-11） |
| 保存帧实际更新与提取矩阵递推式的最大缩放无穷范数差 | 2.89e-15 |
| 冻结位置、材料和排水值、每步历史接线 | 两个构建各 116 组通过 |
| Debug/Release 矩阵与 trace | 4 对矩阵、116 对 trace 字节相同；660436 对数值最大差 0 |

这里 `M*p-b` 是**原始分母行归一化后的压力方程残差**，量纲 Pa；表中的后向归一化残差和缩放映射差则均为无量纲。它们不是未归一化质量残差，也不是墙面 Darcy 通量。报告区分参考解自身的后向误差、TPI 的 PPE 残差、TPI 相对参考的孔压误差。

原始证据：[Release 执行清单](ppe_release_r1/execution.json)、[Debug 执行清单](ppe_debug_r1/execution.json)、[最终分析](ppe_final_r2_分析.json)、[Debug 独立分析](ppe_debug_analysis_r1_分析.json)。各清单记录输入和输出哈希；运行拒绝覆盖已有标签。

另一独立审计逐一检查 metadata、全部 2436 对保存帧、14616 对数组、全部 allstep 摘要及哈希链：[Debug/Release 审计](tpi_debug_release_audit_r1.json)。433 个证据和编译输入文件审计前后哈希一致。默认 CPU Debug 增量构建也已通过，0 警告、0 错误：[构建日志](cpu_debug_followup_r1.log)。fixture 链接中的既有第三方 LNK4099 与生产增量构建结果分开记录，不能将两者混作“所有链接无警告”。

## 4. 时变源下仍有实质性的算法滞后

固定底墙 Wendland、α=0.5、PPE 相容当前及旧层、T=1 ms：

| 源项 | 步数 / dt (μs) | 整个保存时间窗相对整步 PPE 的最大 RMS 误差 (Pa) |
|---|---:|---:|
| 线性 `1+t/T` | 40 / 25 | 42942.67 |
| 同上 | 80 / 12.5 | 22919.21 |
| 同上 | 160 / 6.25 | 11507.13 |
| 正弦 `1+0.5*sin(2πt/T)` | 40 / 25 | 63094.60 |
| 同上 | 80 / 12.5 | 48721.59 |
| 同上 | 160 / 6.25 | 31323.33 |

线性源两次误差细化比对应 log₂ 比值 0.906、0.994，表现为此冻结试验上的近一阶滞后；不能据三档 dt 宣称整个耦合算法的一般阶数。正弦源终点误差受相位影响、不单调，因此采用完整保存窗的最大误差和历史图，不挑终点作精度结论。

80 步线性源的最终 RMS 误差：整步参考 22919.21 Pa，中点参考仍有 22176.80 Pa。**滞后并非仅把横轴挪半个时间步就能消除**，还有单次压力迭代未追上变化的 PPE 解。

## 5. 真实递推式与代码定位

固定几何下实际执行的是：

```text
M = I - W
同一 PPE：M*q(t) = b(t)
实际校正：p_(n+1) = W*((1+alpha)*p_n - alpha*p_(n-1)) + b_(n+1/2)
压力预测：p_predictor = p_n + 0.5*(p_n-p_(n-1))
接受后：previous = p_n
```

对应当前生产代码（本轮未改）：[BeginUplStep](../../../src/source/JSphCpuUpl.cpp:62)、[历史外推](../../../src/source/JSphCpuUpl.cpp:155)、[目标压力](../../../src/source/JSphCpuUpl.cpp:247)、[预测与历史轮换](../../../src/source/JSphCpuUpl.cpp:303)、[Symplectic 阶段顺序](../../../src/source/JSphCpuSingle.cpp:838)。

把精确整步 PPE 历史代入该递推式，左减右的局部缺陷为
`dt*[0.5*I+(0.5-alpha)*W]*q'(t_n)+O(dt²)`。α=0.5 时仍保留一阶项。

常源误差谱满足 `lambda²-(1+alpha)*mu*lambda+alpha*mu=0`，mu 是 W 的特征值。所有本轮图均检查完整特征根；这些小图上的衰减不能推广到任意粒子几何。特别是 α=1 不等于实际隐式 PPE 求解，不能称无条件稳定；非对称 W 还需暂态放大检查。

原始依据为本地 [Lian 2023 u-pl.md](<../../../src/papers/u-pw/Lian 2023 u-pl.md>) 式（29）、（30）、（35）、（38）—（42）。当前生产空间算子也没有完整采用论文式（33）的误差修正，因此本轮名称是“同一生产离散 PPE 诊断”，不是“完整复现论文算法”。

## 6. 对后续开发的直接影响

1. 保留 TPI 当前的实验性质；不再把其较短墙钟时间直接计入等精度有效加速。
2. 不在本轮诊断中偷偷修改 α、松弛次数、方程或压力时间层。若下一步修正 TPI，应分别验收初始化、同阶段源、PPE 迭代收敛与成本，避免组合改动掩盖原因。
3. 按用户指定顺序先转入 PR 边界。NoPen 是压力率之后的最终速度/位移覆盖，不是现有 Ace 的一部分；角点需两个独立面约束，不能只删除当前拒绝。详见 [PR 边界依据](03_PR边界开发依据.md)。
4. 保留真实滑坡的应力扩散、材料和接触参数作为对照因素，不能通过禁用这些设置绕过新模式限制。实际基线及危险旧 BAT 见 [研究算例基线](02_研究算例基线.md)。
5. 完成边界、明显变形及短跑时长预估后才进入新整场滑坡；完成滑坡后才进入新完整 Terzaghi。历史 5 m 滑坡已有 21 个 RhopOut 剔除，不能把历史结果无条件当无缺陷真值。

最终两幅 PNG 已实际打开检查：文字、单位、图例和曲线可读；采用同一时间窗，并分别显示中点参考和整步参考。早期 r1 构建/图形记录保留供追溯，最终引用 r2，不覆盖旧文件。
