# u-pl 测试记录归档

本目录保留已经放弃的 u-pl 开发与验收历史，不是仍受支持的测试工程，也不表示完整固结或 TPI 验收通过。最终回退状态以主代理的回退记录为准。

`upl_test_records_20260908_r1.zip` 按 `precision / stage_ab / time_accuracy / cde / followup / fix` 分组保存原始记录、图表、日志、配置和测试方法。JSON、日志和 Markdown 内的历史路径、哈希、结论均保留原文；旧相对链接可能不再能直接打开，可依据归档清单定位 ZIP 内的文件。

大型数值 JSON/CSV 也压缩保留，避免仅凭扩展名或体积丢掉证据；没有把它们散放为新的活动测试目录。二进制、调试中间产物、原始 BI4/VTK 粒子输出和重复整套生产源码快照不收入测试记录 ZIP。回退前生产源码由本目录另一个独立归档保存。

`upl_test_records_20260908_r1_manifest.json` 记录全部纳入盘点文件的原位置、字节数、SHA256，以及“保留记录 / 原始或重复产物”分类。所有 ZIP 条目逐项解压读取核对散列，归档前后再次核对全部源文件及数量。顶层的重要结论文档和 PNG 是逐字节副本，不改写历史结论。

归档脚本 `archive_test_records.ps1` 已收入 `rollback_verification_methods.zip`，它拒绝覆盖已有标签、目录联接和符号链接，且自身没有删除功能。原六个测试目录在回退验收完成后已按精确白名单删除，实际结果见 `history_cleanup_r1.json`；没有删除记录 ZIP 或原编号算例。

原有 `01` 至 `06` 编号算例、历史水土耦合数据、文献及 `validation/tpi_cleanup_release_20260906` 的 u-pw 回归记录不在清理范围内。
