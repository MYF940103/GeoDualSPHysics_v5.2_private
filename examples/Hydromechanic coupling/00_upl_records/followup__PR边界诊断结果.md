# PR 边界前置诊断：两类误差不能混为一谈

2026-09-07。状态：完成当前生产 CPU PR 的制造场诊断，**尚未修复生产边界，也没有放开 NoPen/角点限制**。本轮 TPI 诊断后发现，下一批 PR 修改须同时评估墙外推与动态/扩散离散一致性，不能只改开关守卫。

## 1. 实际执行了什么

[pr_boundary_harness.cpp](pr_boundary_harness.cpp) 链接未改动的真实 CPU 对象，直接调用 `CorrectUplHydraulicWalls()`、`InteractionUplRate()`、`PreparePoreDynamicAcceleration()`。Debug 与 Release 各完成 54 组，原始 JSON 逐字节相同：

- 两种核：Wendland、Cubic。
- 三种构型：无墙截断图、单底墙 NoSlip、单底墙 FreeSlip。
- 七类场：静水、常水力势、均匀法向/切向加速度的动态相消挑战、切向线性流、非零二次势响应、仿射加速度/二次势相消。
- 42 组默认正则；另对二次响应和仿射相消作 12 组 **仅 fixture 的 Eta2=0 消融**。未将该参数改入生产源码或任何研究算例。

每例 289 个土粒子，底墙例另加 17 个墙粒子；dp=0.05 m、h≈0.09 m，n≈0.3、k≈0.001 m/s、Kw=2e8 Pa，g_z=-8 m/s²（常 H 独立控制用 g=0）。全部是冻结位置/n/k 的瞬时率检查，没有时间推进、接触力轨迹、体积演化或守恒面通量测量。原始精确参数及粒子坐标均在 JSON。

每组分别读取实际 `full`、`diffusion_only`、`dynamic_only` 三次生产调用的孔压率，并验证分量可加性及冻结状态。[独立分析脚本](analyze_pr_boundary.py) 逐组复算粒子统计、误差和 Debug/Release 一致性；不是另写一个理想 SPH 算子代替生产算子。

原始文件：[Debug](pr_boundary_DebugCPU_r1.json)、[Release](pr_boundary_ReleaseCPU_r1.json)。最终分析：[pr_final_r2_PR分析.json](pr_final_r2_PR分析.json)。每个构建 15606 条粒子记录，每条含完整三分量率、压力、位置和区域标记。

[运行后编译链审计](pr_boundary_execution_audit_r1.json) 核对 195 个输入文件，源码/对象/exe/DLL 与构建清单匹配。原始运行退出码 0 来自当时工具观察，未保存为独立 stdout/退出码日志，报告明确区分这两种证据；没有事后补写原始运行时间或耗时。

## 2. 严格区分内部、墙和侧端点

完整支撑内域有 81 个粒子；C++ 原始 `near_bottom_core` 有 36 个粒子，仅排除一层侧边核支撑。**墙 ghost 自身还会再次插值，因此一层排除不足以消除侧端点影响。** 最终分析新增 `strict_two_hop_bottom`：

```text
abs(x) <= 8*dp - 2*support_radius
z < support_radius
```

当前小图只剩 x=0 中心列的 4 个近墙粒子；原始 36 粒子统计保留，最终墙归因使用严格 4 粒子区。图也用 x=0，且避开顶部截断。

这一点有实际影响：切向线性势在全截断图端点可产生很大局部率，不能把它都算成底墙泄漏；严格中心列的残差只有约 3.67e-8 / 6.55e-8 Pa/s（Wendland/Cubic）。这支持该线性制造场未被底墙错误封死，但不是非均匀变 k 的一般切向流验收。

## 3. 静水通过，不意味着动态相消通过

对底墙 NoSlip，静水/常 H 全域最大绝对孔压率不超过 6.55e-8 Pa/s，完整支撑内域为零，属于本测试舍入预算内。

更有判别力的场是：

```text
a_s = (0, 0, 2*z)
H = p - rho_w*g·x = 10000 - 1000*z^2
grad(H) + rho_w*a_s = 0
div(v_s) = 0 （当前瞬时值）
```

连续 Darcy 相对通量处处为零，两项解析孔压率各约 ±166666.67 Pa/s，相加应为零。墙面 z=0 上的法向加速度和 H 法向导数也为零；这比“均匀非零法向加速度却要求固定墙”更适合检验已有静止平墙处理。它仍只是一个瞬时制造场，不是一段已满足力学运动方程的完整轨迹。

| 检查（最大绝对合成孔压率，Pa/s） | Wendland | Cubic |
|---|---:|---:|
| 默认 Eta2，完整支撑内域 | 2298.45 | 2030.62 |
| 仅测试 Eta2=0，完整支撑内域 | 0.2484 | 0.2055 |
| 默认 Eta2，严格两跳近墙中心 | 43693.42 | 47287.06 |
| 仅测试 Eta2=0，严格两跳近墙中心 | 47706.89 | 50997.59 |

默认内域误差约为解析动态项幅值的 1.38% / 1.22%。去 Eta2 后，内域落入包含实际 float 加速度写回的预算（约 44.24 Pa/s），但近墙误差没有消失，反而略大。这里不能把 0.248 Pa/s 宣称为 double 精度误差；它包含明确记录的 float 加速度写回。

## 4. 如何定位来源

### 内部：两个离散式的正则并不匹配

[JSphCpuUpl.cpp:232](../../../src/source/JSphCpuUpl.cpp:232) 的动态项使用校正差分散度；随后扩散系数包含 `rr2+Eta2`。在当前均匀完整支撑图上，仿射散度保持线性精度，而二次势的扩散响应被正则削弱。仅测试去正则后内域相消恢复至写回预算，支持这一归因。

非零二次势控制也有真实响应：默认 Wendland/Cubic 内域平均孔压率约 164368.47 / 164636.25 Pa/s，解析为 166666.67 Pa/s。因此不是“两个算子全为零”的假通过。

这**不证明应直接在生产里去掉 Eta2**，也不证明必须替换整个空间算子。去掉正则会改变近距离配对系数、显式稳定性和杂乱粒子响应；均匀网格消融不能推广到大变形或非均匀粒子云。应先做新 PR 局部一致性修复的推导、扰动/变形图及 dt/分辨率检查，保留旧 u-pw/AB 的系数。

### 近墙：零阶压力和加速度外推不能同时重构该场

底墙核心压力 ghost 相对解析延拓的误差约 2.806 / 3.216 Pa，加速度 ghost 误差约 0.04877 / 0.05452 m/s²。当前压力只作零阶 H 插值，加速度也采用零阶插值再反射；对二次 H、仿射 a 不能给出同时相容的延拓。对应 [压力墙处理](../../../src/source/JSphCpuUpl.cpp:76)、[加速度墙处理](../../../src/source/JSphCpu.cpp:1632)。

这在严格排除侧端点的中心列仍留下上述大残差。只去掉 Eta2、只反射平均法向或只取消平行墙守卫都不构成修复。

名义墙 z=0，而 `BoundNormal=float(dp)` 带来约 3.7e-10 m 的几何偏移；原始 JSON 中的 ghost “float budget”不是包含该几何误差的综合边界精度门槛。报告不拿它对一般非零梯度场证明严格机器精度。该微小几何偏移不足以解释数 Pa 的 ghost 差与数万 Pa/s 的率残差。

## 5. 尚未完成、不能提前宣称通过的项目

- 未测实际数值面通量或封闭域总质量余额；本轮残差是 Pa/s，不是 m/s 通量，也不是 Pa 压力误差。
- 没有时间步/粒子分辨率细化下的完整 PR 边界轨迹。
- NoPen、非平行墙、角点、实际排水时序与 Shepard/重启边界一致性尚未实现本轮修复。
- 没有明显变形下的生产 n/k 验收，也没有新的滑坡/完整 Terzaghi 结果或有效效率结论。
- 均匀法向加速度，以及 NoSlip 墙的均匀切向加速度，仅作为制造边界挑战，不是严格固定墙力学轨迹；不能拿它们的误差单独证明原壁面力学错误。

## 6. 下一批生产修改范围需先明确

本轮证据要求在原先“补边界”的计划内增加一个明确的数值前置步骤：**先在新 u-pl PR 分支局部处理墙重构与动态/扩散项一致性，再接 NoPen 和多面墙。** 这会触及新 PR 的空间离散，不只是添加配置选项；不预设重写整个算子，也不把 fixture 的 Eta2=0 直接当成方案。

预计涉及 `JSphCpuUpl.cpp`、`JSphCpu.h`，然后是 `JSphCpuSingle.cpp` 的阶段衔接和 `JSph.cpp` 的条件守卫。原 u-pw、旧 AB、TPI 现有诊断参考暂不动；共享机械 NoPen 表达式不作静默替换。完成这一步后再按 [03_PR边界开发依据.md](03_PR边界开发依据.md) 的多面几何、实际接触加速度/位移、DDT3 和重启合同验收。

实际 5 m 研究例的显式左/底面几何已存在，无需用户重新提供。但 failure 使用预应力 PART 保存的机械法向，其中 559 个零向量不能悄悄换成新生成法向；4 个底墙右端点的斜向量也不能误判为双墙角点。原 failure 的 NoPen、corrector、DDT3 必须逐项适配或显式列为对照因素。

这一数值修改范围确认前，保留当前生产实现与 guards，不启动会在配置处失败或改变物理对照条件的昂贵整场计算。之后仍严格保持：PR 边界 → 明显变形 n/k → 新滑坡 → 滑坡完成后再新跑完整 Terzaghi；旧结果不覆盖。
