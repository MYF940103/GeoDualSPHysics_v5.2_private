## 已修复什么

新 PR 的孔压算子采用配对水头—骨架加速度差，配合非负矩校正及固定墙/封闭移动顶部的镜像。真实墙粒子的机械孔压另外重构，机械 Vel0/mDBC 规则保持原样。PR 水力行并行时不改变单行求和顺序，异常在线程外有序报告。

外载只放行二维 X 周期、固定横截面的 PR TopVertical。载荷按真实混合惯性质量施加，并记录力、半步取样时刻及累计冲量。排水和加载使用正确的 PR 子阶段时钟。

初轮长跑还发现瞬时横向速度阈值误报：保存状态中实际横移仅数纳米，远低于已有 5 μm 几何容差。现改为全部正常土粒子的 ID 对齐累计横移检查，不投影速度；保留有限性、顶部 owner、共面、穿面和闭合期加速度保护。拟合残差另存真实拟合时间，排水后旧残差不再冒充当前诊断。

CPU Debug 和 Release 均由原 VS 方案完整 Rebuild 通过。Debug 关闭已弃用的最小重编译设置；仍有旧第三方库缺少 PDB 的 LNK4099 警告。没有修改 CUDA 内核或重建 GPU，可执行文件不能视作同版 CPU/GPU 配对。

## 仍不能给出的结论

1. **不能认定新 u-pl 已可用于 retrogressive landslide。** NoPen、非平行墙/墙角、任意自由面和 TopVertical 重启仍受限。
2. **不能认定严格全局水量守恒。** 行局部矩校正不保证相邻行权重对称；压力矩阵单列脉冲诊断的最大体积加权相对不平衡为 1.656%，不是完整固结的累计水量误差。
3. **不能仅凭 n/J 公式验证真实变形。** 冻结仿射场中，梯度修正改善顶部，但底层散度仍约为指定值的 0.686；应继续检查网格、边界和几何/状态体积。完整 OFF 顶层中心高度差也达到约 38.6 μm，不是严格一维对称状态。
4. **不能给 TPI 一个已验收的时间步放大倍数。** 同 PPE 的时变源测试仍存在跟踪误差；α=1 并非总优于 α=.5。现 TPI 不支持本例封闭外载阶段，不能提前排水绕过。
5. **当前并发墙钟不代表公平效率。** [30 s CPU 只读采样](cpu_scheduling_r1_结论.md)中每组平均仅约 0.54 个逻辑核，具体原因未定；未修改进程/系统设置。新模型局部矩校正有实际成本，最终仍需同机器负载、同误差门槛下的独立重复计时。
