# 公共三轮 TPI 的适用范围和验证结果

2026-11-23。公共 CPU 和单 GPU 程序读取同一个 `HydroMechModel`。水土耦合开启时，缺省值 0 使用 u-pw，1 使用有限水体积模量的显式 u-pl，2 使用零储水的三轮 TPI。模型 2 使用线性外推系数 0.5 和 β=0，水力步长系数 `HydroMechTpiR` 缺省为 1。每轮使用施加相应边界后的端点压力更新力和水力残差。公共实现目前支持从头运行的 C02 周期弹性柱和 C04 均布围压球体，要求固定步长、Wendland 核和恒定渗透率。

## 发布后的验收顺序

1. C08 先检查两端的变渗透率压力更新、闭墙预载、撤墙时土粒历史继承、自由面切换及式（47）负压处理，再在已发生大变形的土体上比较孔压、滑移、前缘和粒子团聚。正式案例的精度评价需要独立于启动短窗。
2. 回到公共版本，在相同的渗透率、物理时段、硬件、线程数或显卡、输出频率和预先声明的孔压及沉降误差下，对比模型 1 与模型 2 的计算循环耗时和包括输出的总用时。CPU 与 GPU 分开报告。保留模型 0、1 各自对原程序的逐字段回归和两端直接数值比较。跨机、跨精度、跨输出密度的数据单列。
3. 高渗 C02 采用同材料同网格的 `k=10⁻³ m/s`。先量出各阶段的显式水力步长，再比较 R=1 与覆盖所选目标步长所需的 R。公共 XML 只增加一个可选水力放大系数，缺省 1。检查 R 生效的限值、旧输入与显式 R=1 的等价性，以及错误输入的拒绝行为。机械、黏性和变渗透率梯度限制各自保留。按真实精度和总耗时确定可推荐区间。[步长公式及现有样本](upl_tpi_r_selection_r1.md)
4. 上述验证结束后统一维护中的正式 XML、BAT 和对应程序。分别检查各算例解析后的物理设置、事件时间、保存间隔和规定的原生回归；历史输出和服务器包与原程序配套保存。按依赖和可再生记录清理派生文件。

## 公共水力步长放大系数

在 `execution/special/hydromechanics` 中选择 `HydroMechModel=2` 后，可写 `<HydroMechTpiR value="1" />`。省略时取 1。仅接受不小于 1 的有限数，其他模型若显式填写该项，程序在初始化时报告配置错误。对 R 大于 1 的计算，每个原生 PART 均以 double 保存实际采用的 R。固定步长若超过允许值，原求解器会报出限制及步号。

CPU 和 GPU 均先将显式水力扩散步长上限乘以 R，再与力学、波速与黏性限制取小值。变渗透率实现另保留渗透系数梯度限制，启用 HG 的通道仍保留其时间尺度检查。R 的数值不会把 XML 的 `DtFixed` 自动乘大。要评估 10 µs，应把真实积分步长设为 10 µs，并独立核对孔压、沉降及应力误差。

高渗透率 C02 初始状态（k=10⁻³ m/s，PoreDtSafety=1）在两个实际 Release 程序中给出相同的水力上限 4.76603145 µs。10 µs、R=1 在第 0 步触发水力限制；R=2.25 通过该步。另用 1 ms、R=512 单独验证保护：有 HG 时触发原 HG 限制，隔离去掉 HG 后触发 100.542521 µs 的波速与黏性上限。512 仅用于这项拒绝测试。[CPU 实测](../02_TerzaghiConsolidation_q0_PR/tests/logs/tpi_r_step_bounds_cpu_r1.check.json) · [GPU 实测](../02_TerzaghiConsolidation_q0_PR/tests/logs/tpi_r_step_bounds_gpu_r1.check.json)

R 改动后的 CPU/GPU 各自与上个公共版本比较，模型 0 的四帧各 15 个原生场、模型 1 的四帧各 22 个场全部逐位相同。模型 2 的省略和显式 R=1 均与旧公共输出比对全部 22 个场、原生时钟、带符号步长差和压力历史；在球体各核五帧，柱体 CPU 核三帧、GPU 核 106 帧。模式 0/1 保持旧文件的输出模式，R=1 保持旧模型 2 文件布局。[CPU 回归](../02_TerzaghiConsolidation_q0_PR/tests/logs/tpi_r_public_compat_cpu_r1.check.json) · [GPU 回归](../02_TerzaghiConsolidation_q0_PR/tests/logs/tpi_r_public_compat_gpu_r1.check.json)

## PART 中的压力历史

冷启动令上一时刻压力等于初始孔压。此后每一帧的 `TpiPressureHistory` 子项保存计算实际使用的上一整步源孔压、原始材料 ID、源时钟及步长。C02 在第 1,000 步末仍是闭态，10 个受控表面点的孔压约 10,026.44 Pa。第 1,001 步开排水，这 10 个点的源孔压为零，990 个内部土粒仍与上一步保存的压力逐位相等。GPU 窗内 105 个非初始帧共 105,000 个历史压力与各自积分步的原始运算记录逐位相等。公共模型 2 的通用 PART 重启入口尚未开放。

## C08 大变形与式（47）

从同一 ψ=0° 原生预载出发，私有 GPU 程序以 5 µs 完成 1 ms 闭墙适应和撤墙后 0.30 s。有限 Kw、TPI β=0 与 β=0.04 的前缘依次为 4.12272、4.12237 和 4.11521 m，论文图 14 的数字化值为 4.06780 m。β=0.04 将全窗最负采样孔压从 −27.35 提高至 −7.39 kPa，末态最近邻小于 0.7 dp 的土粒从 51 降到 37。相邻 0.01 s 采样的全体孔压二阶差分 RMS 从 587.94 升到 614.67 Pa。团聚及整体波动仍限制适用范围，β 保留在实验程序。其余剪胀角及 3 s 全过程仍待独立验证。[逐材料数据、论文轮廓和图](../08_LianSaturatedColumnCollapse_u_pl/tests/notes/c08_m0_coupled_baseline_gpu_r1.md)

C08 撤墙涉及塑性历史、自由渗流和粒子退役。实际有限 Kw 预载末态有 4,831 个非自由表面粒子的零储水行修正足以改变 float32 孔压，最大 1.246 Pa。C08 的动力比较应先建立同模型 β=0 预载或经过验证的相容初始化，撤墙时按幸存土粒 ID 继承压力历史，再在同一基线上检验式（47）。[预载相容性数据](../08_LianSaturatedColumnCollapse_u_pl/tests/notes/c08_pre_m0_r1.md)
