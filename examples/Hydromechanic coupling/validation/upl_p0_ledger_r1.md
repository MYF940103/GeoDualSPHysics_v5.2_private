# 动态渗流首版变量闭合

2026-11-01。开发起点为 `2b3e40d`；独立分支 `upl-dev`。本阶段先确定新模式变量与算子试验，不改变旧 u-pw 的生产方程或正式输入。

## 模式选择

按用户要求，拟采用一个布尔入口 `HydroMechDynamicSeepage`，默认 `false`。关闭时完整保留现有有限 Kw、固定孔隙率的 u-pw PR 路径；开启时统一选择动态孔隙率及含骨架加速度的低频 Darcy 分支。k 首版仍取时间不变的各向同性水力传导系数，TPI、k(n)和负压经验处理不捆绑。

该入口在 P2/P3 成套接线时才加入 XML 解析，当前尚未实现，不应写进正式 XML。不会以一个已能开启但静默缺少部分物理的空开关冒充新模式。新旧模式仅分别 fresh start，尚不支持跨模式 PART 迁移。

## 旧变量与新变量映射

| 量 | 当前定义和用法 | 新模式首版闭合 |
| --- | --- | --- |
| `MassFluid` | 固定 SPH 计算质量 | 仅用于定义初始积分体积，不作为随渗流交换后的固定混合质量 |
| `RhopZero` | 初始混合体密度输入 | `rho_t0`，与 n0、参考水密度确定固粒本征密度 |
| `Velrhop.w` | 骨架随动计算密度；m/rho 又用于邻居权重 | 不能直接认作固粒密度或新的物理混合密度；新模式体积和惯性明确分开 |
| J | 无独立状态 | 唯一 double 体积主状态，`Jdot=J*theta`，初始1 |
| n | 全局常数 | 从 J 导出 `n=1-(1-n0)/J`，不再独立积分另一套 n |
| V | 当前 m/rho | `V=V0*J`，作为空间积分体积 |
| rho_t | 与计算密度混用 | `rho_t=(1-n)*rho_s+n*rho_w0`，首版惯性使用参考水密度近似 |
| p | float 孔压及压力率 | 首版保留已有精度，不重新引入高低位或全变量 double |

初始定义为 `V0=MassFluid/RhopZero`、`rho_s=(RhopZero-n0*rho_w0)/(1-n0)`、`m_s=(1-n0)*rho_s*V0`。只有 `0<n0<1`、rho_s>0 和 `J>1-n0` 的状态属于该饱和不可压固粒模型；不能靠截断 n 来掩盖失效。

固定固相质量满足 `(1-n)J=1-n0`。`rho_t*V`一般不保持常数：不能把新的 rho_t 直接塞回所有旧质量分母。参考水密度惯性是 Lian 式低频、线性储水近似，不把它宣称为精确可压缩水质量闭合。

当前计算密度率使用原核梯度（`JSphCpu.cpp:2501`），孔压压缩率和应力率另有梯度矫正（2465–2476、2631–2641）。新 J、储水和体积必须采用同一套明确的 theta=`div(v_s)`；直接由旧 float rho 推 n 会把这些不同离散悄悄混合。

## 动量和水量的一致性范围

新分支候选先按 Lian Eq.26，以总应力 `sigma_tot=sigma_eff-pI` 和实际积分体积构造：

```text
a_i = (1/rho_ti) sum_j Vj (sigma_tot_i+sigma_tot_j) grad_i Wij + g
```

这是需要后续验证的新动量离散，不是“只换 Kw/n”。在相同均匀密度时与旧对称式一致；非均匀密度时不承诺与旧 `rho^-2` 应力式相同。未矫正核的成对瞬时内力相反；若引入 receiver-C 等矫正，须另验互易性、功率与均匀应力平衡。瞬时内力平衡不等于渗流交换质量后的全局动量时间积分精确守恒。

孔压采用 `(n/Kw) pdot=-theta-div(q)`，`q=-(k/gamma_w)[grad(p)-rho_w0(g-a_s)]`。k 单位 m/s，`gamma_w=rho_w0*g_ref`；物理重力关闭不应把参考 g_ref 置零。固定 k 不意味着冻结 n/Kw 或液压自然步长。

水量验收分开记录线性储水残差、边界通量、EOS重建水质量及模型近似余项。均匀不排水、恒 Kw 的代数参考为 `p-p_init=-Kw*ln(n*J/n0)`；用它重建 `rho_w=rho_w0*exp((p-p_init)/Kw)` 时 `rho_w*n*J`不变。这个 EOS 只作首批诊断，不反馈给惯性，也不能据此声称一般有流动时精确质量守恒。

## 主循环与既有功能的接入限制

动态 Darcy 在同阶段内力、外载归一化、阻尼和 HG 都完成后读取加速度，复用现有 cell 表，不能在融合 force 环读取尚未完成的邻居 Ace。当前 Ace 不含 Gravity，积分才加；所用物理加速度必须明确加一次重力。NoPen 的后置投影与壁面加速度延拓需单独验证。

HG 当前使用固定 Mass 构造 V、惯性和功率（`JSphHourglassCpu.cpp:67,142,147,188–189,218–219`）；band 外载也用固定 MassFluid 归一化（`JSphCpu.cpp:1259,1264`）。首批新模式闭合制造场关闭这些功能，随后显式适配体积/惯性再验收，不自动继承旧模式验收。旧模式的 HG、外载与正式算例均保持不变。

## 本阶段测试与下一步

`tests/support/upl_p0_closure_r1.py` 只检验上述代数闭合、参考水量、加速静水符号和微小增量精度，不是耦合求解器。基本不变量限值为5e-13相对量，长递推限值另按累计 binary64 舍入界预先给出；它不采用固结算例的5Pa门限冒充方程证明。

P1 独立 CPU 程序采用当前 Wendland 核，比较旧 raw/receiver-C/symC 标量扩散与 `L*=L-Gp·Lx`，先做二维规则和受控失序场。Eta2 正则化和无正则文献形式分别标记。线性再现、二次误差、静水平衡、体积预算、谱与成本分别记录；即使线性再现通过，也不自动准入生产或三维。

P2/P3 才实施持久 J、排序/预测校正/native 输出及完整新压力率，并添加默认关闭的正式开关。新模式下旧压力率整套停用，不能重复加一次压缩/扩散。P4 再同步 GPU 与固结/Cryer/Lian验证；服务器现有 Cryer 包不变。
