# 饱和低频动力孔压框架开发计划

2026-11-01。代码基线为 `87b5c4d64005a44c67a08728a1869968caaee81c`，已有算例范围见 [u-pw验证基线](upw_baseline_r1.md)。本轮是设计准备，不修改生产方程、正式输入或服务器Cryer程序。用户提供的分享链接未能取得正文，以下采用本条需求、本地原论文及当前源码，不假定已读分享对话。

## 推荐目标

首版采用单套骨架随动粒子的**饱和低频动力 u-p 扩展**：有限水体积模量、动态孔隙率、常数各向同性水力传导系数，保留骨架加速度对Darcy流的影响。保留当前u-pw为默认、可对照的独立路径。新压力空间算子先独立评估，只有收益和稳定性得到验证才进入该模式；TPI、变k、负压经验处理不与首版捆绑。

`p_l`与`p_w`只是液相/水相压力记号。Lian 2023 Eq.5–10仍忽略水固相对加速度，不能把它称为完整两相惯性的u-w-p。当前u-pw也有骨架动力学，区别不是“静态变动态”，而是新增了哪些具体连续项、状态及离散近似。

| 问题 | 判断 | 开发决定 |
| --- | --- | --- |
| 对边坡是否有意义 | 孔隙率、有效应力及渗流反馈有意义；骨架加速度渗流项的大小取决于工况，不能由“大变形”三个字判断 | 加入可验证的低频动力能力；不预先承诺Selborne必有明显差异 |
| 是否先固定k | 合理。Lian的Terzaghi及谐波固结也固定k | 首版不实现经验k(n)，但仍更新n相关储水和已选质量/体积关系 |
| 新二阶离散是否一定更准 | 现Morris也是二阶空间微分；Lian增加的是粒子失序补偿，不是框架名称带来的二阶收敛保证 | 同粒子、核、边界、时间积分进行制造解和成本对照 |
| 固结/Cryer是否应几乎相同 | 小变形、低频、匹配有限Kw/初态/边界的极限下应接近同一理论；快速ramp及Cryer峰值阶段不能先验等同 | 比较理论误差与峰时刻，不把新旧差异直接视为回归失败 |

## 方程与变量约定

采用拉应力为正、孔压压缩为正，`sigma = sigma_eff - p I`。令`a_s=D_s v_s/Dt`、`q=n(v_w-v_s)`、`g`为重力向量，`gamma_w=rho_w g_ref`，则目标低频近似为：

```math
\rho_t a_s=\nabla\!\cdot\sigma_{\rm eff}-\nabla p+\rho_t\mathbf g,
\qquad D_s n/Dt=(1-n)\nabla\!\cdot v_s,
```

```math
q=-\frac{k}{\gamma_w}\left[\nabla p-\rho_w(\mathbf g-a_s)\right],
\qquad \frac{n}{K_w}\frac{D_s p}{Dt}+\nabla\!\cdot v_s+\nabla\!\cdot q=0.
```

这里`k`是现有XML的`HydraulicConductivity [m/s]`，不是内禀渗透率`kappa [m²]`。二者关系为`k=kappa*rho_w*g_ref/mu_w`。即使关闭物理重力，转换水力传导系数的参考`g_ref`也不能变成零；须保持与当前代码参考值一致并明确单位。首版采用参考水密度/水黏度与有限Kw储水近似，不同时引入完整可压缩水输运。

孔隙率方程依赖不可压固体颗粒假设。独立参考是`(1-n)J=1-n0`，其中J是骨架体积比；它不意味着当前`Velrhop.w`就是固粒本征密度。有限Kw的线性储水式也不等于完整水质量方程：后者还含相对通量与水密度梯度的乘积等项。验收必须区分连续残差、离散通量预算与按所选EOS重建的水质量诊断，不把条件储水量称为精确水质量。

### 必须先确定的质量和体积账本

当前`MassFluid`固定，`Velrhop.w`由骨架速度连续方程更新，`m/rho`又用作积分体积和内力权重；初始`RhopZero`通常按混合密度输入。存在流入流出的骨架随动控制体，不能同时任意强制固定混合质量，又由动态n重算物理混合密度。

P0必须给出以下量的唯一含义与去向：固粒本征密度、参考体积/固相质量、当前积分体积、物理混合惯性密度、原SPH计算密度、n及p。建议以固定固相质量和骨架体积关系闭合新模式，明确区分积分体积与惯性密度；**不直接以`n=1-Velrhop.w/rho_s`替代孔隙率方程，也不把新的混合密度直接塞回所有旧rho分母。** P0须推导相应内力/体积权重和惯性，再确定最少状态数组；旧模式完全保留原定义。

Lian连续Eq.8与离散Eq.24还有一项选择：前者是`(1-n_i) div(v_i)`，后者采用邻域`(1-n_j)`权重。非均匀n时不可当作同一个离散。首版建议优先验证局部骨架质量/J闭合，并把与文献离散的差异写清，不同时维护两套可漂移的n/J主状态。

## 空间算子的最小研究路线

当前代码使用receiver-C或土—土symC Morris型扩散。Lian Eq.23加入一阶梯度补偿。对于其二维、常数各向同性k的压力项，可整理成：

```math
L_i^*p=L_i p-(G_i p)\cdot L_i\mathbf x.
```

`L_i`、`G_i`必须采用明确且一致的邻域/体积/梯度定义。该式说明首个候选只需在本地累计压力梯度、标量拉普拉斯和坐标误差矩，循环末收缩；不必先建全局六分量Hessian。若保留当前`Eta2`分母，它是有正则化的同型变体，不是文献公式的逐式复现。

实施前有四个必要审查：

- 论文Eq.23所示`4 r_m r_n/r²-delta_mn`不能直接推广三维；应从维度相关矩推导并用三维二次/混合二次场检验。常见`d+2`系数只是推导入口，不是完成三维推广的证明。
- Eq.25的压力梯度补偿项在所读PDF排版中未显式带`1/gamma_w`，而压差项带有该因子；按k的m/s定义有量纲歧义。应从连续Eq.10和空间Eq.23重推，使压力扩散与其补偿共同具有正确系数，不直接转录Eq.25。未取得作者代码，不能据此判断其实际实现错误。
- Eq.25显式补偿压力而未同样补偿重力z项。直接对完整水头`p+gamma_w*z`作补偿是需要说明的静水平衡变体，不能冒称原文照搬。先用静水和加速平衡制造场决定是否需要该变体。
- 局部一致性补偿与symC的成对互易性不是同一件事。额外项不天然是反对称通量，线性再现不证明质量守恒、耗散或无振荡；也不能自动继承旧symC的验收。

若新算子仅更平滑、没有可量化精度收益，或守恒/耗散代价过大，保留旧的已验证扩散仍可继续发展动态n与低频动力项；不能为“叫u-pl”强行采用一个未通过的算子。

## 分阶段开发和验收

| 阶段 | 本阶段只解决什么 | 交付与进入下一阶段的依据 |
| --- | --- | --- |
| P0 方程与账本 | 符号、单位、n/质量/体积/惯性、边界通量和阶段加速度定义 | 一页变量映射、闭合推导、旧模式基线及测试阈值；未闭合前不加生产n数组 |
| P1 独立算子 | CPU冻结粒子场中的旧receiver/symC与新补偿算子 | 2D后3D常数/线性/二次/混合场、规则与受控失序、近墙/角点；收敛、静水、通量预算、扩散谱/耗散与实际计时 |
| P2 动态孔隙率 | 先观察，再接入已闭合的体积/储水/惯性；k固定 | 均匀压缩/膨胀、无体变剪切、刚体运动；`(1-n)J`、有效体积分数、质量残差、排序/预测校正/输出；不夹带新TPI |
| P3 显式低频动力 | 同阶段骨架加速度进入Darcy；有限Kw、小步长 | 加速平衡/制造解、k=0不排水、慢加载退化、1D谐波幅相及独立半步；新压力率只计算一次 |
| P4 组合验证及GPU | CPU已通过的同一物理同步到GPU，随后短窗至必要完整周期 | 当前ID/实际时刻、CPU/GPU与独立半步、原生场/边界预算及成本；1D→Cryer→混合滑移Lian，正式长程逐例准入 |
| P5 积分效率决策 | 用限步与成本记录判断TPI是否值得 | 机械/液压限步占比、同精度物理时间吞吐；值得时才单独复现TPI及高k基准 |
| P6 目标工况 | 塑性小样本和Selborne需要的能力 | 再决定负孔压经验稳定和k(n)；补齐Selborne多材料/区域孔压条件后才实际启动坡体计算 |

P1的“二阶微分”不预设任意失序粒子二次精确。需先给出该候选的再现条件和预期误差阶，再登记阈值，不能看图后放宽。受控失序使用固定种子和相同native IDs、相同支持域/核/边界，不同时加shifting。若为测试算法本身需切换核函数，另立对照，不能与当前Wendland基线混算。

P2新增n或等价J的持久状态优先评估double，避免长时小增量低于float ULP；先用逐步压缩试验量化必要性。只针对这一个新状态，不重新启动全变量双精度改造，也不引入高低位补丁。n相关储水、自然步长与所选密度/体积关系必须使用同一阶段状态。边界虚粒子不能被当作真实含水控制体参与全域质量总量。

P4沿用原有同模型独立半步和跨后端比较规范：实际匹配时间/native IDs、压力RMS 5 Pa、材料位移上限 .005 mm，按具体工况先登记适用样本与安全条件。新旧物理选项的差异不是“5 Pa半步误差”。不把1D的100 Pa均匀应力条件强套到非均匀2D/3D问题。理论精度另行评定，Cryer约1%的幅值目标仍保留相位/局部场限制，不因跨过1.000%而无界调参。

完整验证只扩展有明确目的的窗口：先1D标准/谐波，再Cryer峰窗及必要长程，随后Lian前三时刻/A-B历史。自重先做静水平衡短检，已暂缓的旧全程残差不在本轮重新无限排查。当前服务器三个Cryer组仍是原模型对照，回传后照既定计划分析，不必为新框架计划重跑。

## 主循环接线及修改范围

当前生产孔压率在主force邻居环融合计算，不是独立`InteractionPorePressureRate()`的调用。动态项不能在那里读取邻居的`Ace`：其力尚未全部完成，GPU还存在读写竞态。

新模式应在本阶段mDBC/SPR、自由表面/C、主内力、加载归一化、阻尼、HG均完成后，再作一次只读邻域遍历；可复用同一阶段cell表，无需为此重新分格。固定各向同性k时，可在这个遍历内同时累计局部压力梯度/补偿矩、加速度散度和所需n率，避免不必要的Hessian全局数组与重复遍历。不同阶段的几何、C与率不得混用。

`Ace`当前不含Gravity，积分才加。P0须明确用于Darcy的`a_s`为哪一套实际阶段加速度、如何包含数值阻尼/HG；不能遗漏或重复重力。NoPen后置速度/位移投影未自动包含在force数组中，新模式初期不据旧SPR测试宣称NoPen动力通量已一致。固壁的加速度延拓及`q·normal=0`也须另验，速度SPR不是加速度边界的自动证明。

新模式接入时，应关闭其旧孔压率的融合累加，只保留需要的孔压力反馈，再由新遍历完整写一次压力率；不能在旧PR上再次添加整套新PR而重复计算压缩/扩散。骨架力学及当前double应力写回不在此时顺手重构。

拟涉及的源码按阶段处理，不一次性改完：

- P1先使用独立测试伴随程序；通过后才抽取小型标量算子函数，不引入通用“大框架”。
- 模型读取/公共参数：`DualSphDef.h`、`JSph.h/.cpp`；CPU数组/积分/force：`JSphCpu.h/.cpp`、`JSphCpuSingle.cpp`；GPU对应文件与`JSphGpu_ker.h/.cu`。
- 新状态必须成套覆盖分配/扩容、cell排序、周期复制、预测/校正、CPU/GPU搬运、native输出和PART读取。具体以调用审计列最小清单，不能只修改积分循环。
- 原生p/p0保留；新增n、体积比或等价诊断、Darcy通量与动力项贡献，输出身份/材料点不变。新模式PART需有状态/模型版本；缺n的旧PART不自动冒充可续算新模式。已有HG精确restart限制不因此解除。

这里“保留新旧模式选择”首先指各自独立的fresh run；质量、体积、n与历史状态迁移未推导和验证前，不支持在同一PART续算时直接跨模型切换。

正式输入预计只增加一个模型选择入口，例如`HydroMechFormulation=UPW_PR/UPL_PR`，名称在P0后确定；中间归因开关留在测试夹具，不向正式XML堆叠大量布尔参数。TPI真的准入时再增加单独的压力积分选择。旧TPI键目前明确报错，继续保持，不能把旧归档代码或旧XML恢复后当作已验证的新实现。

## TPI 负孔压与渗透系数的后续取舍

**TPI**：Lian先令`n/Kw`储水项为零，再以邻点历史外推近似压力约束，不等价于原有限Kw PR方程无条件放大dt，`alpha=1`的历史外推也不能被当作迭代收敛的隐式解。它仍受机械与液压稳定限制。低k时液压显式限步反而较宽松，机械常主导；Lian低渗黏土坡采用显式。只有测得液压限步确实主导、预期节省超过每步新增成本，才开展TPI；并使用相应不可压极限参考及有限Kw偏差预算。变步长的历史外推须重新推导，不能照搬等步公式。

文献其余状态采用Leap-Frog交错更新，当前默认是Symplectic预测/校正。TPI准入前还须定义压力历史对应整步还是半步、首步如何启动、每物理步何时更新历史；不能将Eq.39直接拼进现有预测/校正数组便称作已复现。

**负孔压**：Eq.47针对塑性剪胀，beta需校准，它不是空化或非饱和模型。区分总表压、绝对压和相对p0的超孔压；负超孔压不必然意味着空化。弹性固结/Cryer及谐波试验不默认截断或削弱负压。先用小型剪胀/收缩试样评估真实有效应力与孔压，再决定是否需经验稳定，不能为贴论文图而调beta。

**变k**：先固定k完全可行，但“小整体位移”不保证局部剪切带孔隙率变化小。可在已有n历史上离线评估候选k(n)的变化范围，不反馈求解；若没有材料参数，明确不能定量证明其影响可忽略。只有该敏感性与研究数据支持，才进入k(n)或各向异性，初版不做。

这里固定k指不随时间/孔隙率演化，不要求不同材料具有相同k。首个均质验证可用全局常数；Selborne的分材料定值属于其材料接口工作，不能拿当前单一全局SoilCte代替真实分层。

## 开销与交付约定

新增一次邻域遍历不等于整步耗时翻倍。记录同粒子/同dt/同输出频率下的主交互、新遍历、排序和I/O耗时、峰值内存、CPU/GPU吞吐；比较算法效率时再计算达到同精度所需的每单位物理时间成本。近似总收益为`步长放大倍数 × 旧每步耗时/新每步耗时`，不能只报steps/s。

低k的固结物理时长很长，不代表液压限步最严；固定Tv终点的时长还随k减小而增大。若机械步已控制，TPI不能自动消除这部分长时长成本。

没有实测前不宣称CPU、RTX3050或RTXA6000必然更快。先做有界小计时，不启动多天长程调参。新模型的离散谱/耦合稳定性需复核，不能原样继承旧液压限步；当前FixedDt不会自动被pore dt裁剪，固定步长也必须记录并独立核验稳定余量。

新开发在独立分支逐个小提交，旧u-pw基线及正式数据原位保留。每阶段说明修改函数、数学目的、测试差异和保留结果，验证后选择性commit/push并核对远端。每个case验收后才更新根目录正式XML/BAT，用正式入口完成必要完整计算、图和CSV；测试仍按所属case的`tests/configs、outputs、logs、figures、notes、support`组织，不新建深层目录。实际新增参数时同步`doc/xml_format/_FmtXML_ElastoplasticSoil.xml`，本轮仅列建议名称，不预写不存在的功能。

Selborne现有`07_Selborne3D_u_pw`正式BAT仍因多材料和区域底压ramp缺失而停用；框架升级不自动补齐这些功能，也不应绕过该停用入口。Yao、完整u-w-p高频两相惯性、非饱和/空化及一般曲面运动边界不列入首版。
