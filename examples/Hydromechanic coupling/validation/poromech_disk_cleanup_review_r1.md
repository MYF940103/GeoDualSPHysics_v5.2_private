# Cryer 与一维固结磁盘整理核验

2026-11-03，按用户授权完成明确白名单的整理；本记录不构成数值或物理验收。

- 第一轮：2697 个历史 Cryer VTK，NTFS 实际存储节省 1,737,127,438 字节。
- 第二轮：8021 个已经结束的六月 Cryer VTK，NTFS 实际存储节省 9,153,060,596 字节。
- 合计：10,718 个 VTK，节省 10,890,188,034 字节，即 10.142277958 GiB。逐文件压缩前后 SHA256、文件长度、修改时间一致，原路径保留；未删除或移动结果文件。
- 自重固结只删除三个核实无依赖的旧增量链接缓存 ILK，合计 115,584,456 逻辑字节。这个数不是精确的卷空闲增量；EXE、PDB、对象和源码归档保留。

两份压缩检查、逐文件记录及通知器终态已核验。终态引用的 23 个冻结证据文件重新计算哈希一致；原 owner 已退出，各自最终检查有效，未重新运行清理。ILK 原脚本在删除后的汇总表达式失败，保留该失败并以独立离线检查证实三个文件已删除、程序/PDB 未变化，没有重做删除。

卷空闲量还受其他任务影响，不能将其全部变化归因于本轮整理。只以上述逐文件实际存储差值报告节省。原始 BI4/NBI4、正式输入与输出、重启链、图与 CSV、哈希绑定的程序和源码快照均保留；活动 CPU HG 半步长和独立 GPU component 未停止或重启。

主要证据：`compact_cryer_legacy_vtk_r1.check.json`、`compact_cryer_closed_vtk_r1.check.json` 及其 before/after/calls 记录、`remove_sw_link_cache_r1.offline_r1.check.json`、`poromech_disk_followup_r1.terminal.json` 和 `poromech_disk_followup_r1.queue_attempt.json`。历史文件和原失败收据不改写。

NTFS 压缩对读取透明；如需解除压缩，可对对应清单中的原路径使用 `compact.exe /U /I /Q`，需先准备足够空闲空间。没有必要为正常分析或可视化解除压缩。

Git 选择性备份包含整理脚本、清单、检查与说明，以及已完成 CPU HG coarse 的诊断材料；原始粒子数据、程序和源码归档继续在本地保留，不能称为已通过 Git 备份。活动半步长和 GPU 工作不因这次备份获得通过标记。
