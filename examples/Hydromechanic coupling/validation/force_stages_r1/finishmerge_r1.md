# 求力收尾合并与 GPU 复测

Verlet、Symplectic 的预测和校正，以及 TPI 的各轮端点迭代，均由积分器显式调用边界修正、阶段数组准备、预循环和求力。`Interaction_Forces` 负责邻域求和、完成本阶段的加速度和压力率、计算步长上限。CPU 直接使用相互作用结果中的黏性步长量。GPU 从预循环接收当阶段的周期粒子 ID 映射，Darcy 压力率计算在消费该映射后按原路径释放。

## 对照版本与方法

| 程序 | 来源 | 用途 |
|---|---|---|
| `old` | `994b0f1` 的发布程序 | 初次拆分前的累计基线 |
| `validated` | `68eea4d` 的发布程序 | 含独立 `FinishInteractionForces` 的直接对照 |
| `merged` | 本次 VS2022 x64 构建 | 收尾已并回主求力函数 |

数值回归直接比较 `merged` 和保留的 `validated` 输出。GPU 计时则实际运行三个 Release 程序，每轮使用同一个 C02 模型 2 种子，按 C02 保存步号和完整 PART 字节核对执行结果。两种计时条件分别覆盖三个程序的六种出场次序。主循环取 `Run.csv` 的 `TSimul`，总壁钟另计入启动和输出。每秒采集设备频率、利用率和功耗。

在本目录已有三个版本的可执行程序与依赖后，可用以下命令复测。每次使用新的 `--tag` 来保存结果。

```powershell
python -B gpu_retest.py --version merged --tag locally_repeated --mode both
```

## 数值回归

CPU/GPU 的 Debug 和 Release 四种 x64 配置均由 VS2022 构建成功。合并前后 GPU Release 的 `.nv_fatb` 段共 21,706,240 字节，逐字节相等。[构建与设备代码记录](finishmerge_r1_builds.json)

| 后端 | 直接对照帧数 | 数组比较 | 原生标量比较 | 完整 PART 相同字节数 |
|---|---:|---:|---:|---:|
| CPU | 64 | 1,112 | 4,071 | 81,155,019 |
| GPU | 60 | 1,024 | 4,015 | 75,380,279 |

六条通用路径覆盖干柱、C02 三种模型和 C04 三维球体。两端又各跑了实际撤墙 2,001 步的 C08 塑性窗口，CPU 另外验证了四帧短预载交接。CPU 的显式算例在同一初始状态下以原有首因拒绝超限步长。两端合计 124 帧、156,535,298 字节均与各自合并前版本相同。[CPU 原生对照](compare_merged_cpu.json) · [GPU 原生对照](compare_merged_gpu.json)

## RTX 3050 耗时

每个版本的时间是六次运行的主循环中位数。百分比先在同一个区组内求新版与对照的耗时比，再取六组比值的中位数；正号表示耗时增加。两种条件合计 36 次计时、144 个实际保存帧，同组各版本的完整 PART 均逐字节相同。预热组另有每版 48 步的暖机运行。

| 条件 | 原版 | 合并前 | 合并后 | 合并后相对合并前 | 合并后相对原版 |
|---|---:|---:|---:|---:|---:|
| 默认主机调度，384 步 | 6.403 s | 6.410 s | 6.337 s | −1.30% | −0.61% |
| 分别预热，主机线程绑定同一性能核，192 步 | 3.210 s | 3.198 s | 3.218 s | +0.225% | −0.09% |

合并后相对合并前，各组主循环耗时变化在默认调度下为 −2.51% 至 +1.75%，在预热绑核条件下为 −3.14% 至 +1.80%。包含启动和输出的总壁钟配对中位变化分别为 +0.24% 和 −0.84%。预热组 77 个遥测点的 GPU 图形频率均在 1,920–1,927 MHz。[默认调度原始计时](finishmerge_r1_gpu_default.json) · [默认调度遥测](finishmerge_r1_gpu_default.csv) · [预热绑核原始计时](finishmerge_r1_gpu_pinned.json) · [预热绑核遥测](finishmerge_r1_gpu_pinned.csv)

上轮的 +56.87% 对应默认调度时“合并前”相对“原版”的差异，这次同一对照为 −0.09%。复测没有观察到可重复的主循环性能损失；上次波动的具体成因无法由这两次数据单独确定。
