# 力评估拆分的数值与性能回归

基线为 `upl-dev` 的 `994b0f1`，对照采用当时发布的 Win64 程序。重构采用相同的 VS2022 工程、MSVC 和 CUDA 构建配置。四个历史程序只在留存时核验了一次文件指纹。[基线程序](baseline_programs.json)

## 求力和积分的顺序

CPU 和 GPU 的 `ComputeStep_Ver()`、`ComputeStep_Sym()` 均直接调用 `Interaction_Forces()`。Verlet 每步求力一次，Symplectic 在预测和校正各求力一次。模型 2 的 `CorrectTpiPressure()` 在端点的三轮压力循环里逐轮显式求力。一次评估先处理边界，再分配和初始化本阶段的数组，准备自由表面、载荷和孔压，运行邻域相互作用，最后完成加速度、Darcy 压力率和步长统计。积分器仍在求力和计算步长后调用通常的 shifting。各后端保留其原有的加法、归约、计时范围及临时数组生命周期。

动态渗流墙分两处更新。先由土粒重构本阶段的墙状态，再在材料自由表面和校正矩阵更新后将矩阵延拓至墙。初始化、压力边界维护和粒子输出可单独调用 `UpdateWallAndFreeSurfaceState`。三维 Cryer 围压保留在粒子对求和中，顶部核带载荷在取得主循环生成的原始权重后归一。两项历史受保护的 C++ 调用保留原行为，三个原始探针已通过 MSVC 语法检查。[探针源兼容检查](validated_probe_source_compatibility.json)

## 数值对照

每条路径在同一后端以完全相同的种子、参数、输出计划和线程数运行旧版与新版。逐帧检查实际时间、步号、材料 ID、数组类型及数值字节。TPI 同时检查用于下一次外推的源孔压历史。C08 从原生预载导入，单独检查释放后确实有土粒进入塑性、自由表面孔压、几何和体积账本。[通用对照脚本](regression.py) · [C08 预载与撤墙对照](c08/README.md)

六条通用路径覆盖干柱 Verlet 与标准 shifting、干柱 Symplectic 与 cDBC、C02 三个水动力模型，以及 C04 的球面围压。每端各 54 帧、892 项数组对照通过，108 个完整 PART 的 133,397,542 字节逐一相同。三个柱算例里，固定的十个顶层土粒在完成第 3 步时仍有正孔压，从第 4 步起均为零。各端另对照了 C02 的 8 帧和 C04 的 4 帧非初始 TPI 压力历史。[运行和复现](regression.md)

CPU 的预循环和孔压文件中共迁入 27 个函数。对照基线源码，逐个核实函数体，统一换行和自由表面更新函数的名称后全文相同。CPU/GPU 的 x64 Debug 和 Release 四项构建均通过。[源码移动核对](moved_methods.json) · [构建结果](builds.json)

VS 工程和 filters 已列出两个新源文件，仓库现有的 Make 和 CMake 文件也已同步。这里的构建结果覆盖 Windows VS2022。非 VS 清单在基线中已缺少部分 mDBC 和 hourglass 实现，本轮仅检查了新增编译单元的登记。

在 RTX 3050 上，用 Nsight Systems 记录 C02 TPI 四步。两个版本实际各执行 1,383 次 CUDA 内核，涉及 59 个内核符号；在单一流上的执行顺序、网格、线程块及动态共享内存逐项相同。GPU Debug 两步的 Compute Sanitizer 检查为零错误。旧版的 Nsight 启动器在求解完成后超时，随后导出的 SQLite 已通过完整性检查。[GPU 调用序列](gpu_tools/old_4_validated_4.json) · [旧版导出记录](gpu_tools/old_4/cli_timeout_export.json) · [Debug 内存检查](gpu_tools/validated_debug2/run.json)

## Release 耗时

另从两份 Release 程序离线提取 RTX 3050 对应的 14 个 `sm_86` cubin。逐项比较 638 个可执行段的 25,860,864 字节和 1,256 个已定义函数的布局及指令，全部一致。其中两个 cubin 的字符串表含不同的编译器私有标识。[设备机器码对照](gpu_tools/native_sass_equal.json) · [复核脚本](compare_gpu_device_code.py)

下表采用四对旧版和新版交替运行的结果。正号表示新版耗时增加。主循环取求解器 `TSimul`，总壁钟还包含程序启动和写盘。每对计时运行同时检查实际输出。

| i7-12700，单线程，同一逻辑核 | 384 | +1.01% | −0.14% |
