# C08 力计算分段回归

本轮比较同一后端重构前后的公共 Release 程序。求解器自行读取真实预载，按原时钟和原材料状态撤墙。只在验证目录生成输入和输出，所用 XML 将旧配置的模型及排水键迁至公共写法，调整短窗输出间隔。原 PRE、法向和原案例结果原位保留。

| 检查 | 原生输入 | 短窗 |
|---|---|---|
| CPU 短预载交接 | `upl_preload_handoff_source_CPU_r1/data/Part_0010.bi4`，Cubic，CPU 来源、弹性 PRE、schema 1 | 从实际 0.0009500000000000023 s 开始，40 步，2.5 µs/步 |
| CPU、GPU 同材料塑性窗口 | `c08_h18_wend_psi0_pre_r2/data/Part_1000.bi4`，Wendland，GPU 来源、schema 2、ψ=0° | 两端各自从同一保存态 9.999999999706008 s 开始，2,001 步，5 µs/步 |

接收窗口使用显式 u-pl、变 k、两侧 FreeSlip、床面 NoSlip。预载交接按旧时钟同步撤掉右墙，关闭阻尼和 Shepard，并打开自由渗流。塑性窗口沿用发布算例的人工应力系数 0.3、指数 2.55 以及阶段固定平面投影。其同阶段 Darcy 反力尚未闭合。该 PRE 的 5,000 个土粒实际 κ 均为零；窗口内出现的正 κ 来自真实屈服。

`release_regression.py` 的 `run` 记录程序身份、预载、调用和退出，避免覆盖已有运行。`compare` 使用上一级 `regression.py` 读完整原生文件，在相同后端和相同步上比较每个数组的类型、形状和全部负载字节，并比较物理元数据、实际时钟及有符号步长差。结果另核对原粒子 ID 和初始孔压继承、逐次累加的实时时钟、体积/孔隙率/密度/变 k 关系、已开启自由表面正压为零、固定平面两侧的粒子位置和塑性历史。每份程序独立运行，不将两后端的浮点差异纳入同后端重构验收。

运行命令使用 `python -B release_regression.py run <short_cpu|plastic> <cpu|gpu> <old|validated>`，各自产物位于 `runs/<lane>_<backend>_<version>`。完成同端两版后运行 `python -B release_regression.py compare <lane> <backend> validated`。移机时需提供原母种和对应的真实 PRE；脚本按案例与文件名定位本机副本，并使用原求解器检查预载合同。

## CPU 结果

短预载释放后共 4 帧，88 次粒子数组比较和 296 项标量比较均逐位一致。末帧活动 ID 为 6,800 个，5,000 个土粒中有 149 个自由表面点，正孔压数为零，累计塑性历史仍为零。[原程序与最终 CPU 的交接回归及原生物理量](short_cpu_cpu_validated.json)

同材料窗口共 6 帧，132 次粒子数组比较和 486 项标量比较均逐位一致。原程序与最终 CPU 分别读取同一份 GPU 产生的 schema 2 状态，末态实际时刻 10.010004999705629 s。6 帧中 κ>0 的土粒数依次为 0、0、1、20、69、174，末态最大 κ 为 0.00316559919，孔压 −6.798 至 22.062 kPa，149 个自由表面土粒的正孔压数为零。[原程序与最终 CPU 的塑性窗回归](plastic_cpu_validated.json)

## GPU 结果

原程序与最终 GPU Release 分别导入相同的 schema 2 预载。2,001 次更新、6 帧、每帧 6,805 个原始 ID；132 次粒子数组比较和 510 项物理与诊断标量比较全部逐位一致。末帧有 174 个土粒 κ>0，最大 0.00316559896，压力范围 −6.798 至 22.062 kPa；149 个自由表面土粒全部满足完成步正压约束。所有帧满足同材料孔压初值继承、三面混合滑移设定、原生有符号步长界及 J/n/V/ρ/k 账本。本次数值回归未计入独占性能测量。[原程序与最终 GPU 的塑性窗回归](plastic_gpu_validated.json)
