# TPI 的 XML 选择与水力步长放大系数

## 方案与接口

维护中的配置采用单个 `HydroMechModel`。公共 CPU 与 GPU 程序已接入 0（u-pw）、1（显式 u-pl）和 2（三轮 TPI）。公共模型 2 的可选项 `HydroMechTpiR` 缺省为 1，已归档的 C02 与 C04 保留当时的 R=1。下面保留早期私有试验程序的接口和数据，以便复现。[公共版本适用范围及回归](public_tpi_release_r1.md)

在 ν=0.30 的 Cryer 服务器峰窗中，576 个非空输出区间共覆盖 36,864 次更新，每步含五个阶段。固定步长为 1.90735 µs，全部阶段中水力上限的最小值为 2.92882 µs，骨架波速与人工黏性上限的最小值为 25.03415 µs。实际所需的最大水力比值为 0.65124，配置 R=1 可以覆盖这个峰窗。旧有限 Kw 波速上限的最小值为 1.58360 µs。提高 R 对同一固定时间步的峰值偏差没有修正作用。[服务器步长数据](upl_tpi_r_selection_server_peak_r1.csv) · [同一峰窗的精度](../04_CryerProblem_PR/tests/notes/cryer_peak_iteration_and_support_r1.md)

归档的 Cryer 私有程序使用 `HydroMechPressureIntegrator` 和 `HydroMechDynamicSeepage`。公共 XML 统一选择 `HydroMechModel=2`。该实现用两时层压力向前外推（α=0.5），每步进行三轮端点压力校正，再提交一次历史。简化投影和负压 β 保留在研究程序中。

## 怎样确定 R

Lian 等式（40）使用 Δt ≤ min(Δtₛ, R Δtₗ)。式（41）给出骨架波速限制，式（42）用 Δtₗ = Cₗ n γₗ h²/(Kₗ k_sat) 定义显式流体临界步长。式中 k_sat 为水力传导系数，γₗ 为水的单位重。R 只乘水力项。固定分辨率时，作者指出较高渗透系数允许采用较大的 R。第 4.1 节用同一材料算例的显式步长 0.288 µs 作分母；5 和 10 µs 分别对应约 17 和 35。论文还记录了 α 影响大步长精度和稳定性的现象。[Lian 等（2023），式（38）至（42）及图 4](https://doi.org/10.1016/j.cma.2023.115967)

本项目先根据精度、事件分辨率和成本选 Δt目标，再用 R需求 = max时间、阶段(Δt目标/Δtₗ) 计算所需放大量。对于固定目标步长，此式可直接使用全部阶段的最小 Δtₗ。R需求 小于 1 时，取 R=1 已覆盖该步长；大于 1 时，可用该比值设计高渗算例验证。稳定且精度合格的试验只为相同材料、空间算子、分辨率和时间方案建立已验证范围。Δt目标同时须满足实际力、骨架波速/人工黏性等独立限制；出现变 k 时，还需保留与系数空间变化有关的独立限制。盲目增大 R 不能越过这些限制。

## 实际选值

已有 k=10⁻⁴ m/s 的 C02 和 k=10⁻⁵ m/s、ν=0.30 的 Cryer 峰窗继续使用 **R=1**。对于新的弹性常渗透率工况，先由目标误差、加载和排水事件选取实际步长，再按式（42）计算该步长与沿程水力上限的最大比值，选择可覆盖它的最小实用 R（至少为 1）。复核力学、黏性及 HG 限制后，与同一材料、加载和网格的受控参考比较孔压、沉降及耗时。材料或分辨率改变时重新计算该比值。

C02 的 k=10⁻³ m/s 高渗短窗中，10 µs 配 R=2.25 足以维持时间步，却未通过孔压与顶部沉降的精度要求。两端同取 1.25 µs、TPI 配 R=1 时，首目标 Tv=0.005 的孔压 RMS 为 224.70 Pa，显式 u-pl 为 179.33 Pa。相同实际步长下已经出现该差异。另将已获准的 4 µs 从 R=1 改至 2.25，到排水后首步的 22 个场和上一时层压力在各自后端逐位相同。**对这组高渗参数，按本次精度标准选显式 u-pl、1.25 µs；R=2.25 仅记录为 10 µs 的稳定性诊断取值。** 验证时段至 Tv=0.05。[同机精度、耗时与适用范围](../02_TerzaghiConsolidation_q0_PR/tests/figures/c02_tpi_cost_r1/summary.md)
