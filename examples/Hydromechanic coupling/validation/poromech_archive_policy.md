# 水土耦合算例归档与清理

本约定覆盖编号 01–08 的根目录及 tests。00 保存已归档的开发历史，validation 保存跨算例索引。原论文和独立稿件保留。

## 按用途保留

| 类别 | 判定依据 | 处理 |
|---|---|---|
| 正式成果与运行依赖 | 当前发行入口、已确认的对照成果、正在写入的输出或被后续计算读取的数据 | 原位保留 XML/BAT、实际程序与输入、预载/重启链、原生帧、结论、PNG 与对应 CSV。运行器、读器和后处理中间文件一起保护 |
| 可复现历史 | 仍作为独立对照、回归基准、论文比较或问题复现的历史运行 | 保留一套原生来源和必要的程序/源码、输入、脚本及实测时钟。大型派生可原位无损压缩；无需在线读取的文件可校验后迁冷归档，登记原路径和恢复方法 |
| 修改节点 | 大型输出已无比较用途，但结论解释了选型、回退或变更 | 在对应 case 的 tests/notes 记源码节点、试验变量、适用范围、关键指标或首因，并链接一份有代表性的图/表和必要的末帧。以这个记录替代重复输出 |
| 可清理 | 有证据表明输出已被替代、为临时副本、可再生成，或属于已否决且后续不再使用的轨迹 | 对明确文件或帧范围建立白名单。旧失败先记原始错误及最后已保存时间，按实际需要留代表帧。保留替代件或生成入口后删除白名单内的数值和图像副本 |
| 证据待查 | 路径仍有调用方、同名内容不同、缺少可靠的复现入口或运行状态不明 | 原位保留，向用户列明路径、大小、已查到的用途及删除影响，收到明确反馈后再处置。文件日期、目录名称和进程退出码不能单独决定处置 |

重要历史数据应能恢复对照口径，包括数值格式、实际时间/步号、材料 ID、结果的快照级或统计级复现要求。源文件相同但程序、重启合同或物理参数不同时，按不同运行记录。现成对照可以从必要的 BI4 重生时，优先释放全帧 VTK、重复逐粒子 CSV、临时渲染和过时的诊断副本，保留论文出图所需的选定帧。

## 单批操作

1. 先从 Run.out、原生收据、README、脚本实参、现有所有者及最近输出核对结论和依赖。保护正式及在用文件的实际路径，包括被活动阶段间接读取的程序、预载和数据。
2. 先查已有清单和压缩状态。全量读取只在文件身份不清或确需验证迁移时使用。精确重复用一次内容校验，跨卷迁移校验归档副本后才退役原件；普通原位压缩记文件标识、大小和修改时间。
3. 给每批记录原路径、分类、原因、文件数、逻辑字节、可量化的 NTFS 节省、保留位置和恢复办法。失败保留原始收据。恢复应回到历史脚本需要的原路径，并避免覆盖现有同名数据。
4. 独立复核实际结果，按输出所属 case 汇总。卷空闲变化同时受活动计算影响；删除的逻辑字节与文件级实际节省分别列。选择性提交索引、配置、脚本、结论和必要图表，原生数据及程序按本地/冷归档记录。
