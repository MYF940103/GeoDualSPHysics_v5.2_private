# 水土耦合算例文件约定

适用于本目录及其全部子目录。整理文件不能改变物理模型，也不能将历史结果认作当前版本验收结果。

## 位置与命名

- 每个编号 case 根目录保留正式发行的 `*_Def.xml`、`x*_win64_CPU.bat` / `x*_win64_GPU.bat`、README，以及这些入口生成的正式 `*_out`。不得因为计算结束、体积大或名称含旧标签就删除或移动。
- 沿用已有目录名 `tests`、`figures`、`support`；不另建同义的 `test` 或 `figure`。
- `figures/` 保存正式图及相应的图表数据；`support/` 保存正式后处理脚本、必要输入和参考资料。
- 新试验在所属 case 的 `tests/` 内准备。按已有分类使用 `configs/`、`support/`、`outputs/`、`logs/`、`figures/`、`notes/`；只创建实际需要的目录。
- 已有 `tests/scripts/`（如 05/06）原位沿用，不为统一名称搬迁或另建重复 `support/`；新的 case 再使用上述默认命名。
- 一轮试验使用统一的简短标签连接配置、输出、日志和结论，例如 `tests/configs/tpi_dt2_Def.xml`、`tests/outputs/tpi_dt2_out/`、`tests/notes/tpi_dt2.md`。不要叠加多层日期/阶段/运行编号目录；求解器固有的 `data/`、`particles/` 子目录除外。
- 不把试验、编译日志或临时图散放到仓库根、源码根或正式 case 根。跨 case 汇总记录可放本目录 `validation/`。

## 计算时间与输出约定

- 非无量纲时间验证（如土柱塌陷、retrogressive landslide、Selborne）使用规整十进制的物理计算步长、输出间隔、总时长和事件时刻，不为二进制时钟或逐位校验专门选择 `2^-n` 秒。
- 固结、Cryer 等涉及 `Tv` 的 benchmark，按指定无量纲终点和输出间隔换算物理时间；图表同时保留实际保存时刻及对应 `Tv`。
- 步长必须满足现有力学、孔压和动态渗流稳定限制。尽量选择输出间隔、预载/撤墙等事件时刻可对应整数计算步的组合；需要解析快速瞬态时可使用更细的规整十进制输出，不强制所有阶段使用同一间隔。
- 已封存的历史时钟、输入及结果不因本约定改写或重跑。十进制时间的浮点舍入按实际时钟与既定容差检查，不通过重写元数据或新增半步长链来追求表面位一致。

## XML、BAT 和测试记录

- 先参考本 case 及邻近 01–06 case 的现有 XML/BAT，再对照仓库 `doc/xml_format/_FmtXML_ElastoplasticSoil.xml` 及相应文档。沿用命名、缩进、参数注释、单位、变量、路径及错误处理风格，不凭空另造格式。
- 每次新增或修改参数输入、默认值、有效范围、CPU/GPU支持范围或重启限制，须在同一轮同步更新 `doc/xml_format/_FmtXML_ElastoplasticSoil.xml` 及受影响的算例说明；仅说明已经实现并验证的能力，未通过验收的选项须明确标注。
- 正式 BAT 应从自身目录定位输入和程序，能完成其注明的完整计算/后处理流程；有依赖的重启阶段须在 README 写明。不要声称 BAT 会做实际上未包含的绘图步骤。
- 准备新试验前先列出将新增/修改的文件、输出位置、参数差异和验收标准，再修改。正式输入不用于临时试改。
- 保留旧结果，使用新标签；没有用户明确授权不要覆盖、重跑或删除已有正式输出。注意旧 BAT 的 `-force`、`rd` 及同名输出覆盖逻辑。
- 记录源码节点及未提交差异、程序版本/哈希、输入、命令、完成时间范围、运行耗时、误差指标和结论。正常退出不等于通过验证；中途停止、粒子大量排除、未收敛要明确标注。
- 有比较价值的结果提供对比图：探索图在 `tests/figures`，验收后的正式图在 `figures`。不要覆盖原图或混用不同程序/物理假设的结果。

## 归档和清理

- 先核对本地/远端 Git 节点和未提交文件。Git 忽略的 BI4、VTK、程序及大文件不等于已经备份；关键数据另存快照并核验。
- Git 至少保存输入、脚本、README、关键结论及必要对比图。检查 `git check-ignore`，避免测试目录规则误吞配置、图和记录；不把大量原始输出硬塞进 Git。
- 退役试验先在 README 登记用途、状态和依赖。原路径有跨 case 或脚本依赖时先原位保留，不随意移动。
- 清理只针对核实无用或可重建的具体白名单。派生文件删除前先验证再生，保留原始数据和再生命令；优先可恢复操作，记录数量、路径、大小和恢复位置。
- 正式输出、重启数据、论文原稿、独有图表、恢复 ZIP、历史原始日志及带哈希的清单默认保护。不要改写历史证据中的路径/哈希来伪造当前状态。
