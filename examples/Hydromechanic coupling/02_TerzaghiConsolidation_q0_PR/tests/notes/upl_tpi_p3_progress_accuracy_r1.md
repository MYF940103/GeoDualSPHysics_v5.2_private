# P3长算阶段精度快照

本轮用户要求核对正在计算的最新精度。新增只读Python BI4解析器及阶段脚本，读取实际Run.out已报告保存帧之前的一帧及固定Tv选择帧；输入与已有源/程序/计划不变，不调用物理求解器、C++原生全程工具或VTK，不重新哈希。

解析器的序列化格式来自本地JBinaryData实现，先对封存旧P3窗口part0和1261，与独立C++读取器保留的五个导出记录逐字节核对，包含真实时间和signed dterror，不改原1263帧头。随后读取当前全程已封口的选帧，按原ID排序检查22个typed数组、1040 IDs、原标量计划时间/Step/dt、signed必要步长、弹性、固定标记、J/n/V/rho/k和实际FS2/3排水；它不是所有帧原生、压力轮次、HG计数或全程验收。

科学口径沿用upl_tpi_m0_dt_causal_r1.py:105–144的512模态、未拟合H=1参考。P3为M0，各层按初始100×10材料网格划分，顶部/底部分别是原z0=.995/.005的10个材料ID，沉降=-1000(z-z0)。保存应力为有效应力，总应力对角项减孔压。交替X列Uz去层均值后乘[+1,-1]求均值。参考使用每帧实际t-tD，不平移、拟合或插值。

有限Kw A只读取既有完整theory.csv的最近实际保存时刻及其自身有限Kw参考误差，同时输出实际时钟差；跨模型误差比较不是5Pa half或相同物理的逐点等价门。

产品为tests/figures/upl_tpi_p3_progress_accuracy_r1.{history.csv,profiles.csv,png}及tests/logs/upl_tpi_p3_progress_accuracy_r1.json。所有路径独占创建，保留既有数据；只发布实际选帧的描述性精度，不能声称全程通过。后续正式原生读取仍消费真正终态1653帧，不由本快照代替。
