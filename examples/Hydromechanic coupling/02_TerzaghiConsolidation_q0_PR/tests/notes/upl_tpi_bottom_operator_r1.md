# C02 底层总应力超限与截面传力

P3 完整 2 Tv 的 1,653 个原始保存时刻中，32.242878 s 起有 225 帧底层总应力超过 100 Pa 误差限，终点偏差为 −110.577907 Pa。终点底面通过土粒与墙粒应力相互作用传递了 9,999.876 Pa，中部传递了 9,999.911 Pa，施加荷载为 10,000 Pa。底层材料点的应力过压和整个底面承担的合力是两个独立观测量。原严格门槛维持未通过。[完整计算与理论对照](upl_tpi_p3_full_physics_r1.md)。

## 孔压、应力与材料运动

以初始材料 ID 固定每层的 10 个土粒。触限期间底层平均孔压相对原理论的最大绝对误差为 5.099 Pa，终点仅 −0.108 Pa。底层原生外载加速度在全部 1,653 帧均为零，加载带位于顶部。显式有限 Kw 和 P3 在终点的 100 层总应力差 RMS 为 0.00886 Pa，二者的底层误差分别为 −110.563 和 −110.578 Pa。更换压力时间积分并未辨识出这里的主导误差。

根据原运行的体积模量和剪切模量，约束模量 M = K + 4G/3 = 2,692,307.83 Pa。对全部 165,300 个层均值，比较有效应力 σ′zz 与 M ln J，最大差 0.00163 Pa。终点底层孔压 91.45956 Pa，σ′zz = −10,019.11835 Pa，J = 0.996285529，σ′zz 与 M ln J 仅差 0.00031 Pa。在固定孔压下，总应力恰为 −10,000 Pa 对应 J = 0.996326449。后者只用于衡量所需应变差，未用于构造权重或修改原值。[应力与变形比较表](../figures/upl_tpi_bed_strain_r1.csv)。

直接用位置量出的终点底面至第一层中心平均伸长比为 0.995851622；第一至第二层中心为 0.996646329，同时两端原生 J 的平均值是 0.996305978。中部对应两量为 0.996299731 和 0.996299716。按各初始单元内 J 取层均值积分，底层中心实际位移相对重建值偏 −0.002170 mm，顶部偏 +0.000074 mm。区间伸长比与点值 J 的区别包含求积误差，无法凭此判定哪一项离散单独出错。它提供了优先测试近壁速度梯度、粒子运动和体积更新是否相容的独立量。

## 同一真实几何上的应力算子

读取原 BI4 的位置、J、有效应力和孔压，重算 2D Wendland 应力散度。使用实际支撑 2h、周期 x、Vᵢ = V₀Jᵢ，按动量内核先将应力分量转到 float，再以双精度累加。每个无序粒子对用同一面积向量 VᵢVⱼ∇ᵢWᵢⱼ，分配等大反向的力。截面值由所有跨面的应力对力之和除以 0.1 m 宽度获得。记录含孔压、骨架有效应力和剪应力，从保存状态离线重建；人工粘性、HG、阻尼、顶部施加载荷以及整步墙反力不在这部分应力求和内。重建用于辨别算子和几何，GPU 子步内的累加顺序会有差异。[应力算子时间史](../figures/upl_tpi_bottom_patch_r1.png)。

在原几何上赋均匀 −10 kPa 总应力时，终点底层产生虚假竖向加速度 −1.155324 m/s²，中部约 −0.000005 m/s²。反射墙的积分位置后，底层残差变成 +0.066738 m/s²；但用保存的实际非均匀应力计算，底层应力加速度反而从 −0.185410 变为 +1.044459 m/s²。在原几何给两侧矩阵取算术平均，终点床面的实际应力传力变为 10,060.306 Pa；同时反射墙积分位置，床面传力变为 10,083.705 Pa。仅凭常应力检验确定边界修改会误选方案。[100 个截面的表](../figures/upl_tpi_bottom_cut_r1.csv)；[底界面附近对比图](../figures/upl_tpi_bottom_cut_r1.png)。

## 常应力、线性场与共享对力

在初始、2 s、最后一帧通过、第一帧超限和终点这五个实际几何上，对邻底四个材料层的 40 个土粒试解几何矩条件。允许修改区域内土–土与土–墙对，每对只设一个共享标量 cᵢⱼ = cⱼᵢ。跨出这四层的全部材料对保持各自原权重。取距单位权重最近的解，同时要求每个受检土粒满足

　Σⱼ Vⱼ cᵢⱼ∇ᵢWᵢⱼ = 0，　Σⱼ Vⱼ cᵢⱼ∇ᵢWᵢⱼ(xⱼ−xᵢ)ᵀ = I。

每帧 200 个独立约束均满秩，终点有 760 个可变边。权重由几何和粒子体积独立决定。五个几何都得到正权重，求解没有施加正值限制。终点原始体内权重方案下，校正后近壁 40 点的均匀应力最大加速度为 2.15×10⁻¹³ m/s²，线性矩最大偏差为 4.45×10⁻¹⁶，局部范围之外全部土粒的均匀场重建加速度逐值相同。

对近壁区域求和，内部对力抵消。若常应力在各土粒上的净加速度为零，则床面传力必须等于该区域上边缘的跨面传力。原几何、原体内权重的终点上边缘均匀场传力只有 9,954.818 Pa。仅调整区域内边，无法同时把床面均匀场传力提到 10,000 Pa，又保持所有土粒零加速度和外侧边不变。表中第三组用终点中部几何一阶矩的倒数 1.00452843 归一所有体内面积，因此改变了中部实际应力传力。

用同一面积构造力与速度梯度的离散伴随，在非仿射试验速度和实际保存应力上独立组装，五个几何的功差除以无符号成对功的最大值为 3.91×10⁻¹⁶。这个检查包含虚拟墙侧速度梯度的功；实际固壁本构、HG 与流体能量仍须在联算时核验。[矩约束求解](../figures/upl_tpi_bed_pair_moments_r1.csv)；[实际非均匀应力回放](../figures/upl_tpi_bed_pair_replay_r1.csv)。

## 取舍及后续判据

采用以上权重单改动量会恶化已保存非均匀应力的传力，暂不采用。值得做的小窗应先在实际近壁几何上，用独立给定的微小法向仿射速度场同时检验 SPR 应变率、J 更新以及相同粒子位移产生的区间伸长；同时检查一个深部对照层和自由表面加载带。再用配对的力与形变算子测试制造的弹性平衡，记录载荷、墙反力、HG/粘性和速度修正各自的功。此先导测试无需从零再跑一个完整固结周期。若要说明原应力误差得到修复，需耦合轨迹覆盖旧首次超限和后续衰减，对全部原始层重新检查 100 Pa、理论孔压和顶底沉降等既有条件。简单从初态跑到 2 s 尚未进入原失败区间。

本检查限平面固定底壁、均匀周期柱、上述保存几何及按材料 ID 定义的截面。层号是分析选区。对一般墙体，应按接触面、邻域和边界速度条件定义约束，并单独验证墙面功与三维精度。
