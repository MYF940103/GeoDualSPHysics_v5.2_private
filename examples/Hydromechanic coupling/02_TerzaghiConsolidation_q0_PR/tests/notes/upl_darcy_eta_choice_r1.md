# Darcy 二阶分母取舍

本轮保留生产的成对对称校正矩阵、Taylor 一阶缺陷消除和 `r2+Eta2` 分母；不增加完整 Hessian 存储或新的 XML 选择项。生产源码、正式输入及 C08 服务器运行包未改变。

去掉的候选仅限 Darcy 权重的 Eta2，不能将全局 Eta2 归零。Cubic/Wendland 的梯度可写为 `Fac(r)*r`，Fac 在正距离趋零时有有限极限；有限 C 下 `r·(Ci+Cj)gradW/r2` 有界。实际实现仍须保留 `r2<ALMOSTZERO` 过滤，不能直接调用零距离的核函数。该分母不负责修复 C 的病态或退化邻域。

已有 C08 小变形快照的内点 P2/光滑场显示去 Eta 的标量迹误差收益，但不是实际孔压精度。此次新增两个真实 `ComputeStep_Sym` 短窗：同一 32x16 周期晶格、512 材料 ID、512 更新、257 保存时刻；初始26字段和全部时钟精确相同。两组保持全局 Eta2 和全部原单组安全门，未增加 half、GPU 矩阵或物理长算。

独立未拟合连续弱扰动 4x4 矩阵指数参考与 helper 的连续 RK4 参考，压力最大差 1.251e-12 Pa。所有保存场的最大孔压 RMS 误差为 baseline 7.516032734 Pa、Darcy-Eta0 8.236720444 Pa，增加9.58867%；末时刻压力模态幅值误差1.47158%/1.61268%。位移和速度误差略增，sigma_xx 最大 RMS 误差6.70303/6.68425 Pa略降，不能声称所有量都变差或 Eta0 普遍更差。

结论是没有足够的整套耦合收益支持当前替换；部分空间制造场收益不应直接外推到耦合结果。本轮不再扩展候选求解链。强失序、真实自由面、混合墙和变 k 的物理效果仍只能由相应算例评价。

原始与分析凭据：`logs/upl_darcy_eta_wave_r1*.json`、`logs/upl_darcy_eta_wave_review_r1.review.json`；图和完整257时刻数据：`figures/upl_darcy_eta_wave_review_r1.png`、同名CSV及 `_fields.csv`。图已由根线程实际查看，误差面板以Pa显示，原分析收据的待目视字段保留不改，另存目视记录。
