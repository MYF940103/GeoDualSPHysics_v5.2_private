# Independent public CPU stage audit

Scope: all nine prepared canonical jobs, three actual coarse/half pairs, eleven invalid-input guards, and the current 140-pair default-OFF regression. This is implementation/output/rejection evidence, not general u-pl or formal physical acceptance.

Run the offline audit once from `tests` with `py -3 support/upl_cpu_public_independent_r1.py`. It invokes no compiler, solver, reader executable or Git command. It reads only retained source snapshots, receipts and analysis/native output identities, then creates `logs/upl_cpu_public_independent_r1.check.json` without overwriting anything. Thresholds remain the original 5 Pa / .005 mm and normalized 1e-4 half limits.

Identity follows the build lifecycle: current seven source/document files, programs, runtime, inputs and logs are checked against public Rebuild r3; prebuild programs are checked at their sealed snapshot paths, because their old canonical paths were intentionally replaced by that Rebuild. The isolated canonical programs/readers are the successful `_r2` builds. Solver/native-review job labels remain `_r1`; the failed first reader compilation is not admitted as a successful build.

The Python audit independently decodes the original15 typed analysis binaries and all actual 26-field dynamic trajectories, verifies material IDs, clocks/steps and shared physical fields, recalculates full XYZ half errors, six-component stress energy and J-derived n/rho/volume/k summaries and necessary scales. It does not implement a second native BI4 parser: direct BI4 metadata/types and saved derived-array equality remain the frozen reader's checks, bound to actual complete outputs. This distinction must remain explicit.

Each invalid run must have an owned nonzero exit, its complete exact diagnostic, no native PART frame and unchanged identities. An earlier XML parser rejection is not credited to the intended finite-value guard. The eleven cases do not cover the three pending genuine-PART rejection tests.

Limits: weak elastic 2-D fresh CPU windows, zero gravity, either rectangular XZ periodicity or the admitted opposing static FreeSlip planes. Theta is last-stage data. Signed dterror is not an absolute clock residual. Saved-field energy and necessary local scales are not sufficient spectral stability. No wall flux/reaction reacceptance, new private-control proof, general boundary/GPU/plasticity/PART-restart or full formal physical claim is made by this audit.

Quantified results are recorded only in the new check JSON after successful execution; original results and all failed historical evidence remain untouched.
