# Honest full-scope P3 short native/read-review adapter (author only)

New support/upl_tpi_p3_full_short_native_r1.py and this note are independent
author assets. No reader, solver, build, analysis, context or main has run while
authoring. `read` and `review` require separate root admissions; neither launches
the next action or job. No frozen runner, source, old native or receipt is edited.

This wrapper binds actual new full-short stage upl_tpi_p3_full_short_r1.run and
actual new full source/build through runmod.source_build. It never invokes old
P3 get_job/context/main/review, nor renames an old run to a new stage. The three
fixed profiles are CPU Debug B200/18, GPU Debug B2/2 with memcheck, GPU Release
default A320/18. New tags and original P3 controls are the exact six-tuples in
the frozen full-short runner. Old controls already have passed original P3 run
and independent native read/review receipts; fresh inputs/plans match them.

Before any read, get_job checks actual original root admission/job/build stat,
new source preparation, program/runtime/seed/plan, reference run/native binding,
actual Popen+Win32 owner exits, target/tool exe/argv/creation and pre-wait handles,
complete selector environment, Run.out/CSV and unchanged runtime gates. It calls
only the original context-parameter check_output, not a hardcoded identity
function. CPU thread count, GPU memcheck zero errors and genuine once-only16
fixture remain required. Runtime TimeMax remains each original short input's
value; this adapter does not use the new full TimeMax or create another seed.

Scalar clocks are independently accumulated with `clock[-1]+dt`; actual rows
retain all eight columns and exact saved step/time/dt. The existing m0.WINDOWS
profile is selected by the actual original mode and its end is the independently
computed real end, never n*dt. All three profiles have zero post-open frames;
they do not validate the event or nonempty drainage. A uses drain step1600 and
B uses1000, exactly as their existing reader profiles declare.

The original already-built M0 reader is reused without recompilation. Its exact
build/program/dependency identity is checked by the existing strict identity-root
adapter; the lower m0.read_native is then called only with the honest new job.
Its existing active-reader/fresh-directory/call/log guards and actual owned exits
remain in force. It reads original BI4 once and checks the complete22 typed
arrays,1040 IDs, actual clocks/Step/dt/signed intervals, P0/J/n/rho/V/k ledger,
fixed markers, finite elastic fields, drainage and original geometry. No guard,
schema, source field or tolerance is removed. No new raw read implementation is
introduced and no old data is overwritten or decoded again.

Read receipt: logs/<newtag>.native_full_short_r1.json, stage
upl_tpi_p3_full_short_native_r1.read. Native directory:
outputs/<newtag>_native_full_short_r1. The real delegated reader call/log retain
their honest existing <newtag>.native_m0_r1 names. `completion.json` retains the
reader's actual upl_tpi_m0_dt_native_r1 stage and CPU_M0_private/GPU_M0_private
labels; these are implementation identity, not a claim that the solver was M0
one-row or old P3. Existing output, call, log or read receipt is never reused.

Review checks that exact completed new read, its new-run binding and actual
reader exits. It directly reuses original P3 `intervals(ad,job)` and
`pressure(ad,job)` pure numerical functions with unchanged32/23-column helpers.
The full-scope preparation proves those helper bytes unchanged. There is no
mutation of globals or fabricated old identity. They preserve five force phases,
native signed dterror bit arithmetic and initial sentinel distinction, three
complete residual rounds, actual q2=p1/q3=p2 after BC, original RN/GPU signed
FTZ/J-expression alternatives, all IDs and old safety. Native PorePressRate
remains scaled R3 at actual p2, not dp/dt or residual at p3. A requires absence
of prototype outputs. Original physical HG2N/N/N and its tau/spin/domain gates
are checked independently from each actual new Run.out.

The implementation comparison consumes the genuine old P3 read and qualified
review for the same exact mode/configuration/scheme, with the same frozen plan.
Both declarations remain unchanged. Five series original15.bin, physical.bin,
common_j_theta.bin, soil_n.bin and clock.bin compare all actual records byte by
byte, including all initial/noninitial signed clock bytes and the forced final.
CPU/A have18 records, GPU Debug2 has2. native_ids.csv, fixed_ids.csv and
columns.csv are independently byte-equal too. For B, actual pressure policy,
summary, each one/three pressure CSVs and five-phase dt policy/CSV/summary are
also compared in bounded chunks without SHA. Parsed actual HG runtime summaries
must match their old control. No interpolation, fitted correction or extra ULP /
absolute tolerance is added.

These comparisons are five-export evidence, not proof that all22 raw arrays or
hidden HG history are cross-run bit-identical. All22 original reader guards are
independently checked, and the existing P3 endpoints validate their hidden HG
readonly contract, but these are distinct claims. There is no new ReleaseCPU
runtime test and no GPU Release B short equivalence test. No physical/theory /
full-cycle acceptance follows from short regression success.

Review receipt: logs/<newtag>.native_review_full_short_r1.json, stage
upl_tpi_p3_full_short_native_r1.review, passed, actual job (with run_receipt),
native_read_receipt, completion, HG_original_guards, method_intervals,
pressure_three_rounds, comparison and consumed stat checks. This matches the
frozen full-short runner's separate prerequisite and summary contract.

```text
D:/anaconda3/python.exe -B tests/support/upl_tpi_p3_full_short_native_r1.py read --admission ROOT_READ_JSON --execution-authorized
D:/anaconda3/python.exe -B tests/support/upl_tpi_p3_full_short_native_r1.py review --admission ROOT_REVIEW_JSON --execution-authorized
```

Each separate admission stage is upl_tpi_p3_full_short_native_r1.<read|review>_
admission, passed=true, action_only=true, job.tag exact, inputs unique stat list.
Inputs include this script/note, frozen full-short runner/note and original
P3/CPU/GPU/M0 owner modules, P3 numerical reviewer/note, M0 reader author/CPP/note
and actual strict identity-root/build/program/calls/dependencies, new actual
run/start/call/root admission/source/build/program/runtime/seed/plan/log and
Run.out/CSV, original control run/native read/review/reader call and its exports,
and any B pressure/dt products. Review also pins the new read receipt, actual
reader call, all new native products and same-clock old exports. Read additionally
pins psutil and checks active reader identity. Input metadata are path/size/mtime;
SHA scans, builds, physical solvers, VTK, Git and queues are all zero. Failures
preserve original first error/partials and never retry a completed read or solver.
