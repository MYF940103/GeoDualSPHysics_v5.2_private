## 孔压、沉降与历史的关系

本轮CPU各Tv剖面RMSE：0.1/0.2/0.4/0.5/0.7/1/1.5/2分别为11.1906/8.2648/6.9142/6.7451/6.1110/4.5397/2.1662/0.8833 Pa；GPU相近。Tv>1仍继续衰减，未出现旧float卡平台。补充对比采用对数孔压轴，避免线性大范围掩盖晚期平台，并明确历史载荷/梯度/阻尼/边界不同；这是Data Visualization审图对本轮图的实际影响。

保留历史float末时72.87429 s平均孔压536.976 Pa、顶部沉降4.293816 mm、剖面RMSE524.144 Pa；本轮相对这套历史组合明显改善，但不能归因于某一个开关。旧HG完整2Tv沉降3.690437 mm，而本轮3.658754 mm，绝对误差量级相近，只是由偏大转为偏小，不声称又提高一个数量级。旧NoHG只到55.8 s，不冒充完整2Tv对照。

Q仍从早期最低值缓慢增到约10 Pa，总应力残差约50.5 Pa；不能宣称所有局部模式消失。沿用用户已接受的一维工程精度范围，不因此恢复KEEP或无限延期交付。适用范围仍为弹性、小转动、固定平面、新鲜HG历史、xi=.1、阻尼=.04；无精确HG重启、塑性、大旋转或复杂墙角/曲面/NoPen验收。
