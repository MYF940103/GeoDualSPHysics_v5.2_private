# X0 saved-history offline arithmetic review

Author-only `support/upl_tpi_x0_history_review_r1.py`; do not run before root full review and separate offline admission. It imports only Python standard modules and NumPy, not project helpers. No solver, native reader, build, VTK, Git, subprocess or SHA operation is included. Inputs are the eventual passed ReleaseON `outputs/upl_tpi_x0_short_r2_on/{C02TpiX0.csv,C02TpiX0.summary.json,native_r1/...}` and the existing closed151-save plan. Failed or incomplete physical/native input is not repaired or rerun by this script.

The script reuses the unique native check's actual run/completion and stat-bound physical/clock/native-ID files plus its consumed clock plan. It does not repeat the full raw BI4 or22-array scan. The sidecar CSV/summary receive their first explicit stat seal here; that seal is not misreported as historical solver-receipt binding. Inputs are checked again once after the read. Output paths are fresh/exclusive: `figures/upl_tpi_x0_history_review_r1_summary.csv` (151 small rows) and `logs/upl_tpi_x0_history_review_r1.check.json`. Existing complete/partial outputs reject.

Coverage is exactly151000 sidecar rows ×25 original columns, in part/native-ID order0..150 and40..1039. Each row is matched to its actual native pressure, J and last endpoint theta; these three comparisons use binary64 bits after the original17-digit decimal roundtrip. The closed plan and actual clock export must agree. Source clocks are independently obtained by scalar `time += 5e-6` through30000 updates, not n*dt; every noninitial sidecar sourceTime+dt must equal the actual saved time, source step must be completed−1, and original internal pre/corr/J/endpoint/commit counters must all finish at30000.

Initial rows retain cold zero pressure and explicitly blank S/R cells. Noninitial unconstrained rows require finite S>0 and R; true Dirichlet rows keep S=R=0 and pressure0 with no division. The script recalculates history extrapolation as `float32(pn+.5*(pn-previous))` and the endpoint row as `float32(guess+Rgamma/S)`, retaining original float rounding and drainage priority. Completed step2000 remains pre-open under the original source-n event; the actual151-save schedule does **not** save that event step, so the report cannot claim an observed native step2000. Native FS2/3 and the saved source-clock predicate determine the saved receiver mask. This qualified one-dimensional column retains its tracked drainage membership; the sidecar does not separately save half-state FSType, so half-state mask provenance remains the unchanged internal boundary branch rather than an independently exported half-state field. The report states this limitation.

J_full must equal actual native J exactly. The independently supplied sidecar J_n, J_half and theta_h are reconciled using the original source order `(dt*Jhalf)*theta_h`, then addition to J_n. A small arithmetic bound of `4*binary64_epsilon*(abs(Jn)+abs(term))` permits operation contraction/rounding differences across MSVC and NumPy; it is not a physical tolerance and never substitutes for the exact native J comparison. The endpoint theta is checked against native last-stage theta but is never used as J's integration source.

External coverage consists of151 saved pressure histories. It cannot prove all30000 intermediate prior-step identities from those sparse saves; that part relies on the actual internal ID-key lifecycle checks/counters and the separately reviewed frozen code. No synthetic adjacent history, interpolation, rewritten clock, GB sidecar, full2Tv/physical/restart acceptance, or0ULP/5Pa equivalence with the finite-Kw model is claimed.
