# CPU Vel0 孔压状态迁移：短程比较口径

日期：2026-09-09。范围：先完成正式 Vel0 边界的四组 CPU 短算例与步长敏感性比较；不修改正式求解器、不继续扩大 double 范围、不运行完整 2Tv。

## 试验

- 高低位补丁基线 / 当前 double 状态，各运行 dt = 10 / 5 us，0--0.2 s，4 个 CPU 线程，输出间隔 1 ms。
- 使用正式 full_k1em4 的输入几何及物理参数，Vel0 (`-mdbc`)，不采用前次短测的 NoSlip。派生配置只更改时间控制，去除原输出时序覆盖块。
- 旧孔压重构为 double(high) + double(residual)；新孔压直接读取原生 double。压力、坐标均从 BI4 读取，不以 VTK float 位置比较微小沉降。
- 正式配置 SavePosDouble=0；四组保持同一 CLI `-svextraparts:1`，按 JSph.cpp 的输出分支，Part>0 均保存 double 位置，Part0 为 float。原生读取逐帧核验类型；初始位置采用相同保存原点，绝对沉降有初始 float 输出的共同偏移，版本/步长间沉降差会抵消该偏移。不额外更改输出开关或重跑首组。
- 每帧核验 1040 个唯一 ID，40--1039 为 1000 个土粒子。以 t=0 最大 z 所在层固定 ID 集合计算沉降：mean(z_initial-z_current)，正值向下。
- 同 dt 的新旧比较为迁移差异；同版本的 dt/2 与 dt 比较为步长敏感性。按实际时间与 ID 对齐，记录时间偏差，不将步长差或有限 Kw 结果称为真值。
- 若两步长的输出时刻相差一个步点，步长比较只选实际时间误差 <= 1e-11 s 的共同样本（浮点累计容差，不允许 5 us 错位），报告未配对数量与覆盖时间；不做隐式插值。迁移与步长幅度比仅在同一个共同样本集合上计算，完整迁移结果另保留。
- 统计范围预先分为加载 [0,0.01] s、早期排水 (0.01,0.03] s、后续 (0.03,0.2] s；同时报告全程与终点，避免只选择差异较小的时段。
- 继续展示前次压力审查线（全时空 RMS 0.01 Pa、最大 0.1 Pa）的通过情况；这不是物理正确性标准。未通过不能改写为严格迁移验收通过。
