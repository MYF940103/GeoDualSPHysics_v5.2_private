# C02 固定底壁的变形率与上下半胞

完整 P3 轨迹的底层总应力终点偏差为 −110.57791 Pa。用真实粒子几何做制造场检验后，原近壁路径可以恢复均匀切向速度和线性法向变形，但对满足底壁不穿透的二次法向场存在误差。改用低成本的壁面约束二次拟合能消除制造场误差，实际粒子速度却显示床侧和上侧两段的改善方向不同。这次不采纳仅替换底层速度导数的方案。

## 按实际运行重建

选择 26 个实际保存时刻，覆盖表面加载、开始排水、2 s、原门槛首次超限前后和终点。该柱只承受顶部压载。实际 `CfgInit_Normals.vtk` 和 `CfgInit_NormalsGhost.vtk` 的 40 个固定 ID 均与 Part_0000 对齐，底壁 z=0，墙法向为 +z，虚点偏移矢量为边界粒子到平面矢量的两倍。所有受检时刻距离虚点最近的土粒 ID 均与初始对应一致。终点 40 个镜像虚点各有 24 至 41 个土粒参与核拟合。[逐墙 ID 与虚点位置](../figures/upl_tpi_bed_rate_r1_ids.csv)。

冻结来源为 `tests/outputs/upl_tpi_p3_full_GPU_r1_source/JSphGpuSingle.cpp` 和 `JSphGpu_ker.cu`。力循环先准备一般 SPR，随后动态墙的 `KerDynamicPoreWall<0>` 根据当前 V₀J、镜像点的 Wendland 加权矩和最近实际土粒，重构该处的速度。固定 FreeSlip 墙反转法向，保留切向。土粒的压力压缩项、J 更新及骨架应力率均读取此导数速度，后二者都采用本地一阶矩逆。`KerUpdatePorosityObserver` 在预测使用 Jₙ，在校正使用 Jₕ，更新为 Jₙ + Δt J_stage θ_stage。这里用实际周期坐标、相同邻域和保存的粒子体积，独立以双精度评估几何算子；受检 26 帧底层实际速度重算的 θ 与保存的最后力阶段 θ 最大差为 1.70×10⁻¹¹ s⁻¹。逐力阶段 GPU 场及其累加顺序未保存。

制造场使用恒定切向平移、法向 v_z=z 和 v_z=z²，相应系数分别以 s⁻¹ 和 m⁻¹s⁻¹ 计。前两式满足固定平面 FreeSlip，法向均满足 v_z(0)=0。二次场仅要求墙面法向速度为零，曲率没有被人为设为零。候选用同一 2h 支撑内的真实土邻居、W V 加权及已知 v_z(0)=0，拟合 v_z=az+bz²；只修改距墙小于 2h 的法向导数，x 方向保持原路径。该候选针对 1D 固结运动，在冻结几何上无参数拟合至已知压力或应力。[制造场逐层结果](../figures/upl_tpi_bed_rate_r1_manufactured.csv)。

## 保存轨迹中的体积与应力

下半胞从固定床面到第一材料层中心，上半胞从第一层中心到第一、二层中心的随体中点。上界位移、速度均由相邻两个材料中心等权定义。因此上半胞速度差商也等于两个中心之间的速度差商。底层原生 J 是点值，有限半胞的长度比是区间均值。终点下、上半胞的长度比分别为 0.995851622 和 0.996646329，两者按初始长度平均得到整个对偶胞 J_cell=0.996248976。原生 J=0.996285529。[全部保存时刻的几何、孔压与应力分解](../figures/upl_tpi_bed_cell_r1.csv)。

以 M=K+4G/3、p* 为原有理论底层孔压、q₀=10,000 Pa，以张为正，终点差值可直接按观测量相加。该分解用于定位数值量级，各项之间存在动力学相关性。

| 原阈值检查中的分量 | Pa |
|---|---:|
| 几何半胞对应的有效应力减理论有效应力，M ln J_cell − (p*−q₀) | −209.46708 |
| 点 J 与半胞几何应变对应的差，M ln J − M ln J_cell | +98.78135 |
| 本构写回与点 J，σ′zz − M ln J | +0.00031 |
| 理论减原生孔压，p*−p | +0.10751 |
| **材料点总应力加原载荷** | **−110.57791** |

因此直接用半胞长度比替换 J，会使同一终点状态的应力误差变大。下半胞和上半胞的实际伸长率在终点分别为 +1.159×10⁻⁷ 和 −4.308×10⁻⁶ s⁻¹。原近壁路径的底层点值为 −2.303×10⁻⁶ s⁻¹，二次候选为 −1.913×10⁻⁶ s⁻¹。用同一线性导数求积比较这些层间变化，在本次 32 s 后所选实际样本上，下半胞残差的按时间加权 RMS 从 4.115×10⁻⁶ 降至 3.248×10⁻⁶ s⁻¹，上方两个中心之间反而从 3.226×10⁻⁶ 升至 3.692×10⁻⁶ s⁻¹。上述 RMS 来源于实际采样间隔的梯形求积；它们衡量速度与有限间距的相容性，不是解析误差。[26 个实际瞬态](../figures/upl_tpi_bed_rate_r1_actual.csv)。

采用全部 1,653 帧的原生 θ 按实际保存时间作梯形积分，与终点 ln J 变化之差折算为 −5.093 Pa；用原生材料速度对独立材料半胞变形率积分，对应差为 −11.048 Pa。从首次超限到终点的 225 帧，这两个差分别为 −0.051 和 −1.304 Pa。原完整记录有 7,288,262 个更新，保存间隔最长 0.182194 s；隔四帧做积分时全程符号还会变化。这些是对独立量级的检验，无法从 1,653 个保存时刻精确还原预测、校正两个力阶段，更不能据此将 5.093 Pa 归为求解器时间截断误差。[实际时钟积分表](../figures/upl_tpi_bed_cell_r1_quadrature.csv)。

## 决策

几何共享权的动量试算表明实际底面能够传递近乎全部外载。单独改动成对力会恶化保存状态的总传力。单独改动速度导数对真实上下两侧也没有一致的收益；对平坦墙的解析二次速度场取得精确值不足以启动新的全程试算。能改变这个决策的证据，是同一套力和速度导数在独立的近壁弹性变形基准中既保留成对功，又同时降低上下半胞误差、维持实际传力。在这个前提成立后才值得进入包含旧超限窗口的耦合轨迹，仍按原始 100 Pa、孔压与沉降条件验收。[成对力与截面传力](upl_tpi_bottom_operator_r1.md)。

复现入口为[制造场与速度回放](../support/upl_tpi_bed_rate_r1.py)和[原生体积与几何积分](../support/upl_tpi_bed_cell_r1.py)。均使用原始结果且保留初始和末帧；测试没有改动求解器或 XML。
