# u-pl 私有 GPU 固定墙阶段

2026-11-02；基线 `038f569d1d9b4ed6e124e99cf84a3268a30b5bfb`。通过的是二维、零重力、小振幅弹性、对向 x 轴 FreeSlip 固定墙、z 周期的内部开发入口，不是一般边界或正式物理算例验收。公共 GPU XML 入口仍被拒绝，默认 u-pw 与服务器程序未替换。

## 源码改动与目的

- `JSphGpu.h`：默认 false 的内部墙标志和小型函数声明，无独立 n/k 状态。
- `JSphGpu.cpp`：检查限定墙几何，调用最近粒子锚定的 V0J 一阶镜像重构，分别处理状态、矫正矩阵、已完成的加速度。只在该私有路径跳过原 mDBC，复用导数速度临时池。
- `JSphGpuSingle.cpp`：初始化墙几何，按同阶段依赖安排墙状态、自由表面/C、周期 C、墙 C、全部内力、周期 Ace/theta、墙 Ace、完整孔压率，不改预测/校正公式。
- `JSphGpu_ker.h/.cu`：相应重构核和完整率中的真实固定邻居。FreeSlip 使用 Qv、Q sigma Q、Q C Q 和 Q Ace；固定粒子物理速度仍为零。两个本轮邻居循环增加空范围检查，非空求和顺序不变。
- 同步 XML 指导文件与 `validation/upl_current_status.json` 的验证范围，未新增公开参数。

GPU 原生保存 J/n/最后力阶段 theta，V/rho/k 由保存的 J 派生。CPU 的原生 V/rho/k、PosDiv、固定墙零 marker 与 GPU 固定样本 n 不能混作相同材料量。孔压/孔压率 float、应力 double 和 CPU rational/GPU additive 的旧被动密度积分均未改动。

## 结果

默认 CPU Debug 与隔离的权威 GPU Debug/Release 全量 Rebuild 通过。真实墙组件检查锚点、同点/离点线性再现、矩阵/加速度反射及周期所有者。Debug 组件、两步实际积分和独立端点审计均 memcheck 0 错误、0 泄漏。

无墙旧入口 7 组共 557 帧原 15 数组及实际 time/Step/signed dterror 精确；完整率常/变 k 5 组共 1031 个 33 列帧精确。这不是所有正式 mDBC 算例的默认 OFF 回归。

新运行 7 组 GPU，共 1065 帧；1024 土粒子、256 固定粒子。4 组旧 CPU 控制只重读，没有重算。完整短窗为 2^-15 s、257 个实际匹配保存时刻，是制造弱波问题，不是固结 2Tv。

原 5 Pa/.005 mm 及独立半步 p/v/u 归一化 1e-4 门槛均不变。常 k 的全域、固定初始材料近墙带及终点弱波参考目标均在 1% 内；GPU 终点孔压模态误差为 -0.259892%/-0.259911%。不能把常系数解析参考套给变 k。

制造参数 Ck=2^-13 产生约 5.8695% 的 k 空间跨度；常/变 k 的同 GPU 孔压效应约 0.0232807/0.0233363 Pa，超过 max(.001 Pa,10 倍本组半步差)。这是已分辨的模型效应，不是材料标定或精度提升。

全部 1065 个保存状态另作一次端点力/孔压率重算，共 1090560 个率记录和 2130 个物理面记录，满足原率、法向速度/通量和反力预算，正 k 的错误 Ace 对照非空。端点重算不推进时间，不是 PART restart 或所有原始预测/校正阶段观测。保存的最后阶段 theta 与重算端点 theta 明确分列。

图及匹配 CSV 在 `tests/figures/upl_gpu_wall_*`；全部绑定见 `logs/upl_gpu_wall_stage_r1.check.json`。原 BI4、程序、大体积逐点审计保留本地并绑定哈希，不声称随 Git 云端备份。

## 保留的失败与后续

Debug 组件首轮命令行覆盖 FreeSlip，初始化拒绝；完成的 r2 未重跑。后续离线包装修复 PowerShell 数组优先级和 JSON 数字转字符串精度问题，未改物理场、公式或门槛；失败记录保留。

选择性本地/远端备份后，进入有限公共 GPU 主开关接线、输出契约、真实 mDBC 默认 OFF 精确回归及不支持输入/PART 拒绝测试。重力、外载、排水、一般墙/NoSlip、三维、塑性、TPI 和正式长程仍各自准入，不由本轮短窗自动开放。
