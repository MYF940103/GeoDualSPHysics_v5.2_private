# C02 P3 完整固结诊断（2 Tv）

2026-11-19，GPU P3（M0，三轮端点压力更新）完整方法及原生检查通过后，从既有导出独立计算全部 1,653 帧、100 层、1,000 个原始土体材料点。十个预定时刻的孔压、顶部和底部材料沉降均达到相对 A 的精度目标。底层总应力超出原定 100 Pa 限值，严格物理验收未通过。

| 终点指标 | GPU P3 | CPU 显式有限 Kw，A | 旧 GPU u-pw |
|---|---:|---:|---:|
| 100 层孔压剖面 RMS 误差（Pa） | 0.414432 | 0.570510 | 0.881094 |
| 顶部材料沉降（mm） | 3.684117 | 3.683854 | 3.658754 |
| 顶部材料沉降有符号误差（mm） | +0.010055 | +0.010137 | −0.015309 |
| 底部材料沉降有符号误差（mm） | +0.002341 | +0.002341 | +0.000927 |
| 最大层总应力偏差（Pa） | 110.577907 | 110.562937 | 50.535351 |
| 相邻层总应力二阶差分 RMS，Q（Pa） | 18.882898 | 18.878322 | 10.108110 |

P3 与旧 u-pw 的误差对照各自实际时刻的经典 H=1 理论，A 对照其有限 Kw 理论。A 与 P3 共用 FreeSlip、当前材料坐标和外载带，步长和后端不同。旧 u-pw 使用 Vel0，此外加载实施与排水时钟有差别。十个标称时间因子的完整误差与匹配时刻见 [targets.csv](../../figures/upl_tpi_p3_full_diagnostic_r1/targets.csv)。例如 Tv=0.005 时，P3 与 A 的层平均孔压 RMS 为 114.641 和 114.615 Pa，顶部沉降误差为 +0.022543 和 +0.019980 mm。理论采用未拟合的 512 模态解，忽略有限加载时长、分布加载带、惯性等影响。按固定材料 ID 计算顶底沉降，两层初始中心高度分别为 0.995 m 与 0.005 m。

全部 201 个实际 Tv≥1 的保存时刻均值与底层孔压逐帧下降。终点平均孔压 57.932365 Pa，对应理论 58.295801 Pa；底层孔压 91.459560 Pa，对应理论 91.567065 Pa。十目标主指标为 100 个材料层的均值 RMS。终点 1,000 个原始粒子各自对所在层参考的 RMS 为 0.414432 Pa。应力统计采用张力取正、总应力 σ=σ′−pI 的约定。全程交替 X 列竖向位移最大幅值为 1.552×10⁻⁷ mm。

在 t≥0.1 s 的 1,364 帧中，225 帧超限，均为最底材料层。32.060694 s 是此前最后一帧通过值，32.242878 s 首次保存到超限，至终点 72.884288 s 持续超限，覆盖 40.641410 s 的可观测跨度。最大 110.577907 Pa 出现在终点。顶部两层应力差的全窗最大值为 8.344287 Pa。旧 A 的同一门槛在 226 帧超限并达到 110.5755 Pa。这种共同表现把近底端的空间离散与边界列为后续归因方向，现有证据不能区分应力导数、边界或载荷各自的贡献。

P3 在 RTX 3050 的 7,288,262 步用时 148,738.234 s，A 在 CPU 单核的 11,661,219 步用时 148,603.906 s（均取求解器主循环）。步数减少 37.5%，实测整段用时相近（P3 多 0.0904%），硬件、方法和诊断开销均有差别，算法自身的加速比仍待受控比较。

### 终点底部应力对照

从 P3 的原生 `physical.bin` 取 100 层的竖向总应力 `sigma_zz - PorePress`，按初始材料层与 A 的 `full_validation_upl_CPU1_r1_final_stress.csv` 对齐。两组终点实际时差 1.259 µs。两组最底层有符号偏差分别为 −110.578 与 −110.563 Pa，其余 99 层的最大绝对偏差为 59.382 与 59.372 Pa。两组 100 层有符号偏差剖面之间的 RMS 差为 0.00886 Pa，单层最大差为 0.05630 Pa。底部超限在更换后端、时间方案及步长后仍高度一致。区分边界速度重构、近壁应力导数与加载离散各自的贡献，需要独立的空间算子证据。
