# CPU 动态渗流公开入口：有限范围阶段记录

本阶段基线 `d8bdcef8b3cf723f954769c598d2dbb2fa19f714`。这是实际 CPU 程序的 XML 接线、输出和拒绝行为检查，不是正式 u-pl 物理发行验收。正式 case 输入、历史输出及服务器程序没有改动。

## 修改在哪里、为什么修改

| 文件／位置 | 本轮目的 |
| --- | --- |
| `JSph.h`、`JSph.cpp`：初始化、`InitSoilParameters`、`LoadConfig`、`SavePartData` | 增加默认关闭的 `HydroMechDynamicSeepage`；同一入口完整启用已验证的 J／孔隙率／体积／惯性／动态 Darcy 分支。读取常 k／变 k 选择及显式 Ck，记录 ON 模型元数据。 |
| `JSphCpuSingle.cpp::LoadConfig`、`SaveData` | 分配前映射内部开关；按实际保存粒子顺序输出 J、n、末阶段 theta、PosDiv 和由 J 派生的 V／混合密度／k。不是新增一套 k 积分状态。 |
| `JSphCpu.cpp::InitDynamicPoreWallCpu`、`JSphCpu.h` | 公开实验墙面只允许两个相对的静止轴向 FreeSlip 平面及切向周期；澄清内部变量含义。本轮不重写已经测试的压力率方程。 |
| `JPartsLoad4.cpp::LoadParticles` | 逐片拒绝带 J 数组或模型标签的 PART，即使开关关闭或标签值为 false，也不能静默丢掉状态。未实现跨模型续算。 |
| `doc/xml_format/_FmtXML_ElastoplasticSoil.xml` | 同步默认值、单位、经验关系、输出、适用范围和限制。测试后的状态文字与构建时快照分开记录；六份源码不变。 |

默认仍为原 u-pw；孔压及孔压率仍为 float，应力沿用此前 double 状态，新增 J 为 double。变 k 使用 Lian2023 Eq4 的指数关系，Ck 无量纲且需要材料标定；本次 `2^-13` 只是制造测试参数。

## 实际完成的检查

- 权威 CPU Debug／Release 全量 Rebuild r3 通过。旧程序、失败读取器编译及各次源快照原位保留。
- 最新默认 OFF 回归：140 对原生帧、1040 IDs、原15数组和时钟／步号／dterror 全部逐位一致。
- 9 个实际程序任务共1563帧，约132万条动态土粒子记录；独立复核2462项绑定无差异。两项额外 OFF 任务的9帧数据与历史在“省略／显式关闭”间完全一致。
- 三个完整257帧短窗：周期常 k、墙面常 k、墙面变 k，各自整步／半步的最大孔压 RMS 差依次为0.000319623、0.000303061、0.000356309 Pa；最大材料位移差均小于6.61e-11 mm。保留原5 Pa／0.005 mm及归一化1e-4门槛。
- 11项非法XML均由准确目标检查拒绝，没有保存原生粒子帧。
- 三项真实 PART 拒绝通过：ON读取旧OFF、OFF读取ON、OFF读取仅新增false标签的OFF副本。副本原15数组及原标量逐位保持；真实OFF加载正控制通过。这不是耦合续算验收。

完整物理短窗终点仅 `2^-15 s = 30.517578125 μs`。不能用这些结果替代固结或Cryer长程验收。

## 数值结果及明确没有通过的项目

严格“旧私有夹具与新入口全部257帧、26列逐位相同”条件**未通过**，原始false结论保留。初始帧PosDiv最大差1.9906867742538452，来自正式 `SaveData` 先刷新位置散度／自由表面诊断，而旧夹具直接快照；周期初始横向速度还有数值差为0的正负零位型。全部6组后续第1–256个保存时刻26列逐位一致。没有删列、覆写原生数据或把部分一致改称全程一致，也不据此继承完整私有墙面通量／负控制验收。

独立连续参考复算中，常 k 墙面终点孔压误差为−0.259922%，其原先登记的全场、近墙和终点1%目标通过。周期32列的终点误差仍为−1.471591%，未新设或放宽该场景门槛。变 k 没有借用常系数参考冒充解析真值。

墙面变 k 最大局部变化约2.98%，空间跨度约5.87%。同初态常／变 k 的最大孔压场RMS差0.0233047 Pa，大于自身半步0.000356309 Pa及预先登记的分辨阈值0.00356309 Pa；说明功能非空，不代表精度改善65倍。
