# C02 高渗透率短窗精度与成本

k=10⁻³ m/s，排水从 0.01 s 开始。每组 13 帧，排水后的输出间隔 ΔTv=.005，终点 Tv≈.05。显式 u-pl 对应有限 Kw 解析解，三轮 TPI 对应 M0 解析解。孔压取 100 个材料层的 RMS，顶部和底部取各自初始材料层的沉降误差。
