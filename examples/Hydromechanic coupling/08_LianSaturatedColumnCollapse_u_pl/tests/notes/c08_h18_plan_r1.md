# C08 h/dp=1.8 参数对比及三组交付计划

用户要求hdp1.8、人工应力系数0.3/0.5/0.7，可调整指数，选择后用同一设置完成三个剪胀角正式计算、图和CSV。旧PRE与所有失败不覆盖；必要时重做预载已获明确授权。

先保持C08 Cubic及论文材料/dp.04/混合滑移不变。参考干土实际为Wendland、无孔压反馈/无软化；历史指数也不统一（.5组3.825，其余2.55），不能直接当作系数优劣证据。首轮在同一新PRE、同指数3.825下比较三个系数，较好系数再分别比较指数3/5；最多两个跟进，不做全部交叉搜索。必须同时考察近对、负压/应力脉冲、滑动形态、前缘/沉降及运动维持，不能把早停当成功。

新的严格弹性源为Cubic hdp1.8，dt5us、10s/2M更新，AS/NoPen关闭、Shepard40、阻尼.03。阻尼率正比系数/H，.03/.072近似保持原.02/.048；接收前合同相同，撤墙后阻尼和Shepard仍由原逻辑关闭。必要步长、弹性资格和κ0守门不放宽。原程序能力允许这些设置，不代表新源已平衡。

实际活动源为configs/c08_h18_pre_r2_Def.xml及BAT、profiles_r2 JSON和三个steps_r2 CSV；support下有准备器、源owner、一个共用native工具和共享matrix/post入口。r1因TimeMax等于撤墙事件而在LoadConfig拒绝，没有任何PART或积分；原失败保留，r2只将TimeMax声明改为13，并用-nsteps:2000000停在10秒预载末态。测试均在tests既有浅层分类。源从零积分，不给σ初场；H进入合同，原H1.2 PRE不能直接给H1.8接收。若源失败，保留首因并定位角点/应力/压力，不启用失败PRE。

计划按原OutputTime调度及真实scalar+=dt预演，保留额外首个撤墙后保存与最终部分间隔，不使用n*dt替代真实时钟，不改为二进制特殊时步。5us在2M步时的时钟可能略小于10，故接收帧数由显式plan决定，不能照抄旧90/300计数。

源完成后先核22数组、全部原IDs、P0、J/n/V/rho/k、实际时钟、signed必要时步及材料资格；再审末段速度/能量、应力/孔压和沉降是否足以作为撤墙基准。通过后依次做ψ0参数窗口，选定后准备根目录标准正式XML/BAT并实际完成三组3s、独立Fluid/Bound particles、图及对应CSV，并与Lian的各组形态/孔压进行有范围说明的比较。原NoPen反力尚未同stage闭合，TPI/负压稳定未实现的能力不能声称已经复现。

每个有效阶段选择性同步本地/远端Git。只在身份不明确时追加文件哈希；正常用已有绑定、stat及实际程序退出，不做BI4/对象反复SHA扫描。一次活动长阶段只用直接owner的一次同线程终态续接，旧owner不重挂，不发连通性自测。
