# C08 负孔压正则化在实际空间行上的量级

Lian 等（2023）式（47）用上一个已提交时刻的总孔压 `p_n` 判号，正文将其用于考虑塑性变形的土。本文算例采用 β=0.04。论文指出 β 可由剪胀三轴试验标定。私有 C08 候选在 `tests/support/c08_tpi_negative_r1.h` 的 `PrepareFinal` 内采用 `pn < 0`，零值进入普通行。真 Dirichlet 优先；最终完成步自由渗流边界另处理正压。参考原文见仓库 `src/papers/u-pw/Lian 2023 u-pl.md` 第 3 节式（47）及第 4 节图 16。

`c08_tpi_eq47_state_r1.py` 从已审阅的 `c08_tpi_state_r1/soil.csv` 取两帧各 5,000 个材料 ID。保留原始空间行的对角项 S 和残差 R。缺少前一步历史时明确采用单次冷启动假设 q = pα = p_n，条件压力增量为 R/(S + c)，其中负压行 c = β/Δt，其余行 c = 0。R 单位为 Pa/(m·s)，S 和 c 单位均为 1/(m·s)，故这一行归一化下 β 单位为 1/m。原来的有限 Kw 动力场仅提供两组固定状态。

|---|---:|---:|---:|---:|---:|
| 0.380005 s | 1,125 | 3,875 | 8.0455 → 0.000256 Pa | 935 | 1,125 |
| 0.760005 s | 2,269 | 2,731 | 28.1424 → 0.000764 Pa | 1,162 | 2,269 |

在 5 µs 时间步下 c 约为 8,000，负压行的 S 为 0.134–0.280。两帧增量衰减比 S/(S+c) 的中位数均约为 2.66×10⁻⁵。β=0 复现已有 10,000 个 float32 原始条件压力值；β=0.04 的 10,000 个 float32 值也与独立 90 位十进制分子形式的计算逐位一致。两帧各有 9 和 0 个正自由面试算压力由既有策略置零。真实 Dirichlet 受约束行为 0，另用六个合成行检查该优先级。

在当前归一化和步长下，β=0.04 会很强地抑制冷行的单次压力变化。下一次动态对照需采用真实前一步总孔压和同一组材料/边界，分别报告负压最小值、持续时间、压力振荡、滑带及运动范围；当 q 与 pα 有差异时保留 c(pα−q) 项。已有两个固定状态不能给出动力轨迹、成团程度或最终滑塌精度。本次没有启动求解器，也没有改变预载、塑性模型或沙漏控制。
