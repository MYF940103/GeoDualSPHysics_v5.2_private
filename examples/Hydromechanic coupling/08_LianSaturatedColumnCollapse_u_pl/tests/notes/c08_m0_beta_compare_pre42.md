# C08 闭墙重力起步的两条 M0 轨迹

私有 CPU 候选从同一组 5,000 个土粒和 2,060 个墙粒开始，采用固定参考水位计算的初始静水孔压、零有效应力、同一 5 µs 步长和相同的两级冷启动孔压。两次实算分别取 β=0 和 0.04，均完成 42 个积分步，全程闭墙，实际末时刻为 0.00021000000000000023 s。43 个实际时刻上，全部 7,060 个 ID 的 22 个原生数组逐位一致，位置、孔压、应力和 κ 的两轨差均为零。[独立逐帧记录](../figures/c08_m0_beta_compare_pre42.csv) · [汇总](../figures/c08_m0_beta_compare_pre42.json)

每条轨迹的 210,000 个预测源压力均大于或等于零，所以式（47）启用的附加容量始终为零。各轨都核对了 126 组压力轮和 210 个步长检查，最小允许步长为 8.89658 µs。每一积分步均只在第三轮投影 100 个表面点的正压，第 40 步另外执行一次原 Shepard 操作，与两轨相同的 200 µs 位置对应。压力历史按材料 ID 与相邻的已提交压力逐项比较，变渗透率和孔隙率方程在每个保存状态均通过。此结果验证了无负压时 β 的零作用；末态速度和最大压力仍在上升，预载平衡与有负压时的滑带演化有待独立动力证据。[曲线图](../figures/c08_m0_beta_compare_pre42.png)
