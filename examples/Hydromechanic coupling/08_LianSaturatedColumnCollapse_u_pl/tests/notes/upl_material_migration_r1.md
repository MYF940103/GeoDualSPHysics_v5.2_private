# 材料统一的比较与整合验收

采用 Lian 的累计等效偏塑性应变 κ；体积塑性变形仍由剪胀势计算。devκ 与 fullκ 是不同历史定义，不能把它们之间的差别称为浮点精度改善。

## 怎样判断方案更优

1. 固定相同材料、历史定义和应变路径，比较端点返回与瞬时线性化 devκ 方法。参考为已完成的独立 DOP853 路径，不用算法自身的屈服残差充当精度真值。检查应力、κ、塑性体积变形、加载/卸载/再加载及步长收敛。
2. 常强情况用闭式解；顶点、φ=0 和三种 DP 系数分别检查。张拉修复保留明确的原 Bui 上限政策，不冒充原单塑性势的普遍顶点解。未获区间单调性认证的路径明确拒绝，不能随意投到顶点。
3. 检查实际工程中的 Pre 恢复 κ、Cor 单次提交、Verlet 应力/κ 时间层配对、周期复制/排序，以及新旧合格弹性 PRE 的接续。跨后端原界为孔压 RMS≤5 Pa、材料 XYZ 位移最大差≤0.005 mm。
4. 用同一 Release 编译和相同 incoming states/路径比较成本，计时不含 I/O。只将同模型的线性化 devκ 与端点算法作精度/成本权衡。旧 sft 仅作为历史实现对照，不能把 Debug/Release 差异当算法加速。

现有 21 组材料、252 条路径已完成；每段64增量的 PS 联合软化代表路径最大应力误差为：ψ=+2.5°，端点0.2141 Pa、同devκ线性化0.2158 Pa、旧sft77.0222 Pa；ψ=-5°分别0.6508、0.6658、179.8109 Pa。旧列还含历史定义和系数/符号差异，不是纯精度比。完整输入、参考、图CSV在 `upl_material_path_r1` 记录中。

## 当前生产迁移范围

共享 `FunSoilMaterial.h` 留基本/软化两个入口，CPU/GPU共用同一返回核心；移除旧 fast 函数体及永久 MaterialReturn 算法分支。旧 XML 的0/1只作同义兼容别名。φ/c/ψ演化、三种系数及导数、顶点和φ=0均在该核心。材料参数和保存κ仍为float，局部应力/系数/根运算使用double。

Verlet只补应力/κ前一时间层配对和CPU前一层初始化；原全局启动与两步策略不变，不能宣称其普遍不可逆性已获验收。u-pl公开物理范围仍为Symplectic。

四配置程序使用独立 `upl_material_release_*_r3` 输出和共同源码归档，canonical bin、服务器r2包和旧记录均保留。具体已运行状态以各项终端收据为准，构建成功不是物理验收。

本轮实际通过：CPU 14点/26阶段调用，GPU对应26调用（应力与CPU差0，内存检查零错误/泄漏）；CPU/GPU各4次周期复制、8条复制记录及12条实际非恒等排序记录；28点原生布局adapter与6项真实PRE/通用PART加载政策检查。两后端MaterialReturn别名0/1的22帧完全相同；新版本弹性PRE接续各11帧22字段和signed clock与连续运行完全相同。

实际256步塑性周期短算各保存5帧，CPU/GPU原比较界通过：孔压RMS最大差0.00272193 Pa、材料XYZ最大差1.58845e-10 mm。CPU有768个非零κ材料点，最大κ约3.78213e-4；此短算不是完整塌陷验收。

首次GPU旧/新严格比较错误地混用了旧Release与新Debug，因此未通过0ULP；初帧差异已早于材料第一次积分。原失败收据保留。随后仅补一个新Release800步源运行，与旧Release的全部22帧/22数组及完整signed-clock CSV严格逐位相同，无容差替换。旧Release PRE→新Debug的11帧则按跨配置说明，孔压RMS差0.00187142 Pa、位移差1.35630e-8 mm；不能称跨配置逐位证明。

同模型Release成本实测：公共incoming状态 Taylor123.65/端点301.15 ns，独立路径123.46/297.92 ns，七批中位数比2.44/2.41。两者同为一阶，本轮21路径每段64步最坏应力分量误差为0.9812/0.9467 Pa；端点并非每种κ误差都更小。选择端点作为统一基线依据完整的状态一致性及功能范围，局部成本代价明确记录；不能把该倍数外推到整个SPH。图及对应CSV：`tests/figures/upl_material_cost_accuracy_r1*`。

## 已发现的测试范围问题

- `upl_material_release_native_r1_fluid_CPU` 实际退出1，尚无物理步；拒绝于既有 `ConfigConstantsSoil` 的零约束模量。该函数与迁移前 f662043 的函数体完全相同。这不是新材料返回的数值回归，也不扩展成纯流体功能开发；GPU同输入不重复执行。零材料的接口保留检查已在28点adapter中完成，不宣称纯流体整机等价。
- `upl_material_periodic_cpu_r2/r3` 的真实访问异常保留。小夹具先缺 AppInfo 日志初始化，继而发现手拼 dcell 编码不满足实际1+31位分配；只修新测试夹具并检查逐点解码，不改生产分区逻辑或门槛。
