## Time layers and pressure row

This is a new, restricted Symplectic extension, not Lian's original leapfrog ordering and not a true implicit solve. Alpha=.5, beta=0. The original predictor and corrector solid updates—including position, velocity, six effective stresses and J—are retained. Only their two finite-Kw pressure integrals are bypassed on ON:

`p_half = float(p_n + .5*(p_n - p_previous))`

`p_guess = float(p_n + .5*(p_n - p_previous))`.

`p_n` is captured by original native ID from `PorePressPrec` after the original first force/cap and swap. This is the genuine constrained full state consumed by the step; it is not recovered from a saved or interpolated frame. Predictor drainage retains its original priority. The later corrector hook captures actual `p_half` after the real midpoint force and its drainage, J_half and theta_h. Corrector pressure writes only the guess, then returns before original finite-Kw `p_n+dt*R_h`; it does not rotate history. J still executes the original predictor and single original corrector. J_n, J_half, theta_h and completed J are captured separately.

The third `Interaction_Forces(INTERSTEP_SymCorrector)` occurs in the outer loop after the original completed-geometry `RunCellDivide(true)` and before `TimeStep += stepdt`. It sees completed x/v/effective-stress/J and the guessed pressure, performs the real dynamic wall/FS/C, raw momentum/AV/damping and dynamic Darcy calculation, then the original `DtVariable(false)` necessary bounds. It does not call another material return, porosity integration, position or velocity update. The HG path is disallowed rather than given an undocumented third history stage. Its force scratch is released; on an exception the process fails without a new history commit or saved endpoint. Original partial/last native states must be retained; this is not an in-process rollback/retry facility.

**The source clock remains original n for all three forces.** Neither `TimeStep` nor `Nstep` is temporarily advanced. Loads and drainage therefore retain the original source-clock lag even though the third force has endpoint geometry. Completed step2000 is pre-open; later steps use the original fixed-grid event predicate. This mixed endpoint-geometry/source-n-clock choice is a declared candidate interface, not paper-literal endpoint forcing or proven second order. Original `RunGaugeSystem(TimeStep+stepdt)` precedes this new pressure endpoint; hence real gauges are rejected in this prototype.

In the original dynamic Darcy neighbor pass, only the endpoint call accumulates `sumw`, using exactly the existing current-volume, SymC, Eta², neighbor and wall values. The original LP/gradient/Taylor-defect/acceleration source expressions remain unchanged. For constant k:

`R_gamma = -gamma*theta_endpoint + k*lap`, `gamma=rho_w*9.80665`

`S = -k*sumw`

`p_new_raw = float(p_guess + R_gamma/S)`.

R_gamma is computed from the actual double intermediate in that same real pass; it is never reconstructed from the quantized finite-Kw float rate. The original float endpoint rate is still calculated/stored and checked as a diagnostic, including its existing finite/natural/pore safety. S must be finite and strictly positive for every unconstrained soil row; there is no denominator epsilon, clipping, coefficient fitting or regularization. True Dirichlet rows take priority and remain zero without division. The pressure gradient/Taylor defect, actual wall pressure and acceleration are evaluated at the guess; they are explicit known parts of this local row. This is not an implicit wall or full coupled Jacobian solve. Variable-k is rejected rather than silently omitting its product-rule channel. The current SymC/Eta²/FS operator is retained; this is not a claim to implement the paper's receiver-C-only/bare denominator spatial scheme.

The corrector pressure hook sets a private temporary-guess flag before the original outer cell division. Only `JSphCpu::ApplyPorePressureBoundaries`' completed **positive free-surface** cap is skipped while that flag is true. `HydroMechFreeSeepage` itself is not toggled: doing so would change the Darcy branch. True fixed drainage and periodic pressure copying in `ApplyFreeSurfacePorePressure` are never bypassed. FS and dynamic-wall reconstruction still run. Shepard is enforced OFF so no filter path requires a bypass. In this first column FreeSeepage is OFF, but the narrow flag protects the intended interface without changing the final boundary policy.

After all1000 endpoint rows and necessary step limits pass, all candidate pressure values are validated before their bulk native/periodic write. The endpoint/temporary flags are cleared, the original complete boundary/periodic policy is applied, every completed soil J is checked unchanged bitwise, and each full-step history rotates **once**: previous becomes the captured p_n. Final constrained pressure is recorded separately. Row or boundary failure reaches no new SaveData/history commit. Default finite-Kw pressure is never also added. Fixed ghost pressure/J/FS/C can legitimately be reconstructed during the third force; they are not claimed unchanged. The native theta field is the last endpoint diagnostic; **theta_h captured in the sidecar is the divergence that actually integrated J**.

## R2 author recovery and narrow change

In the intervening message/tool-call race the r1 author header and note were changed to latch row errors instead of throwing in OpenMP. Those current author stats therefore no longer match the original r1 prepare receipt; neither timestamps nor old generated outputs are rewritten to disguise that fact. The original r1 generated header still records the actually prepared throw-inside-row version. R1 has not been built or physically executed as X0 and is retained as an unselected preparation.

R2 is a new preparation/tag/output/header. Relative to the actually prepared r1 header, its only numerical-control change is error propagation: Row checks lifecycle/ID bounds before indexing, unique rows, finite theta/guess, and non-Dirichlet finite positive S/finite residual; each original failed condition latches the first error code/native ID and returns. CPU1 remains required, so no atomic is needed. The later serial PrepareFinal throws the recorded first cause before any final pressure/history commit. No S threshold, finite criterion, row formula, time layer, boundary, force call or material operation changes. Header guard and summary stage labels change to r2; namespace c08x0, class ABI, environment name and all original source anchors remain unchanged.
