# NN 图版面修订

原物理分析与所有 CSV、PNG、收据均保留。原 NN 图的长标题和 constrained layout 出现重叠；本版只从已封存 spatial.csv 生成一个新标签 NN PNG，显式安排标题、坐标区与 colorbar，不重复原生读取或物理分析。

两组 × 三个实际时刻的全部 30000 土粒子保持原数据和共同完整数值范围，不平滑、不改值、不删点。灰线是已采用的 x=0、z=0 接触平面参考，不冒称边界粒子导出；原物理图仍有实际边界粒子。实际 Fluid/Bound 粒子导出未由本任务修改。

脚本与数学由 root 审阅后直接离线调用一次，不启动求解器、读取器或 VTK。新的 check 绑定原物理检查、CSV 与本版 PNG，保留原图以供复核。版面修订不代表物理验收。
