## 当前现象与下一步

径向 RV alpha=.1 的 .90 s 轨迹已完成唯一原生解码与离线比较。相对原 AS .3/n2.55 对照，末态孔压 RMS 从 12.9522 降至 10.7240 kPa，但全窗最小土粒间距由 .270834dp 恶化至 .092459dp，最负保存孔压由 -58.4140 恶化至 -61.2758 kPa。保留原方案和 RV 两方案，均不据此宣称团聚修复或正式验收。

径向方案最差近粒对为固定材料 IDs7011/7012，Part67，tau=.670004999974635 s，间距 .00369836 m。这两个原右侧同列、初始 z=.06/.10 m 的材料点当时均 FS0，孔压约 +3.239/+3.582 kPa，沿粒对总应力约 -23.848/-24.834 kPa。该保存瞬间已是压缩/正孔压，不能把最小间距简单归因为此时负孔压张拉；P38–40 的先前接近过程仍曾有吸力与总主应力张拉。P67 已有微弱径向分离，故因果检查须覆盖接近的早期。

固定初始邻接四点 [6961,7011,7012,6962] 在径向方案 Part29 出现某个有向三角形负面积、Part34 四点连线自交。这是材料邻接几何描述：连线会跨局部滑移，不是 SPH 单元，也不等于实际体积或质量翻转；不能以此直接断言 J 错误。原 AS 对照也出现该四点连线折叠。

拟新增 `support/c08_h18_bed_gradient_probe_r1.cpp`、`_build.py` 及对应说明：只重算原 AS 和径向 RV 各自 Parts28–34 共14个已保存态，不推进时间，不调用材料返回或滤波。新入口链接已封存 CPU Debug 物理对象，不重建公共物理 TU。记录实际 CPU 的 PoroTheta、六分量 Rsigma、修正矩阵和近墙全速度/切向速度，并逐字面重算梯度。独立保留所有5000土粒及四个重点材料点的六个无序粒对；不预设这14态存在旧 CPU 逐位真值。结果不等同当年 GPU 更新内未保存的 Pre/Cor 阶段。

## SPR、黏性与动态墙现状

依据 `outputs/c08_preload_schema2_source_r1/full_source.zip` 中实际绑定源码：

- `JSphGpu.cpp` 的 BoundDerivativeVel 分配条件为 SPR **或** DynamicPoreWall；动态墙拥有自己的导数速度生产路径，SPR0 并不等于该速度不存在。
- `JSphGpu_mdbc_ker.cuh:152–175` / `JSphCpu_mdbc.cpp:1163–1186`：静止 NoSlip 底面全镜像速度为 -v_mirror，黏性速度为其切向投影；FreeSlip 侧面全镜像为法向反射 Qv_mirror，黏性速度为 (I+Q)v_mirror/2。物理墙速度仍为0。
- `JSphGpu_ker.cu:1918–1966,2074–2097,2259–2269`：动态 θ/应力梯度使用全镜像导数速度，AV 使用切向黏性速度。LP/Lx 用压力差及成对修正，Da 用加速度差，不能用某个 dv 标签代表整个 Darcy 算子。
- G1 与 θ 使用同一个物理体积/矩阵和导数速度，但数值累加顺序不同：G1 先 float 梯度求和再矩阵修正；θ 逐对 double 收缩。因此下一探针量化两路径，而不事先宣称不一致一定足以解释团聚。
- 墙加速度闭合与固定平面投影反力不同；当前 `ReactionClosed=false`，不能通过打开旧 SPR 标志证明反力闭合。

## 不能直接打开 HG 或 shifting 的原因

现有 HG 含非周期邻居实现，但其已验证域为小转动弹性、固定材料集合，Gather/BuildPairs 要求 kappa=0，软化分支被显式拒绝。它的历史弹性恢复力未扣除塑性滑移，直接解锁会对真实滑移施加弹性回复，可能加剧早停；PRE 也没有对应 HG 历史。既有0.5s柱体半步与2s柱体结果不是 C08 塑性自由面资格。

旧 shifting 只改位置，没有 p/J/sigma/kappa 一致输运，也没有已验证的自由面切向投影。当前动态容器显式拒绝它；不能删门来进行看似低成本的试算。相关详细依据见 `c08_h18_shifting_compatibility_audit_r1.md`。
