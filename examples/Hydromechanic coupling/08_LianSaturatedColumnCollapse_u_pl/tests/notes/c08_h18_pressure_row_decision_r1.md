# C08 后期压力行：组件审查结论

在原AS0.5/n2.55完整3 s的Part300，恢复真实状态并只调用一次原CPU力/Darcy，不推进时间、不更新材料。实际时刻12.999999999592434 s、完成2600000步。5000土粒子原始float变化率逐位吻合；5000压力行、35000制造记录、15000代数影子、28分区统计和6行双节点CN制造检查通过，原算术预算未改变。两个实际工具出口均为0。构建只编译一个独立入口，链接86个原DebugCPU物理对象；无公共源码或活动GPU依赖修改，无SHA扫描。

三张PNG和配套CSV已目视检查，标签和范围可读，无平滑或剔除极值。完整6805解析供体的常量压力算子在5000接收者上严格为零；仿射梯度误差约机器精度，但raw-FS压力算子独立制造场仍有较大的边界响应。该制造场冻结实际加速度，并非完整静水/自由渗出边界误差，更不能据此认定应替换FS条件。原数值gradJ的变k参考是条件性参考，不是完整连续解。

这些结果未发现普遍的对角符号或常量零空间错误。局部Δt·S/M不小，但不等于显式失稳；冻结邻项代数影子也不是当前真实中点、全局隐式解或物理修复。若只将原变化率除以分母，会同时压小体积源，不能采用。

下一项只准备有限Kw的独立单步对角CN组件：在真实中点取s_h=S_h/M_h，使用真实p_n和p_h，按

`p_new = p_n + dt*[R_h+s_h*(p_h-p_n)]/[1+dt*s_h/2]`

更新该测试步孔压。保持原预测、材料、J、空间算子、正压FS投影、墙和必要时步；它不是Lian去除储水项的TPI，也不加入β。需要验证恒定体积源不会被错误衰减，并按实际字段比较已有原Part300单步，不新增OFF轨迹或半步链。只有单步证据支持时才考虑后续轨迹；当前没有正式接口或长程准入。

AS0.3/n2.55的独立0.9 s GPU窗口继续原样运行，尚待终态原生和物理比较；其他两组ψ不因本组件通过而自动解锁。原3 s负压漂移、团聚和过早停滞仍未解决。全部原始输出、PRE、旧失败和正式文件保留。
