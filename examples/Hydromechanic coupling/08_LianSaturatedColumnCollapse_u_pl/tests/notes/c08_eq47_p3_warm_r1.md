# C08 连续孔压历史与式（47）三轮修正

读取已保存的 Wendland H/dp=1.8、ψ=0°、HG 关闭的 GPU Debug 存储观测，材料 ID 与原生 22 数组完整。采用撤墙后相邻的第 2,000,001、2,000,002 积分步，实际时刻分别为 10.000004999706007 s 和 10.000009999706007 s。独立 CPU 组件在后一几何上对全部 5,000 个土粒分别计算 β=0 和 0.04，每组重算三次全体粒子的力、加速度和 Darcy 项。坐标、速度、应力、κ、J 与时钟保持固定。

每个 ID 的历史外推为 pα=p_n+(p_n−p_prev)/2。第一轮从 float32(pα) 开始，每一轮用全部邻居上一轮写回的孔压重新组装空间残差 R 和正对角 S。令 c=(β/Δt)·1[p_n<0]，则 q_next=q+[R+c(pα−q)]/(S+c)。三轮共用原生 p_n 决定的触发条件和同一个双精度 pα。末轮按原自由表面规则将正孔压置零，再轮换两级已提交历史。两套试验共覆盖 10,000 次末态投影及历史校验。人为在第三轮最后一个粒子注入无效对角项及在末轮投影返回失败，两个算例均保留了原有两级历史。

β=0 的 15,000 次写回与原有端点函数逐位相同。独立 Python 程序从原生二进制重新读取两组压力，以 80 位十进制按分子式 (S·q+R+c·pα)/(S+c) 计算参考值，检验其是否落在相邻 float32 中点之间，平局按偶数舍入。两组共 30,000 次写回全部通过。该校核以实际组装的空间系数为输入，覆盖历史、算术、分支与阶段顺序。
