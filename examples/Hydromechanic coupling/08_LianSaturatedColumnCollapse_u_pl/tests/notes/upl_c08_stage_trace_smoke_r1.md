# Stage-trace smoke: explicit run/native/review actions

Author-only new runner `support/upl_c08_stage_trace_smoke_r1.py`; source/note names were checked before creation. No import, AST execution, solver, reader, build, queue or data mutation was performed during authoring. Old scripts and source are unchanged.

CLI is `run|native|review Debug|Release --execution-authorized`, one action per invocation. Debug has40 updates/TimeMax10.0001/TimeOut.0001/one native frame, with exactly one compute-sanitizer memcheck target. Release has12000 updates/TimeMax10.03/TimeOut.01/three frames and no instrumentation tool. Release run additionally requires the closed new Debug review; the root must independently read that result and authorize it. There is no automatic sequence, notifier, later solver or scope beyond.03s.

Tags are `upl_c08_stage_trace_smoke_Debug_r1` and `upl_c08_stage_trace_smoke_Release_r1`, with independent fresh configs/outputs/logs. Programs come only from the corresponding closed macro-enabled trace builds, source ZIP/JSON and original113-object closure. Only missing known7 configuration/DLL files are copied from runtime_r5 to the isolated build directory; existing files must match size/mtime. No executable, old runtime, source or object is rewritten.

Config is parsed from the root psi0 r5 Def. It substitutes the same original r2 GPU PRE path and changes only TimeMax/TimeOut, updating their comments to the actual .0001/.03s implementation scope; units and other parameters remain unchanged. Global-nsteps is source4M+40 or+12000, with one immutable two-column planned_steps.csv. All dt2.5us/DtMin/NoPen1/AS1 .2/2.55/keep true/material/Model1-Ck2/free-seepage settings retain the original checks. No new PRE, other group, half step or altered physics is introduced.

The runner calls the existing bedkeep `check_input`, `owned`, `invoke`, strict AS-semicolon `summary` and real typed Win32 ownership tools without monkeypatching globals or reimplementing process loops. Fresh start/call/run/native/review paths refuse duplicates. The actual trace CSV must exist, be nonempty and contain the3 intended IDs with one hit each; its real event/step/row counts are recorded, not replaced by assumed substage semantics. Run checks retain original7060/2060 registration, zero ordinary exclusions, unique255 retirement and exact kept5 IDs, normal finish, and actual saved files. Native/geometry/field acceptance is pending the independent native action.

Native action reuses the existing closed six-utility C08NativeBedKeep_win64.exe, never recompiles it, and refuses prior outputs or a matching active reader/solver. CLI remains `--read psi0 GPU DATA PRE END SAMPLES 1 PLAN FRESHOUT`. Original22/6805 IDs/5000soil/1805fixed, ledger/P0/rho/FS/kappa/clock/plane and AS/keep metadata budgets are retained. It is invoked at most once per profile; failure is preserved without retry or automatic physical call.

Review is separate. Debug compares the complete one-frame22/time payload/layout and raw signed-clock rows with retained bedkeep_smoke_GPU_r1. Release reads only the first3 real record payloads and clock rows of completed root r5's300-frame native output. It checks actual headers `[6805,22,3]` and `[6805,22,300]` separately and never rewrites either. The same-step/time/all-ID22 payload and signed clock rows must be byte exact; mismatches record the first raw differing byte and preserve evidence. These are instrumentation nonperturbation controls, not a half-step convergence/5Pa comparison, speed benchmark or physical-collapse acceptance. All outputs use stat bindings, without SHA or recursive raw-data scans.
