# C08 负孔压、间距与真实连续压力历史

采用已保存的两套有限水体积模量轨迹，保持原材料 ID 和真实时钟。两套资料的核与人工应力不同，统计分别计算。

## 三秒内的颗粒间距

Wendland、H/dp=1.8、步长 5 µs、人工应力 0.3/2.55、HG 关闭的 ψ=0° 接收组共有 301 帧，每帧 5,000 个土粒。按总孔压 p<0 筛选，1,505,000 个粒子–帧中有 853,347 个满足条件，3,705 个材料 ID 至少出现一次。沿用最近土粒距离小于 0.7 dp 的判据，37,718 个近邻观测中有 34,259 个同时为负压。首次出现近邻的实存时间为撤墙后 0.180005 s。最终有 121 个近邻粒子，最小间距为 0.06336 dp，最远土粒 x=5.04326 m。三秒内最小孔压 −58.414 kPa，末帧最小孔压 −24.607 kPa。

对上帧尚未靠近的粒子，按上帧总孔压及更早一个保存区间的累计塑性量 κ 增量分组，再看其下一帧是否首次进入近邻距离。每一帧重新确定风险集，同一粒子可以重复计数。

| 上一保存区间 | 上帧孔压 | 下一帧靠近 / 当时尚分开 | 比例 |
|---|---|---:|---:|
| κ 增加 | p<0 | 390 / 156,679 | 0.2489% |
| κ 增加 | p≥0 | 270 / 75,919 | 0.3556% |
| κ 未增加 | p<0 | 64 / 658,826 | 0.0097% |
| κ 未增加 | p≥0 | 0 / 565,979 | 0% |

近邻状态与负压大量共存；已发生塑性发展的粒子中，两种孔压符号都能随后进入近邻距离。保存间隔约 0.01 s，无法分辨区间内谁先发生，也无法由此判定负压正则化能否消除团聚。

## 连续积分步的材料压力

Cubic、H/dp=1.2、步长 2.5 µs、人工应力 0.2/2.55 的原始逐步跟踪覆盖撤墙后 0.6000025–0.6599975 s。每个 ID 有 23,999 个具备上一积分步的样本。逐一验证上一步结束压力与当前保存的 p_n 在 float32 中逐位相等。以真实下一步压力为比较对象，下表仅统计 p_n<0 行。半步线性外推 pα=p_n+(p_n−p_{n−1})/2 与论文端点邻居估计的用途应区分，表中误差仅描述历史斜率的信息量。
