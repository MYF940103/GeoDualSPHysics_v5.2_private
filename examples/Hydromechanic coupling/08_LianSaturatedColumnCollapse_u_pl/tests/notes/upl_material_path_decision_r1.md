# 材料统一：路径比较与阶段决定

2026-11-07。本轮只新增 tests 中的材料点候选、程序、分析和记录；没有修改生产源码、正式 XML/BAT 或服务器 r2 包。CPU Debug 工具链实际编译/链接并运行了材料点程序，不是 SPH 空间计算。

## 实际比较和结果

参考模型明确采用累计等效偏塑性应变

\[
d\kappa=\sqrt{\frac23\,de^p:de^p},\qquad
f=q+DP_\phi I-DP_{kc},\quad g=q+DP_\psi I,
\quad q=\sqrt{J_2},\ I=\operatorname{tr}\sigma.
\]

本轮为 21 组材料：三种 DP 系数 × 三个初始剪胀角 × 常参数/联合软化，加三组单项软化。固定偏应力方向，依次加载、卸载、再加载，分别每段 8/16/32/64 个材料增量。所有状态处于压缩、光滑且稳定的分支；不是 apex 测试或塌陷空间验证。

独立参考由微分一致性方程积分，系数导数通过复步微分取得，包含弹性再进入屈服事件。收紧 DOP853 容差后的最大应力变化为 3.4925e-10 Pa，最大 κ 变化 2.082e-17。参考的功/弹性能量平衡最大差为 1.819e-12 Pa。另有 3240 条常强局部解析映射核对、全保存点的 q>0 和塑性段绝对屈服漂移检查。它们检查数值参考，不能代替土体物理标定。

实际 C++ 共 22,680 条更新、252 条完整路径，全数保留、无失败或跳过。每段 64 步时的代表性最大应力分量路径误差如下：

| 材料路径 | 新端点一致返回 | 同 devκ 的 Taylor 比较方法 | 实际旧软化函数 |
|---|---:|---:|---:|
| PS，ψ0=+2.5°，φ/c/ψ 联合变化 | 0.2141 Pa | 0.2158 Pa | 77.0222 Pa |
| PS，ψ0=−5°，φ/c/ψ 联合变化 | 0.6508 Pa | 0.6658 Pa | 179.8109 Pa |
| PS，ψ0=+2.5°，仅摩擦角变化 | 0.000221 Pa | 0.005249 Pa | 58.1422 Pa |
| PS，ψ0=+2.5°，仅黏聚力变化 | 0.0000576 Pa | 0.000820 Pa | 44.7714 Pa |

在 12 组演化材料中，新端点方法的最坏应力误差从每段 8 步的 7.4785 Pa 降至 64 步的 0.9467 Pa；同 devκ 的 Taylor 方法从 9.6869 降至 0.9812 Pa。两者均表现为本路径上的一阶误差。不能据此声称端点方法在任意非比例路径上都更准确，也不支持为了更低残差盲目增加局部子步。

旧列调用的是冻结对象中的真实 `ConsRelationEPsft_fast`，即使参数退化为常数也仍调用该软化函数，**不是**生产代码的基本/软化自动分派。该函数还存在全塑性范数、不同一致性分母、旧κ屈服面末投影、float 系数和三维 `1.732f` 等差异；且没有 `sf` 接口。本轮严格传原 ψ0，没有在调用外补衰减。因此旧列是历史实现对照，不能将误差比解释成同一模型的纯数值精度比，更不能称为 double 带来的改善。

真实源码输出的屈服值与独立 Python 系数表达式最大差为 7.276e-12 Pa；应变加和闭合最大 3.643e-17，局部连续 κ 与实际偏塑性增量最大差 2.060e-18。这些闭合检查大部分是必要代数检查；方法排序依据完整路径与独立参考的差异。程序每步保存 κ 仍为 float，`local_continuous_kappa` 不是全程 double 历史。

## 统一实现的决定和剩余工作

1. 以 **devκ、一套端点返回和两个清楚入口**作为迁移基线：基本弹塑性 `ConsRelationEP`，φ/c/ψ 演化的 `ConsRelationEPsft`。材料参数和保存 κ 不整体改 double；系数、导数、应力和局部根运算用 double。
2. 使用 `DP_phi/DP_kc/DP_psi` 及其 κ 导数。系数/导数引擎覆盖 PS、3D 外接、3D 中接，纯 ψ 衰减也必须进入演化入口。
3. 原始 f 的实际导数是 `fκ=I*DP_phiκ-DP_kcκ`。同 devκ 下的光滑瞬时分母是 `G+9K*DP_phi*DP_psi-fκ/sqrt(3)`。端点 Newton 导数还含 ψ 演化的有限增量项，且 fκ 中使用返回 I；不能把旧 plus 分母直接搬入新接口。
4. 顶点不能继续按总塑性乘子累计 devκ；真正 q=0 返回应由 `Δep_dev=s_trial/(2G)` 得到 `Δκ=q_trial/(sqrt(3)G)`。φ=0 时是圆柱而不是有限圆锥顶点，不得计算 kc/α。
5. 保留原 Bui 张拉上限 `I_tip=DP_kc/DP_phi` 作为明确的既有兼容政策。ψ=0/负ψ下的附加张拉流须与原 DP 光滑/合法 apex 分开标明；不偷偷降低张拉强度、不增张拉损伤参数，也不宣称负ψ全域机械功非负。常强组件先做解析/流动/旋转检查，之后才接入软化候选。
6. 完成顶点、φ0、联合软化与所有六分量的测试后，才做生产迁移、CPU/GPU 构建及实际调用回归，最终移除永久算法选择。当前 `general_candidate_r1` 仍仅是光滑路径候选，其保守区间单调证明会拒绝一部分可解路径，不能作为完整通用算法发布。

服务器 r2 继续使用其已冻结程序及既有材料范围。这里不修改其归档、预载契约或运行中的计算，也不将本次材料点结果当作 r2 塌陷长程验收。

## 原版与历史修改的后续核对

用户提供的 Mendeley GeoDualSPHysics v1 已实际读取最少原文：原软化函数储存 devκ，但分母另用 full-flow 因子；其三个通常积分入口仍调用基本弹塑性函数，不能把“函数存在”当作软化已在这些入口生效。原版 float 应力及映射/导数也与现工程不同。完整原文和许可单独保存在 `tests/support/upl_material_original_geodual_r1/`，没有执行或替换工程。

retrogressive 历史记录进一步定位：`a698ce5` 修复三种系数/导数映射，`5d9fd84` / `0d70118` 接入 CPU/GPU 软化分派；`79982b3` 才把 soft 的 devκ 改为 full-flow shortcut。该阶段主要 dry 测试 φ=ψ=0，两种范数相同，不能据此判定非零ψ的新历史已经得到验证。旧记录还包含已移除的测试/诊断和过时重启说明，应按实际 commit 与现存证据解读。

常强/顶点组件已完成一次修复观测器后的独立检查：75点、35次三维旋转、22次一般候选的规则返回对照，最大解析应力差7.276e-12 Pa，连续κ差3.331e-16。原 r1 因7个纯静水旋转态的极小乘子归一化比值失败，真实退出1和原记录保留；r2改为有量纲的浮点误差界，候选本构代码不变，实际退出0/75点通过。两版除failure说明外34列逐项文本完全相同。详见 `upl_material_apex_observer_r2.md` 和原始/新收据。这里验证的是常强组件，不意味着 apex 已接入一般软化候选或生产源码。
