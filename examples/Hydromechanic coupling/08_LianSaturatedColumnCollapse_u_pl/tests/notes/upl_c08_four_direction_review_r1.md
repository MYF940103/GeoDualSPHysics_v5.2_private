# C08 四方向审计与下一项对照

本轮保留原 r2 GPU 10 s 预载、r5 ψ0 三秒结果及旧失败输出。未修改生产 C++/CUDA、正式 XML/BAT 或默认值；文档仅澄清三个已有接口的适用范围。核验采用必要的文件身份/stat，没有反复扫描原始 BI4 或 SHA。

## 人工应力

已对照 Bui2008 原 PDF pp.1552–1553、1563，Bui2011/2021 和 Lian2023 相关页。当前受测路径未发现明确的谱符号、张量槽位、重复除密度平方或旧阶段应力未刷新的错误。u-pl 使用当前总应力 σeff−pI，raw 人工应力为 −ε(σeff−pI)+，再乘当前体积/混合密度权重；它不是在 raw R 和 pair 两处重复除 ρ²。变 J 时该权重不字面等于 Bui2008 的 fixed-mass 形式，不能扩大一致性结论。

Bui2008 对其 Cubic、h=1.2dp 试验推荐 ε=.5、指数2.55；当前 .2 是仓库默认值。Lian 的 TPI α=.5 和剪胀衰减 sf=.2 不是 AS 系数。仅据文献取值不足以认定 .2 是脉冲根因。冻结局部算子中提高 ε 对部分状态有利，但 τ=.64 s 的内部块最大实部仅从 +2223.86 变为 +2191.20 /s，改善约1.47%，仍有增长方向。

下一项单独真实对照 `upl_c08_as05_window_GPU_r1`：仅 ε=.2→.5，指数2.55、dt2.5 μs、原 PRE、材料、边界、滤波阶段政策与其他设置保持。全部5000土粒真实演化至撤墙后 .66 s；66帧及三点阶段观测用于和已有 ε=.2 对照，不是新正式3 s或参数扫描，也不自动产生另一组半步长或其他ψ。

## 孔压继承

实际 source 为 r2 GPU `Part_1000.bi4`，时间10.000000000374257 s。按 native ID 比较已有源 VTK 与 r5 首帧：5000土粒 P0 全部 float32 位相同。三点真实初始阶段观测的 p 也与源相同，其中4956为1209.60791015625 Pa、5809/4959为零。代码按ID恢复全部主状态，排序后再次恢复；随后只清压力率与塑性增量 scratch，不清孔压。

r5 Part0 时间10.010000000377431 s，已有4000次新更新；相对 PRE 的 p 差 RMS5805.286 Pa、最大22621.156 Pa。因此两图看起来不同不能直接认定继承失败：撤墙后新暴露排水面会改变孔压。已有同色标图和5000行逐材料 CSV 在 `figures/upl_c08_preload_first_frame_compare_r1*`。本次真实导入瞬间尚无全5000点的独立 p 快照，不能用三点或 P0 一致冒称全场 p 逐位证明。源 VTK 的坐标为float，亦不声称原double坐标位一致。

## SoilTriggerFos

它是旧 `-partbegin` 软化重启的峰值黏聚力折减，不是撤墙定时器。当前 statefile 交接 PartBegin=0，Fos不触发；ψ0峰值黏聚力仍5000 Pa，未被除以1.65。retrogressive 的启动机制、材料和 `-partbegin` 不同。Lian土柱通过撤墙启动，故本轮不增加强度折减、不改已认证 PRE 合同。

## 其他技术与算子配套

应力率梯度修正、孔压压缩源项修正、人工黏性、AS和现有固定平面接触已经启用；独立SPR/HG尚不在当前Cubic/塑性/变k/撤墙资格范围，不能直接套开关。动态墙已有其导数镜像速度。PRE使用的Shepard/damping在撤墙时明确关闭；若以后考查继续Shepard，必须单独标明阶段政策及其非守恒平滑影响，不与本次AS对照混改。

八个实际保存状态的冻结压力块 A/B 已完成。仅将动量压力力改为 C-weighted、其余直接二阶/散度/AS保持时，16个all/FS0视图的最大实部均恶化；最大 +16849.72→+47234.42 /s。不支持直接合入这种局部改法。完全matched D/G数学控制在所有视图中保持负储能对称部，但它的常量/仿射/静水压力子算子action不为零；未包含独立重力/有效应力源及完整边界，不能由耗散证明精度或作为已实现方案。图及全部原结果见 `figures/upl_c08_pressure_pairing_plot_r1.png`、`upl_c08_pressure_pairing_ab_r1_summary.csv`。

后续顺序：先审 ε=.5 实际轨迹与原始安全门、孔压脉冲/塑性/应力/速度及形态；若未解决，优先围绕压力梯度—散度—加速度反馈的整套一致性继续低成本验证，不单改外载、不靠增阻尼或改强度贴合论文。Lian负孔压稳定式是另一个塑性演化模型，不能与AS或直接裁剪负压混称。当前同阶段接触反力进入Darcy仍未闭合，完整塌陷尚未物理验收。
