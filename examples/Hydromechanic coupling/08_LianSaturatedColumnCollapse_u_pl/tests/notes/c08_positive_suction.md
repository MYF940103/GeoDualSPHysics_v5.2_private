# C08 正压截断条件下的剪切带负孔压

本记录使用 +2.5°、三轮 TPI、β=0.04 的保留结果 `c08_psi25_tpi_paper_b004_r1`。撤墙后自由面粒子完成步表压为 min(p, 0)，内部压力由耦合方程更新。时间均从实际撤墙时钟算起。每帧包含 5,000 个材料粒子，固定材料编号用于追踪同一土粒。原 β=0 组用于观察负压历史项改变后的整个耦合响应。

## 低压出现在哪里

- 撤墙后 0.88 s，ID 6918 的表压为 −25.9343 kPa，位置为 (4.140, 0.176) m，FS=0。核支撑半径 0.144 m 内有 40 个土邻居，墙邻居数为零。36 个土邻居低于 −20 kPa，邻居中位数为 −23.18 kPa。
- 全部释放保存帧中有 3,305 个低于 −20 kPa 的粒子时刻。3,286 个同时具有正的累计塑性应变且位于该帧累计塑性应变最高的 10% 内，96 个属于自由面。该统计含同一材料点的重复采样，累计塑性应变表征塑性历史。
- 原固定右列的 49 个新暴露材料点在释放前为正压，两个原有表面政策均在首个 5 µs 将其清零。保留政策与全零政策的首步差别始于原已暴露的顶角 ID 7059，前者记录 −8.05 Pa。全零对照组后来出现的 −308.55 kPa 极值有不同的材料编号和墙邻域。

## 剪胀与水力响应

固定材料点 6918 由撤墙时的 +16.41 kPa 降至 0.88 s 的 −25.93 kPa。此时原生 J 给出对数体积应变 6.65866%。按同一平面应变 Drucker–Prager 塑性流动方向，对实际 κ 积分得到塑性体积应变 +6.87892%，平均有效应力变化给出弹性应变 −0.22034%。两者之和为 6.65858%，与保存 J 的差约 0.000071 个百分点。该结果验证此材料点的体变与其实际塑性历史一致。论文精度仍取决于剪切带的位置、宽度、流动强度和水力回补。

估计使用 β=0.04、α=0.5、γw=9,806.65 N/m³、端点相邻物理步压力以及 ln(Jb/Ja)，并假定中间每个物理步的负压历史项持续生效。保存帧仅间隔约 10 ms。区间内 β 的逐步触发、每轮水力空间项和加速度不能从区间端点单独反演。固定保存场重新组装的 0.88 s 行中，体变、土邻压力差和墙邻压力差分别约为 −464、+336 和 0 Pa/(m·s)。

用同一邻域对比论文式 (24) 的邻居孔隙率权重和由 J 演化的本地孔隙率，在 0.88 s 的 ID 6918 得到 dn/dt 瞬时估计分别为 0.02688、0.02879 s⁻¹。早期时刻两者的偏差方向发生变化。论文式 (25) 的体变源项没有额外的 (1−n_j) 因子。

## 与 Lian 等图 16 的现有差距

在撤墙后 1.20 s 表压小于 −20 kPa 的 56 个计算粒子位置中，54 个能在论文图 16 的有效颜色范围内取样。这些共同位置上计算中位数 −21.89 kPa，图上约 −0.91 kPa，逐位置差的中位数为 20.97 kPa。0.50 s 的可读交集为 8 个点，两个中位数分别为 −21.63 和 −7.09 kPa。该比较按空间坐标配对，受印刷色带精度及两种滑塌轮廓差异影响；按低压筛选的子集不能代表全域平均精度。

## 独立逐轮观测

`c08_positive_round_observation_r1` 使用同一预载、输入、步长、自由面政策和三轮 TPI，私有主机观测对象用于输出迭代历史。链接保留 112 个原始对象，包括全部原有 CUDA 对象。观测 ID 为 6868、6918、6919、6920、7010，计划在撤墙后 0.30、0.88、1.20 s 各保存三轮真实力阶段输入。使用 `c08_positive_actual_rows.py` 逐项重构。在 ID 6918，真实起始 +16.407 kPa，首个 5 µs 后 +17.457 kPa，第七步仍为 +0.380 kPa，第八步（40 µs）降至 −0.379 kPa，此步以正的上一步压力进入，β 项尚未激活。当前阶段的累计体变及全场结论来自此前完整基准结果，新增观测的全窗口同轨与压力预算待终态审查。

读回时应先看实际求解返回和已有原生审查文件。新审查器按原格式核验时钟，释放前的四个 PART 均没有 `GravityPreloadActualTime`，撤墙后该字段须在两份中均存在且字节相同。正在运行的 Python owner 载入了只接受该字段始终存在的旧版离线检查；若求解成功而检查仅因该字段中止，保留原终态记录，使用修正版的 `verify` 只读检查已保存的 132 帧，并保留新的独立收据。
