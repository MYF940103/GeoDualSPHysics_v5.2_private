# Two saved wall stencils: one nearest-donor centroid candidate

Only this note and `support/c08_h18_wall_centroid_candidate_r2.py` are authored.
No script, rendering, build, solver, native reader, hash scan or Git is run.
No successful saved34 helper, bound note, prior artifact, public source or
private diagnostic program is changed. Root fully reads before one offline use:

```text
D:/anaconda3/python.exe -X utf8 -B tests/support/c08_h18_wall_centroid_candidate_r2.py --execution-authorized
```

Fixed fresh prefix `c08_h18_wall_centroid_candidate_r2` produces comparison,
donor and consistency CSVs plus one PNG in `tests/figures` and one check in
`tests/logs`. Existing matching complete/partial outputs prevent another use.
The study consumes only already qualified AS.3 partial90 and AS.7 partial34
reviews through the exercised `options.load_option()` and reads only their last
typed22 states with `old.read22()`: Part89/wall893 and Part33/wall803. Both must
retain the same original source/PRE/material/program/plan context. It does not
read BI4 or rerun source qualification.

Original GP and nearest retry are recomputed with the unchanged r1 pure
Wendland `kernel()/fit()`, H=.072f, native J volume weights, original .001
determinant and saturated J gates, and original mirror from each failure log's
fixed B plus float normal. Only the known valid-donor primary geometry-failure
configuration is supported. The original evaluation target remains that GP.

One candidate centre is formed from the existing nearest fit's visited donor
set, using its original positive W*V weights. There is no iteration or scan of
candidate centres. At that centre the unchanged fit/kernel rescans the full
saved soil set and evaluates back at the unchanged original GP. Thus weights
and possibly support membership change: the CSV explicitly reports newly added
and lost donors versus nearest, centre shifts, actual donor weights/J ranges,
determinant/margin, raw condition and extrapolated J/domain margin. Improvement
cannot be called a pure coordinate transformation or credited to recentering
alone when membership also changes. Zero-weight donors do not determine the
centroid; the full original support rule remains used by each fit.

Constant and affine tests are separate from native J/stress/pressure. They use
all11 manufactured dimensionless slots with known original-GP values while
retaining actual native J as the quadrature weights. Geometry-rejected fits
retain null results; no error or condition acceptance threshold is added.
Manufactured recovery demonstrates only algebraic consistency of those saved
templates, not accuracy for the nonlinear native fields.

The positive weights place the centroid within their convex hull. They do not
make effective MLS reconstruction weights positive, guarantee extrapolated J
is bounded by donors, close conservation, or establish contact/trajectory
stability. This is an offline candidate operator study, not a solver change or
a recommendation to lower gates or delete an active wall. Both original runs
remain failed; the available last saves are earlier than their unsaved rejected
stages. Actual cell traversal, packed PosCell/FMA and nearest-tie visitation are
not replayed. A favourable saved candidate cannot repair or identify the actual
terminal branch. Root must first assess the independent private terminal
diagnostic; no implementation, solver or parameter choice is automatic.
