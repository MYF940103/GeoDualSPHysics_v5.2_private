# Two-entry unified DP material candidate r1

Author-only test header: `tests/support/upl_material_unified_candidate_r1.h`, namespace `fsoil_unified_candidate_r1`. No production/source/build/run/package changes. It combines the inspected general-r1 coefficient/derivative expressions and the fixed-strength apex-r1 policy; prior executed candidates and observations remain unchanged. This new combined header has not yet been compiled or executed.

The two entries are `ConsRelationEP(state,K,G,DP_phi,DP_kc,DP_psi)` and `ConsRelationEPsft(state,material,fit)`. Both use one return flow, commit routine and apex routine. `DP_PS`, `DP_C` and `DP_MC` retain their existing meanings. Physical names and float material inputs/saved kappa are retained; coefficient, root and tensor operations are local double. No native adapter, XML option, alternate material selector or spatial admission is added. A soft entry whose phi/cohesion/psi do not evolve takes the same closed-form branch as the basic entry with the same evaluated coefficients.

For smooth return, `kappa=old+lambda/sqrt(3)`, `I=I_trial-9*K*DP_psi(kappa)*lambda`, and `F=q_trial-G*lambda+DP_phi(kappa)*I-DP_kc(kappa)`. Its exact scalar derivative is `-G-9*K*DP_phi*(DP_psi+lambda*DP_psi_k/sqrt(3))+(I*DP_phi_k-DP_kc_k)/sqrt(3)`; I here is the returned trace. This is a scalar return derivative, not an assembled consistent tensor tangent. The retained root budget is `1e-10*max(1,q_trial,abs(DP_phi_old*I_trial),abs(DP_kc_old))` Pa, with at most 80 safeguarded Newton/bisection evaluations. The original common elastic classification `F_trial<1e-5 Pa` remains, including a small positive-yield interval; no new threshold is introduced.

Both phi inputs may be zero, including a zero residual angle. Alpha zero is a cylinder without a finite cone tip; the fixed branch returns radially without dividing by alpha. Identical hydrostatic diagonal inputs give q exactly zero through the pair-difference invariant. No q division is performed on a zero-q path. This invariant evaluation is algebraically equivalent to the old mean/deviator expression but is not claimed bit-identical to it for arbitrary tensors.

At a cone tip the deviatoric increment saturates: `kappa_tip=old+q_trial/(sqrt(3)*G)`, including zero increment for pure hydrostatic input. All tip coefficients are evaluated at this continuous history before float storage. For positive beta, a genuine single-potential apex is preferred if `lambda_A=(I_trial-I_tip)/(9*K*beta_A)>=q_trial/G`, where `I_tip=DP_kc_A/DP_phi_A`. Otherwise the explicitly separate existing tension-face policy is tested: `lambda_s=q_trial/G`, `lambda_t=(I_trial-I_tip)/(9*K)-beta_A*lambda_s>=0`, with `f_t=I-I_tip`, `g_t=I`. This is reported as `TensionRepair`, not as a solution of the original single potential. Negative-beta repair is not claimed to guarantee nonnegative plastic work. The old policy's tip value is retained, not a new independent tensile-strength parameter.

Genuinely evolving softening still requires a conservative interval-wide monotonicity certificate. The general-r1 absolute-value bound is tightened without changing F: on `k in [old,old+L/sqrt(3)]`, alpha decreases from alpha_old to alpha_end and `B=beta+lambda*beta_k/sqrt(3)`. For nonnegative psi, `B>=beta_end-L*sf*abs(psi_old)/sqrt(3)`; for negative psi, `B>=beta_old` because beta_k is nonnegative. If that B lower bound is nonnegative use alpha_end, otherwise alpha_old, to bound `-9*K*alpha*B` above. The original absolute upper bound on `(I*alpha_k-kc_k)/sqrt(3)` is retained. This preserves the stabilizing positive-beta term, including when sf=0, which the prior absolute-value certificate discarded. Rate-zero exponential evaluations are deliberately left unchanged to preserve the validated coefficient operation groups.

A certificate failure returns `UnresolvedPath` with the original state; it is neither a proof of physical nonexistence nor permission to jump to an apex. Only a certified path with positive endpoint F excludes its entire radial interval before the shared apex policy is considered. Pure hydrostatic input has no radial interval and goes directly to the tip policy. Multiple-root/uncertified continuation is explicitly still unresolved; this is not yet a general production-complete material. No extra rejection layer or silent old-history projection is added.

Successful states are Elastic/Smooth/Apex/TensionRepair. Invalid, NoAdmissibleFlow, NonConverged and UnresolvedPath preserve all input state members; failure diagnostics may change. Commit checks finite stress/history/multipliers and float-saved history nondecrease. Continuous root residual and float-history storage residual must be assessed separately by the later probe; neither is spatial solver accuracy. The fixed 75-point apex evidence belongs to the prior fixed candidate, not to this unexecuted combined header. The next already-authorized component stage is a common two-entry/three-fit matrix, phi-zero and threshold witnesses, continuous/saved history and compliance checks, plus explicit unresolved-path observations; no new spatial/half/reference chain is implied.
