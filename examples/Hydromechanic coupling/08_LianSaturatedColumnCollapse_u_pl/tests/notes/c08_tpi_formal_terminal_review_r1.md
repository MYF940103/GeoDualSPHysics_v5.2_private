## −5° 的首次终止

GPU `JSphGpuSingle::DtVariable` 的 `final=1` 阶段在日志步号 2,072,052 拒绝固定 5 µs。当时记录孔压扩散界 4.999917080722533 µs、变渗透率梯度界 49.05726208150041 µs、波速黏性界 116.79084848128863 µs。原退出码 1。最后有效保存为 `Part_0047.bi4`，完成步 2,070,200。该帧前缘 x=4.577117 m，顶层沉降 124.61 mm，最低表压 −49.77 kPa，最小 J=0.78453，最小孔隙率 0.17148。47 个已保存状态通过各自的时钟、材料 ID、孔压历史、自由面、J/n/rho/k 和短窗 12 帧前缀检查；终止子阶段的未保存状态仍未知。[原日志](../../CaseLianCollapse_psim5_TPI_GPU_out/Run.out)

正式私有程序的 `link.rsp` 绑定 `c08_m0_gpu_coupled_r1_build` 的 `JSphGpu.obj` 和 `JSphGpu_ker.cu.obj`。这些对象的捕获源码对第 i 个土粒使用 Dᵢ=Kw kᵢ/(nᵢρw g)；运行取 PoreDtSafety H²/max(Dᵢ)。kᵢ 为随 J 演化的值。末帧最小孔隙率点 ID 7010 按旧公式得到 5.144514 µs，同最后一个完整保存段的日志下限一致。按现行源码的初始 k₀ 估计，同一保存态点为 4.358743 µs。前者确认了已运行版本的离散，后者只代表保存态上的另一估算。终止子阶段的限制粒子 ID 未保存。实测下限从撤墙后 0–0.01 s 的 8.8816 µs 逐步降到 0.34–0.35 s 的 5.1445 µs，然后触发原保护。单纯将 5 µs 下调到刚低于报错值，只有很小的局部裕量。后续准入需明确选用的时步口径和孔压历史配套，现有门槛保留。
