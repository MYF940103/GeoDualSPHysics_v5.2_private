# C08 近墙矩阵重构：实施验证阶段

2026-11-16。当前为候选修正，尚未完成新的 3 s 塌陷或论文精度验收。

## 已定位的问题

原 optimized-HG full3 与 host-only replay 均真实失败，退出码 1。最后完整保存状态为 completed step 2196001、t=10.980004999668907 s；报错指向随后未保存的 stage1、native ID 894。异常捕获是设备拒绝之后的输入快照，不包含被拒绝的拟合矩阵寄存器，不是新的已保存状态。

原 GPU 内核对同一捕获输入进行两项查询：实际流体 C 场报告 aggregate invalid=690（native 894）；仅将流体 C 改为单位阵时报告 invalid=Np=6805。两项 memcheck 均无内存错误/泄漏。单位阵仅用于因果定位，未用于物理计算。

独立重算显示，原 G 附近 17 个有效 donor 的几何矩阵 det≈0.001000025，非常靠近原 0.001 门槛。各 donor 的 C 合格，但外推得到的目标 C 的 xz 行列式约 −0.02522。不能据此宣称已读取原 GPU 的中间寄存器或原失败分支。

## 最小候选修改

仅修改 `src/source/JSphCpu_mdbc.cpp` 与 `JSphGpu_mdbc_ker.cuh`。对非周期二维动态墙，有限且非正的重构 C 行列式也可触发**已有的一次**最近真实 donor 重试；仍在原 G 处评价。CPU 不在重试前提交不合格矩阵。

原几何阈值 0.001、有限性/J 拒绝、最终 detC>0 门槛及最多一次重试均保留。未增加单位阵、质心、截断、第三次拟合或 XML 参数。正行列式不等于一般 SPD 保持或全局 Darcy 耗散证明。这是数值路径修改，不能预先假设重新编译后所有字段均逐位不变。
