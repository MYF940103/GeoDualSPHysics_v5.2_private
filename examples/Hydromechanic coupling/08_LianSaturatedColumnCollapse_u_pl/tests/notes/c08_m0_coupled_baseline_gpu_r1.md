# C08 成熟预载撤墙后的三轮 TPI 对照

目标是检查从同一个原生预载出发，负压控制会怎样改变 ψ=0° 柱体的运动、孔压和间距。采用 5,000 个土粒、Wendland 核、H/dp=1.8、5 µs 和随体积变形演化的渗透系数。接收程序先读有限水体积模量、同材料 schema2 的 10 s 预载，并在 GPU 下载核对主要状态。初始时前一时层压力取各粒子实际总孔压。经过 200 步闭墙适应后才移除原 ID 1805 至 2059 的右壁，保留 1,805 个固定边界点。释放时开启总应力人工应力 0.3/2.55、固定面法向不穿透，关闭预加载阻尼与 Shepard 滤波。两个分支都是三轮 M0，唯一改变的物理参数为 β=0 或 0.04 m⁻¹。固定面投影的同阶段 Darcy 反力尚未闭合。

实现沿用早前核验的变 k、β CUDA 核及 111 个目标文件，单独重编模型配置与 GPU 单卡调度的两个 C++ 单元。有限 Kw 的原始对照直接从 10 s PRE 撤墙，额外的 1 ms 闭墙适应及冷启 TPI 历史是比较条件的一部分。两种 TPI 算法在完全相同的几何、材料、荷载和适应时间下比较。

旧有限 Kw 结果来自原来的 GPU 程序，两条 TPI 轨迹共用当前私有 GPU 程序。跨程序比较可衡量实际结果与保留基线的距离。单独归因于 β 的依据是同一程序、同一适应时间的两条 TPI 轨迹。

两个单独的短测试覆盖闭墙 200 步与真正撤墙后 8 步。每组检查 12 个保存时刻的 22 个原生数组、1,040 次步长限制、624 轮压力更新及释放前的 5 次 Shepard。两组均在 10.000999999705970 s 释放，最小步长上限 8.88974425 µs。材料的两时层压力跨退墙操作保持，11 个相邻保存时刻按 ID 核对了每个土粒的上一时层。原生文件同时记录了人工应力、不穿透启停和参数值。[短测核验](../logs/c08_m0_coupled_baseline_gpu_r1_short.check.json)

0.3 s 窗口按撤墙后的每 0.01 s 输出，同时留存模型交接处及释放后头 8 步。物理审查采用实际保存时刻，核对固定墙、压力历史、孔隙率及渗透系数，分别统计材料位移、压力分位数、剪切塑性历史和小于 0.7 dp 的最近邻距离。Lian 图 14 的 ψ=0° 有色区域仅作为主体外轮廓比较。轮廓数字化约为 ±0.036 m，粒子中心与着色轮廓另有约 0.02 m 表示尺度。该图未给出可逐 ID 对照的总孔压或塑性历史场。[运行与重建](../support/c08_m0_coupled_baseline_gpu_r1.py) · [原生审核](../support/c08_m0_coupled_baseline_gpu_review_r1.py) · [物理分析](../support/c08_m0_coupled_baseline_gpu_physics_r1.py)

压力变化还按固定材料 ID 统计相邻采样压力增量的反号次数、采样压力的二阶差分 RMS，以及沿采样路径累计的绝对压力变化减去首尾绝对差。后者保留高低往返变化，单调演化为零。三者仅覆盖每 0.01 s 的实际输出。更短时间尺度上的脉冲峰值仍可能落在保存时刻之间。

### 撤墙后 0.30 s 的结果

两次完整窗口均采用本机 RTX 3050。各完成闭墙适应 200 步及撤墙后 60,000 步，原生保存 42 帧。最终时钟 10.300999999694612 s，撤墙后实际时间 0.299999999988643 s。各有 180,600 轮压力更新和 301,000 次步长检查通过，β=0 和 0.04 的最小步长上限分别为 8.8573 和 8.8663 µs。每组都检查了全部材料 ID、22 个主数组、压力历史、排水、变 k 及固定面几何。与各自短窗共有的 12 帧逐 ID 比较了主数组和历史压力，另在原 BI4 头部直接比较了双精度时间与带符号的 dterror 字节。GPU 循环实测分别为 1,355.43 和 1,343.20 s。[完整窗口核验](../logs/c08_m0_coupled_baseline_gpu_r1_w30.check.json) · [逐帧记录](../figures/c08_m0_coupled_baseline_gpu_r1_w30_native.csv)

开启 β 后，0.01 s 采样捕捉到的最强负压减轻约 73%。但全体压力二阶差分 RMS 增加 4.5%，自由表面呈负压的材料点增加 9 个。末态两条 TPI 轨迹共有 614 个负压材料点，原负压中 497 个转为非负，另有 123 个材料点开始呈负压。两个分支的同材料末态压力差 RMS 为 1.344 kPa、位移差 RMS 为 8.20 mm、最大位移差为 50.57 mm、有效剪应力 σxz 的差值 RMS 为 1.114 kPa。两条轨迹仍可辨识剪切带。原有限 Kw 与 β=0 的同材料位移差 RMS 为 0.269 mm，配对点在撤墙相对时钟上差 5 µs。[压力和沉降历程图](../figures/c08_m0_coupled_baseline_gpu_r1_w30_history.png) · [历程数据](../figures/c08_m0_coupled_baseline_gpu_r1_w30_physical.csv)

这次可以验收模型交接、三轮压力更新、变 k 以及原配接触配置在 ψ=0° 的 0.30 s 独立物理窗口内协同运行，也测得 β 对极端负压的作用。β=0.04 的最小间距在 0.25 s 曾低至 0.462 dp，至 0.30 s 仍有 37 个粒子低于 0.7 dp，且滑移、塑性和负压区域随之变化。保留两套私有对照及证据，暂缓把该系数设为公共默认、宣告团聚解决或推广到其他剪胀角。论文图 16 的剪胀组需要其自己的材料与预载；本次数据没有验证该组。[完整统计](../logs/c08_m0_coupled_baseline_gpu_r1_w30.physical.json)
