## Single scientific pass and quantities

R2 summary supplies the signed cumulative compression, Darcy remainder, source split, pressure-write, weight-change and actual positive-cap terms. One additional streaming pass over the175582576-byte sidecar sums the unsigned rate-quantization bound and accumulated absolute increments per state, and extracts only fixed material IDs4953/4954/6767/6865 (364 rows). It does not re-run the5000-ID endpoint budgets or pressure/J checks.

S=sum(nV*p/Kw) is a conditional linear pressure-storage proxy in m2 per unit depth, not fluid mass. Native p-fixedP0 is not the paper's plastic-dilation excess, and this script does not plot it as that field. Compression is the observed wn*h*comp partition, not automatically -V0*h*Jh*theta. Darcy remainder includes rate quantization; the bound is unsigned, separately labelled and never added as a measured source.

Directly read final R2 summary values are: initial S=2.74750645924e-5, final S=-9.05545549914e-6, compression=-8.90690964760e-5, Darcy remainder=+7.26318884331e-5, cap=-2.00499632103e-5, weight=-4.33664300376e-8 and pressure-write=+1.75917022974e-11. These are strongly cancelling signed contributions, not root-cause percentages. The scientific script derives all intervals from the actual complete data, rather than fitting these values.

Intervals use genuine endpoints PRE, Parts0/10/30/38/60/76/90. They preserve actual source/end times and completed steps. PRE-toPart0 includes release plus the first update; the sidecar records release-cap counts but not a separately signed release-cap amount, so total first-save cap cannot all be attributed to wall removal. Parts38/76 mark the previously reviewed first saved .7dp crossings of the selected two pairs; they are not all-soil first events or exact substage onset times. Correlation with a contribution does not establish causation.

Global and each fixed-ID interval tables retain every signed partition, net delta S, unsigned bound increment, sum of absolute signed-partition changes and ledger-minus-net residual. No contribution/net percentage is reported when terms cancel. Roundoff bookkeeping and the unsigned bound are not physical sources or automatic evidence of a resolved instability.
