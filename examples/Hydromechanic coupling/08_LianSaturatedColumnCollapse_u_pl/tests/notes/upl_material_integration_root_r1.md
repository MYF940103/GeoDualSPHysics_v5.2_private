# Experimental material-return integration

2026-11-06. The production candidate retains LegacyFast as the default and exposes `MaterialReturn=1` and optional `DilationDecay` only as an experimental, independent material choice. It does not automatically select a new material when dynamic seepage is enabled.

Changes: `FunSoilMaterial.h` contains the verified fixed-phi DP_PS endpoint return and explicit native-tensor adapters. `StSoilCte` appends one unsigned selector and one float decay constant; all original material constants and persistent kappa remain float. `JSph.cpp` reads, checks and logs the controls, and writes their metadata only when enabled. `JPartsLoad4.cpp` rejects the experimental material metadata on PART restart, including when the new run requests the old material. The two VS project/filter pairs expose the new header in the existing Source group.

CPU and GPU Symplectic Pre/Cor select the shared return explicitly. Predictor keeps the original kappa; corrector commits its returned kappa. Invalid, unsupported-apex and nonconverged returns reject the stage without substituting an elastic/capped answer. GPU owns one four-byte status word per candidate run, rather than a particle-sized status array. Other threads and earlier predictor p/J preparation may already have changed intermediate arrays: failure is fatal, not a rollback or valid restart state. No Verlet path, SPH force, pressure equation, J integration formula, boundary law or existing dynamic plastic admission was changed.

Both authoritative Debug builds passed with zero errors (CPU54/GPU55 existing warning lines). The same71 standalone material cases passed on CPU and GPU. Actual CPU stages exercised two Pre/two Cor calls: kappa.5 stays unchanged in Pre and becomes.50007367134094238 in Cor; stress matches the retained tensor, and a manufactured ApexNeeded produces real corrector mask8 with no failed-particle native write and no movement-scratch leak. Actual GPU wrappers passed142 calls,54 Pre/54 Cor history checks and34 failure-no-write checks; same-input stress difference is0Pa, memcheck reports zero errors/leaks. These are bounded implementation checks, not spatial plastic accuracy.

These runs are elastic startup controls, not a performance benchmark or collapse validation.
