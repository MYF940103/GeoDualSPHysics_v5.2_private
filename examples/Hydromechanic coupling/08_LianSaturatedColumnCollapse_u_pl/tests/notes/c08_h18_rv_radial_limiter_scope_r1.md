# C08 RV 径向限幅候选：只读数学范围

本记录是根线程正在进行的机理诊断所对应的**独立数学候选**，不是已实现的 CUDA 算法，不是文献原公式，也不是 C08 的物理修复或正式参数选择。根线程须先完成现有真实材料近对的起始受力证伪。本任务仅新增本说明；未修改或运行源码、脚本、求解器、读取器、VTK、构建、Git，也未新增参数扫描或自动任务。

## 问题与明确假设

当前额外 RV 力在 `tests/support/c08_h18_rv_gpu_r1.cu:118–134` 使用两个局部 LS 重构残差的向量平均。它的全局耗散来自 LS 正交性及其数值证书；**全局耗散不等于每个实际靠拢近对都受排斥**。当实际径向速度为负而平均残差的径向分量为正时，原 RV 对该对的径向力会向内。

以下构造只讨论固定一次 force stage 的互反土–土邻接图。假设：

- 每条无向边的两个方向都存在，使用同一个正且对称的权重 `beta_ij=beta_ji>0`，alpha 为固定非负数。
- 位置不重合，`r_ij>0`；局部 LS 矩阵有效。保留现有重合、秩、条件性、几何和所有物理安全门，不用新的分母正则化掩盖重合。
- 本阶段的正质量 `m_i=rho_i*V_i`、位置、邻接图及权重视为冻结。当前动态混合质量和图会在真正计算中变化，故该假设不跨阶段延伸。
- `L_i` 是当前速度的局部仿射重构，不改变它以强行激活稳定项。当前物理 AV、应力和 Darcy 算子不在本候选内替换。

## 定义：限制残差，不缩小重构斜率

固定无向边 `(i,j)` 的规范方向，令

```
d = x_i-x_j;  r=|d|;  n=d/r
dv = v_i-v_j
s = dv dot n
q = [dv - 0.5*(L_i+L_j)*d] dot n
a = min(max(-s,0), max(-q,0))
F_ij = alpha*beta_ij*a*n;   F_ji=-F_ij
```

`s<0` 表示真实粒子靠拢。只有 `s<0` 且 `q<0` 时才有正的径向外推力；`s<0,q>0` 时关闭原来可能向内的分量。这里保留的是**额外项**的仿射零模性质，不能称原物理 AV 与整个系统也仿射零模。

若一个精确仿射场满足 `v=A*x+b`，且 LS 正确恢复 `L_i=L_j=A`，则 `q=0`，本候选力为零，包括仿射压缩、剪切、平移和旋转。有限精度只能要求按独立误差界得到相应的小残差/小力，不能虚称计算位完全为零。

该条件也给出一个直接的证伪点：**若实际新团聚对主要是 `s<0` 而 `q≈0`，严格仿射零模的候选本来就无力阻止其收缩。** 它不是无条件保持最小粒距的排斥势，更不能承诺修复真实局部压缩或强剪切造成的排列退化。

## 每对功、动量与角动量

精确算术下，每对对系统的瞬时功为

```
P_ij = v_i dot F_ij + v_j dot F_ji
     = alpha*beta_ij*a*s <= 0.
```

因此不依赖原向量 RV 的 LS 正交关系，即可得到这一对的非正瞬时功。力严格成对反向，净力为零。力平行于真实 `d`，故任意原点下的成对力矩为

```
x_i cross F_ij + x_j cross F_ji = d cross F_ij = 0.
```

这与原 RV 的非中心向量力和 LS 法方程力矩证书不同。没有必要把旧 `work+2*form`、法方程 contraction 或旧 torque-defect 预测式原样保留；这些恒等式对应旧算子，不能给新算子背书。

## 为什么必须有实际速度幅度 cap

在 `s<0` 时，可写

```
gamma_ij = alpha*beta_ij*a/(-s)
F_ij = -gamma_ij*(dv dot n)*n
0 <= gamma_ij <= alpha*beta_ij.
```

`s>=0` 时定义 `gamma_ij=0`。理论上使用该比值即可；实际实现不必在 `s≈0` 时做除法，直接计算有界 a 更稳妥。

若只用 `s<0 && q<0` 开关、随后令 `a=-q` 而不限制 `a<=-s`，则 `s→0-` 而 q 保持负值时 gamma 可无界。这样无法从旧 beta 的邻接度推得有限的显式时步上界。`min` 幅度 cap 正是这一上界所需条件，不是可省略的装饰限幅。

若最终需要按前向误差证明加入很小的符号/残差不确定带，它必须来自实际 dot/normalization/LS 的误差界，并保留 `0<=a<=max(-s,0)`；不能把新的经验 deadband 拟合到 C08 图形。

## 冻结图与质量下的显式能量界

令 `P_ij=n_ij n_ij^T`。固定当前 gamma 后，所有边形成对称正半定的向量图 Laplacian K，满足 `F=-K*v`。质量矩阵 `M=diag(m_i I)` 为正，`A=M^(-1/2) K M^(-1/2)` 对称正半定。对任意向量，可由 `|u_i-u_j|^2<=2(|u_i|^2+|u_j|^2)` 得到保守界

```
lambda_max(A) <= 2*max_i [sum_j gamma_ij / m_i]
              <= 2*alpha*max_i [sum_j beta_ij / m_i].
```

对仅含这一冻结额外算子的前向 Euler 更新 `v+=dt*M^(-1)F(v)`，若 `dt*lambda_max(A)<=2`，则质量加权动能不增加。一个更便于保守检查的充分条件是

```
dt*max_i(sum_j gamma_ij/m_i)<=1
```

或以其 alpha/beta 上界替代。虽然上界数值形式可能与旧 degree 门相近，**这是一个新的证明，不能沿用旧证书即宣称成立**。

即便 gamma 是当前 v 的非线性函数，对这一次从同一 v 计算 gamma 和 F 的 Euler 更新，仍可把该次 K 冻结来使用上述一步结论。但不能把它自动推广到真实 pre/cor：几何、J、质量、局部重构、限幅活动集都会变化，且动量还含原力、重力和动态 Darcy 耦合。仅在两个阶段都恰好使用同一个固定线性 A 时，显式中点多项式 `1-z+z^2/2` 才能直接使用 `0<=z<=2` 的相应界。真实非线性 coupled pre/cor 不是这个特殊情形。

因此，新候选若实现，瞬时 pair 功和冻结独立算子界只是必要的限定证据，**不等于完整 u-pl 离散总能量稳定性证明**。保持原必要步长门，不能据本式放大原计算步长。

## 必须重新建立的数值证书

1. **反向对一致性**：每条无向边采用固定 ID 方向、固定乘法/归约顺序和同一个 beta、a、n；交换 i/j 后必须得到相反力。不能仅依靠实数公式而忽略两个独立 CUDA 路径的舍入差异。重合拒绝、反向邻接和完整 ID 门保留。
2. **新功恒等式**：独立累计 `D=sum_unordered alpha*beta*a*(-s)>=0`，并检查节点功 `sum_i v_i dot F_i` 与 `-D` 的一致性；同时明确没有内能/孔压历史接受这份数值耗散。旧 RV 的 LS 残差平方 form 恒等式不适用。
3. **中心力与零净力**：验证无向对力及力矩，再独立验证节点累加后的净力/总力矩。误差预算区分单对运算、邻接累加和全局归约。
4. **真正的误差计数**：新单位向量包含 sqrt/除法，q 包含易抵消的重构减法，min/max 与符号判断处于非光滑点。应按实际计算图推导 dot、LS、normalization、力与归约的前向误差界；min/max 的 Lipschitz 性可界定近零分支影响。不能把旧 `64*(N+E+dmax+1)*eps` 原样换个标签。
5. **FMA 与提交**：当前旧 RV 曾出现 Release 的严格抵消证书差异，说明必须绑定实际编译收缩策略。新私有 TU 若存在，需独立证明真实生成路径；不能把其他二进制的 Debug 结果当 Release 位真值。将双精度 F/m 加到原 float Ace 后，应重新核对真实提交增量 `m*(Ace_new-Ace_old)` 的功、净力、力矩和舍入误差，原理论中心力不保证 float 提交仍严格中心。
6. **制造与边界测试**：平移、完整仿射、纯压缩、纯剪切、刚体旋转、非均匀体积/质量、交换对和四种 s/q 符号组合；cap 超限情形及 s 接近零情形。制造测试需要实际数值误差界，不能硬编码将制造残差清零。此范围仍是土–土；没有补齐固定墙反力、真实物理应力或 Darcy 的互相功闭合。

## 与文献的关系及不能照搬之处

[Rosswog 2020, MAGMA2, §2.2.1, Eq.14–23](https://academic.oup.com/mnras/article/498/3/4230/5897370)，DOI [10.1093/mnras/staa2591](https://doi.org/10.1093/mnras/staa2591)，使用粒子中点的重构速度差计算人工粘性，并使用斜率限幅。这为“抑制不必要的光滑场耗散”提供直接文献关联。本记录的双符号/幅度限制则是根线程候选的独立推导，**不是该论文的原式**。

特别地，不能将其斜率因子 Phi 直接乘到 Li/Lj 后仍宣称本候选仿射零模：对于真实仿射压缩，若 Phi<1，就有 `q=(1-Phi)*s`，额外力不再为零。该论文 Eq.21 的近距离因子还会在近对主动减弱重构。因此若选择仿射零模，应限制已得到的残差 q，而不是简单削弱重构斜率；若有意采用其近对恢复耗散策略，则必须承认数值性质和目标已改变。

[SPHinXsys 官方 theory](https://www.sphinxsys.org/html/theory.html#wcsph-method-based-on-riemann-solvers) 的 WCSPH 使用连心方向的 inter-particle Riemann 问题计算连续与动量作用；[Zhang, Hu & Adams 2017](https://doi.org/10.1016/j.jcp.2017.01.027) 的低耗散 Riemann 方案以 limiter 降低膨胀/压缩波中的不必要耗散。这支持“径向、按压缩状态启用、有界耗散”的设计类比，不能证明本候选已等价于该 Riemann 求解器，更不能由其流体 benchmark 推出塑性 u-pl 修复。

官方 theory 的 transport-velocity 还明确区分物理速度和输运速度并包含附加应力；这与仅改变位置的旧 shifting 不是同一实现，详见本目录 `c08_h18_shifting_compatibility_audit_r1.md`。

## 根线程下一步判据

先用已经保存并独立解码的真实轨迹/冻结源算子检查，新团聚起始近对是否确实在原 RV 中存在可观的向内分量、以及有界新候选能否对这些对产生可观的向外响应。若主要靠拢是 `q≈0`、纯切向或本候选未激活，不应为了得到“有效”而继续调 alpha；应承认此候选未击中机制。即使冻结响应更合适，仍需完整实现回归和独立物理窗后才能判断，而不能自动解锁另外两组 psi 或正式全程。
