# C08 三轮 TPI 的闭墙启动和首次负压触发

真实 C08 的 5,000 个土粒随变形更新渗透率。私有 CPU/GPU 候选在三轮端点迭代使用当前土粒的水力传导系数，并保留传导系数空间梯度的贡献。在已保存的显式轨迹中单独去掉该梯度项，撤墙后 0.38 s 和 0.76 s 的一次压力写回分别有 2,885 和 3,755 个粒子发生改变，最大差值分别为 2.034 和 17.230 Pa。完整物理行送入 GPU 后，30,000 个冻结更新结果与 CPU 逐位相同，其中有 6 个负源压力行。[行级复算](../logs/c08_m0_pressure_cuda_r1.check.json)

## 闭墙启动的两端实算

从零应力启动，在同一初始几何上各跑 42 步，步长 5 µs，每端分别采用 β=0 和 β=0.04。逐一对齐 43 个保存时刻的全部 7,060 个原始 ID，检查 22 个数组、压力历史及第 40 步 Shepard 滤波。每个 GPU 运行的 210 次步长限制检查均通过，最小上限为 8.897 µs。两端最大逐帧孔压 RMS 差为 0.00132 Pa，单粒最大 0.00977 Pa，材料位移最大差为 5.64×10⁻¹⁰ mm，自由面分类差数为零。独立的 GPU 两步内存检查报告 0 错误。这段时间没有负源孔压。[逐帧两端比较](../figures/c08_m0_gpu_coupled_r1_cross.csv) · [CPU 双轨对照](c08_m0_beta_compare_pre42.md)

## 两种初始状态给出的不同证据

提前撤墙的 CPU 实施试验在第 40 步退役 255 个右墙 ID，留下 1,805 个边界粒子和全部 5,000 个土粒。49 个新自由面粒子在撤墙瞬间仍带有 647.48～28,339.09 Pa 的旧压力，正压在下一整步第三轮才投影。第 48 步有一个符合式（47）的负源压力；β 从 0 改为 0.04，末步最低孔压从 −17.702 变为 −14.660 Pa。这个窗口只包含 40 µs 的撤墙运动。[β=0 原生记录](../logs/c08_m0_release_short_r1_b0.review.json) · [β=0.04 原生记录](../logs/c08_m0_release_short_r1_b004.review.json)

以真实有限 Kw 的 10 s 预载末态冷启 M0，并继续闭墙 1 ms，末态相对预载的孔压漂移 RMS 为 2.238 Pa，速度 RMS 从 4.151 降至 3.774 µm/s，最大速度从 5.807 升至 8.713 µm/s。该试验可以度量切换模型后的初始调整。滑塌前缘、剪切局部化和持续孔压振荡需在撤墙后的实际动力时段独立评价。[闭墙衔接图与分层数据](c08_m0_beta_compare_hold1ms.md)
