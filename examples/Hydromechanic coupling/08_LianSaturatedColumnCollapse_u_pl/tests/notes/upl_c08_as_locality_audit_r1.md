# AS 距离局部性：核、h/dp、ε、指数必须联合比较

只读当前源、Hydro AGENTS、已核的 Bui 原文页及 AS05 已封口结论；仅新增本 note。下表由固定核多项式作纯数学计算，没有求解、构建、解码、参数扫描、拟合或生产改动。ε=.5 已完成且拒作修复的结果保持，不改默认 ε。

## 实算 normalization 与开关

令 s=r/dp、a=h/dp，AS 距离乘子为

`F(s)=ε [w(s/a)/w(1/a)]^n`。

Cubic 无量纲形状 `w(q)=1−1.5q²+.75q³`（q≤1），`w(q)=.25(2−q)³`（1<q<2）；Wendland C2 为 `(1−q/2)^4(2q+1)`（q<2）。实际邻域支持为 r≤2h。各核自己的维数归一化系数在该比值内消去，但实际力的梯度/体积/应力并不会消去，故跨核的 F 不能当作实际加速度。

源码：`src/source/FunSphKernel.h:51–81,88–132,206–212` 与 `FunSphKernel_iker.h:36–80`。CPU AS 在 `JSphCpu.cpp:2196–2197` 直接计算 `W(float(Dp*Dp))`；CUDA 在 `JSphGpu_ker.cu:2199–2201` 用 `W(CTE.dp*CTE.dp)`。分母不是 W(h)、每步最近粒距或核常量中旧 `deltap=2/3` 的 wdeltap。CPU/GPU float 运算路径有舍入差，下表按理想给定 h/dp 的实数形状求值，不声称 CUDA bit replay。

`JSphCpu.cpp:2076–2094,2135–2139` / CUDA:673–714 把 total stress 的正主应力保留并乘负 ε；压缩主值清零，不是把全局对角元逐项裁剪。无额外最大 R 截幅，也无 `min(f,1)`、`r<dp` 硬启动门。AS 对所有获准非浮体源按当前拉伸谱计算，并不只作用于滑动面或三个 trace ID。float 谱、cast 和每 pair float 增量的既有局限不因改指数而消失。u-pl 仍为 raw Pa R 与 Vj/rho_i 权重；retro legacy own-rho²/effective-stress 路径不能直接等同。

`JSph.cpp:787–791,3813–3817`：当前动态容器允许有限 0≤ε≤1、有限 n>0，但仍要求 !Shifting 等原窄门。代码“允许” n=3/4/5 不是其物理/时间稳定性认证。用户允许 shift 是后续实现授权方向，不表示可以仅开现 XML 绕过此门；本 note 不同时引入 shift、SPR、HG、滤波或 FOS。

## 只保留两个有限候选，单次选择而非矩阵扫描

1. **A：ε=.3,n=2.55，Cubic a1.2不动。** 直接对应 Bui 原文试过的中间强度（其报告仅减轻断裂，并非完全消除）。相对当前 ε=.2 对每个 pair 乘子均×1.5，仍是已拒 AS05 的 .6 倍。这是强度控制，不是更局部策略；可能仍产生早期负压/运动抑制，不能先承诺改进。
2. **B：ε=.2,n=3，Cubic a1.2不动。** 这是由距离公式定义的局部化探针，**不是论文给出的土体校准值**。在 dp 处不提高幅度，s=.5 时比基线增强约37.3%，s=1.5 时减弱约44.6%。其与基线之比为 f^.45，最大约1.5235；与已拒 AS05之比为 .4f^.45，整个支持内不超过 .6094。它可以区分近接触增强和外圈广泛作用，故比再次单增 ε 更有局部性辨识力；仍不能保证总力/轨迹更小或稳定，因为应力谱/几何会随解改变。

若仅选一个检查局部性，B 比 A 更有辨识力；若需纯文献中间强度控制，则 A。不要首轮同时改 h/dp 和 n，也不要自动连续运行两者。**不把 C08 ε=.2,n=4 列为首轮物理候选**：其 s→0 乘子8.43891，已高于早停 AS05 的5.43339，s=.5 也为3.35128；原文还有直接警告。需要时可仅作为冻结 pair 数学反例，不是本轮新求解计划。

## 因果与准入限制

AS05 已证：ε=.5 晚期三个 ID 的大脉冲减小，但约 .3 s 后运动停滞；末前缘粒心4.05677 vs4.61063 m、maxspeed .03638 vs1.32806 m/s，raw压力RMS37.11 vs20.30 kPa。更小变形不能当作更准确。早期 .23 s 的新组保存负峰−367.67 kPa明显比基线同刻−3.40 kPa大；只看晚窗会漏掉该反例。

若根选择其中一个，先仍需新参数明确的输入/metadata预期和独立准入；不允许用旧 .2/.5/n2.55 专用 summary/reader 把新参数误认证。判读必须同时看全体材料运动/前缘、实际近邻 r/dp/团聚与裂隙分布、负压/总应力/κ/J、FS及墙接触，而非只以三个压力探针或论文轮廓选优。核比乘子并不测量剪切带物理断裂；AS也不能替代负孔压、梯度—散度一致性或时间积分稳定性的因果检查。本 note 没有创建/启动任何新物理输入或 owner。
