# r5 pressure pulse probe r2: raw channel, AS nonlinear action and real spectral derivative

Author-only new script `support/upl_c08_r5_pressure_probe_r2.py`. It is copied from the final frozen r1 source, with fresh r2 source/note/output names checked before creation. The original r1 script/note and its actual failure are preserved. That execution loaded an earlier version and failed with duplicate nearest_fixed_B_m keywords before output writing; r2 retains the final distinct `nearest_fixed_B_observed_m` name. No r1 retry or evidence rewriting is performed. This new script has not been imported, AST-run or executed while authoring.

Scope is unchanged: actual parts60/61/62/63/64/69 and IDs5809/4956/4959,18 heavy receiver cases. Literal300/6805/22 memmap uses `(6805,components)` fields, the same formal native bytes and original12B header, with no adaptive N or raw BI4 access. All300 recorded states of the same three IDs remain only as the already-planned trajectory context; no new force-probe frames or physical run are added. Per-part progress prints identify the six heavy iterations. Original solver/post/native exits and all original ledger/P0/FS/clock/plane coverage remain required. Bindings are the closed native exports/calls and immutable helper files; no recursive provenance/hash scan is added.

The original `Cloud`, `Mechanical` and `probe` helpers remain unchanged. Raw direct-pressure/Taylor/kgrad/FS-choice rows, pressure-only raw mechanical self terms, and complete two-hop raw-mechanical-to-Darcy channels remain available. Every original WallStencil check still applies before using AS neighbors; no fixed ghost is synthesized, removed or truncated. A node's local C observations use complete fluid moments, not a wall MLS determinant rule.

The added AS model follows the current-J source path in JSphGpu_ker.cu: total stress construction around681; raw tensile spectral map around654-657; float dp reference kernel around2137-2138; and J-weighted pair contribution around1806-1824. At the saved state let S_i=float32(sigmaeff_i-p_i I), diagonalize S_i in double precision, and use R_i=-epsilon*(S_i positive part). Native IJ is xy,yz,xz; the full3D tensor is reconstructed before taking its XZ block against the2D raw gradient. epsilon is .2f. Wdp uses float dp=.04 and float dp*dp in the existing Cubic helper; ratio=W/Wdp uses float multiplication and exponent2.55f. The acceleration map is sum_j(Vj/rho_i)*fij*(Ri+Rj)*graw_ij. Its current nonlinear value is separately computed, not obtained from a Jacobian action.

With sigmaeff/J/geometry held fixed, pressure shifts all principal values equally, so eigenvectors do not need a pressure derivative. For nonzero eigenvalues D_i=dRi/dpi=epsilon*P_i_positive. The AS force derivative is B_AS_i,l=sum_j(Vj/rho_i)*fij*(delta_i,l Di+delta_j,l Dj)*graw_ij. Raw-only, AS-Jac-only and raw-plus-AS-Jac channels are propagated through the same frozen Darcy algebra. The additional AS rate derivative is Kw/(n_i*gamma)*rhow times {ki[sum_j Vj(Bj,l-Bi,l) dot gi + chi_FS Bi,l dot lx] + ki/[(1-n0)Ck]*gradJ dot Bi,l}. gamma remains1000*9.80665; no gravity magnitude is substituted. There is no new third-hop dependency in these operator rows.

For actual nonlinear AS acceleration, the same divAce/FS-Ace-lx/kgrad map is evaluated on the nonlinear current R tensors. CSVs report its three rate contributions and total separately from ASJac*p, their difference, raw-pressure-only acceleration and their partial sum. Jac*p is not the nonlinear AS force: frozen effective stress supplies an affine offset and active tensile rank depends on the base stress. The helper's historical `native_p_channel_contribution` column means linear row action only, including in the new AS-Jac channels. The dedicated AS_nonlinear_vs_Jacobian CSV and plot retain the distinction explicitly.

Every receiver records its principal values, positive rank and minimum absolute eigenvalue. The entire AS-contributing two-hop neighborhood records the minimum absolute eigenvalue/native ID, rank0..3 counts and exact-zero count; a separate AS_spectra CSV retains each required node's eigenvalues, R and dR/dp tensor components, plus source-input and output-float rounding sizes. At an exactly zero eigenvalue the classical derivative is not unique; the recorded convention uses lambda>0 and excludes exact zero, with no fitted epsilon threshold. Small reported eigenvalues must be interpreted relative to casting and eigensolver differences, not treated as certified CUDA branch identity.

This is a double-eigh real-number derivative of the frozen, source-float base tensor, deliberately not the literal derivative of float quantization, the CUDA iterative eigensolver, packed positions, float accumulation or FMA. The nonlinear spectral proxy retains the real spectral tensor; it is not the unexported GPU AS tensor bit pattern. Output float-cast differences are recorded but are not acceptance budgets. Actual AS1 has now been included only in this restricted frozen pressure channel. AV, effective-stress/material evolution, velocity/theta/J evolution, pressure projection and time integration remain excluded. Saved FS and theta are full-state/last-stage observations rather than exact unsaved substage state. Neither negative matrix entries nor cancellation of channel actions prove the pulse's cause or global instability.

The conditional FS-minus-interior quantity is still explicitly a proxy: Delta lap=(gradp+rhow*A_partial) dot lx. Raw-only and raw-plus-AS-nonlinear partial accelerations are recorded, and the corresponding linearized rows include AS as appropriate. Missing effective-stress and other force channels mean this is not the actual full-Ace switch or an observed substage switch.

Channel panels separate raw-only Jac*p, raw-plus-AS Jac*p, AS-only Jac*p and nonlinear current AS action.
