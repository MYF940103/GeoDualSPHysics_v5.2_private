# 真实床法向与legacy NoPen必要几何门

已进行一次小规模只读统计，脚本`tests/support/upl_c08_bed_nopen_mask_r1.py`实际exit0（约1.07 s）。只读已封口43帧typed22、copied `CfgInit_NormalsGhost.vtk`及已闭合contact表；全部输入前后stat相同，无solver/reader/build/Git/SHA，不改source、原生数据或旧valid analysis。新数据为`tests/figures/upl_c08_bed_nopen_mask_r1_bed.csv`、`_groups.csv`、`_particles.csv`和`.json`。

实际GPU caller在`src/source/JSphGpu_ker.cu:1970–1991`：固定墙NoPen路径先要求`rrmag < 1.25f*dp`，再要求raw-normal长度`norm>0`、`norm < 1.75f*dp`及`normdist < .75f*norm`。分量调用后`ComputeNoPenVel`在1674–1681行仍只对朝墙速度`dv*unitnormal<0`累计。当前dp转float后，两条必要门的实际阈值分别为0.04999999701976776 m和0.07000000029802322 m。不能将raw-normal向量当成单位法向；它还编码B到镜像GP的距离。

距离和plane资格采用native double位置及显式float差值算术作诊断，不声称重放未保存的GPU packedPosCell/FMA；55–62 mm与50 mm的差距远大于相关float舍入量级。统计没有修改半径、阈值、法向或退役规则，也没有开启新求解。
