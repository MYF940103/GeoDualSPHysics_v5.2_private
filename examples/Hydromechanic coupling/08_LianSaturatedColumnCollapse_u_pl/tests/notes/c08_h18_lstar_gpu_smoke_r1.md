## Separate admissions and one owned invocation

The CLI is prepare|run --profile off1|debug2 --execution-authorized. Each phase independently requires logs/<job>.root_<phase>_admission.json with authorized=true, exact allowed_job/profile/phase, execution_script/note/source_build stats, current root_thread_id, automatic_native=false and automatic_next_job=false. Queue/watcher flags must be absent or false. Run admission also binds the actual preparation stat. All paths/argv passed to the real process are strings. Fresh output, plan, start/call/run/log/status protections forbid reuse of existing or partial attempts. No retry/rearm mechanism exists.

The runner reuses the already reviewed m.invoke implementation, which launches one Popen child, acquires actual Win32 tool identity/handle, and for compute-sanitizer additionally captures the matching private solver descendant handle before exit. Start evidence records the current owner PID/creation/exe/argv/parent; the call retains native creation FILETIME, exe/argv/parent, tool Popen/Win32 and native target Win32 exits separately. Debug invocation is compute-sanitizer --tool memcheck --leak-check full --target-processes all --error-exitcode 99 PROGRAM ... with target=PROGRAM, not an invented nested exit code. Direct Release uses its actual Popen child as solver. All observed error and leak summaries must exist and be zero.

The actual private program must not already be active. Run.csv is parsed with exactly the original AS_Bui2008(.3;2.55) embedded semicolon, preserving all other fields; completed-step cap, save count and PartsOut=0 are checked, together with the real Part file list. Actual solver handle exit0 and normal schema2 Run.out completion seal solver_completed=true before argv/Run.csv/memcheck/derived-stat review. A later review failure therefore preserves completed physics and does not license rerunning it. Failures retain first_failure, real exit/identity evidence, all partial outputs and the last unmodified PART line from captured console stdout; no unsaved native stop time or array is reconstructed. PID survival observations are reported as observations, never automatically reaffirmed ownership after possible PID reuse.
