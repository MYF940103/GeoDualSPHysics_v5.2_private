# C08 成熟预载切换到 M0 后的第一段撤墙

选取 ψ=0° 的 10 s 同材料 Wendland 源，5000 个土粒、2060 个固定粒子、hdp=1.8、dt=5 µs。原源结果位于 `tests/outputs/c08_h18_wend_psi0_pre_r2/data/Part_1000.bi4`。该源沿用旧有限 Kw 的压力方程；GPU 载入实际保存的 p、P0、速度位置、六应力、塑性历史、J、θ 和自由表面等，并在设备读回逐 ID 对齐后，用该时刻实际孔压同时初始化 M0 的 p_n 与 p_prev。此后两份压力历史由模型 2 的三个端点校正轮次自然演化；保存的步号与真实二进制时钟延续原源。

保持右墙再计算 200 步（1 ms），继续使用预载原有的阻尼与每 40 步一次的 Shepard。到实际 t=10.00099999970597 s，第 2000200 步已完成，在下次力学步开始前撤走 255 个原生固定 ID，4900 个内部材料与 100 个原外表面材料按现有邻域重新分类，49 个材料成为新自由表面。拓扑改变前后，按 ID 比较 p_n、p_prev、P0、六应力、κ、J，均逐位相同。随后关闭阻尼和 Shepard；自由面正压仅在完成步末轮执行投影，负压予以保留。变量 k 仍由保存的 J 与初始参数计算；AS、HG、NoPen 在整个私有诊断中均关闭。

首个真实撤墙后完成步将新自由面的 402.78–19556.54 Pa 原正压力交由末轮投影。前 8 个撤墙步，β 从 0 改成 0.04 时，首次出现含负压源的原步与首次原生场分歧同在 2000202。到第 2000208 步（撤墙后 40 µs），最低孔压为 −13.800/−2.617 kPa，负压材料数为 218/157，位移差最大 7.22×10⁻⁶ mm。跨端对照采用之前的 CPU β0 闭墙 1 ms 保存点，其相同时间的最大孔压 RMS 差为 0.00360 Pa。短窗每组审查 208 个保存时刻、104 万项相邻帧实际前次压力、1040 个阶段时步和 624 轮压力更新。

重现入口与数据

- `tests/support/c08_m0_release_mature_gpu_r1.py`：在私有目录复用完整已验证的 C08 M0 CUDA 核，替换两个主机编译单元，执行 `short` 或 `w03`，可选 `--beta 0.04`。
- `tests/support/c08_m0_release_mature_review_r1.py`：原生类型、数值、时间、历史与阶段审查；`tests/support/c08_m0_release_pair_r1.py`：同存储时刻、同材料 ID 对照、PNG 与匹配 CSV。
- 逐组结果保存于 `tests/logs/c08_m0_release_mature_gpu_r1_{short,w03}_{b0,b004}.review.json`。每组有对应历史 CSV，配对图表以 `_pair` 结尾。

这项观测回答给定当前力学和边界后，切换孔压稳定项怎样改变起动负压。验证与论文的滑塌形态仍须采用所选正式材料与实际接触/人工应力配置，并观察更长释放时间。

### 撤墙后 0.03 s

每组原生共 268 帧，第一次对照的全部 208 个状态逐位复现，包括上一时刻孔压、实际时间及有符号 dt 偏差。下面的全窗极小值来自实际保存帧；前 8 个释放步逐步保存，其后每 100 步保存一次。

| 量 | β=0 | β=0.04 |
|---|---:|---:|
| 全部保存帧最低总孔压（kPa） | −13.800 | −2.848 |
| 0.03 s 最低孔压（kPa） | −4.302 | −2.356 |
| 0.03 s 负压材料数 / 5000 | 1380 | 1464 |
| 0.03 s 最快材料速度（m/s） | 0.25033 | 0.19082 |
| 0.03 s 前缘 x（m） | 3.983697 | 3.983108 |
| 0.03 s 最小材料邻距 / dp | 0.96483 | 0.97093 |
| 0.03 s 塑性粒数 / 最大 κ | 2093 / 0.04122 | 2207 / 0.03444 |

β=0.04 减小了负压峰幅，也改变了应力和运动。全窗两组之间材料压力 RMS 差最大为 2449.64 Pa，单点六应力分量差最大 13.423 kPa，材料位置差最大 0.64831 mm。末帧有更多土粒处于负压。原生散点图采用跨 β 共用的压力色标，并按原始材料 ID 求差。
