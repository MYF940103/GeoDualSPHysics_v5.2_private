# 从已变形的 C08 粒子状态检验负孔压区的 TPI 更新

从原 ψ=0°、有限水体积模量 GPU 正式诊断的 `Part_0038` 读取 6,805 个真实粒子。此时已撤墙 0.380005 s，5,000 个土粒中有 1,125 个总孔压为负，最低 −8.7501 kPa，最大塑性历史量 κ 为 2.82482。私有 CPU 程序按原 ID 恢复全部坐标、速度、密度、双精度六分量有效应力、κ、体积比 J、体积应变率、孔压、基准孔压和自由面属性，逐位核对后才进行下一次力评估。保留的 1,805 个固定边界使用原侧墙与床面属性。计算沿用 Wendland、H/dp=1.8、固定步长 5 µs、人工应力系数 0.3 和指数 2.55。固定平面接触仍采用原阶段投影，Darcy 反力尚未在同一阶段闭合。

两组均从这一截面冷启三轮 M0，令前一时层孔压等于截面实际孔压。每组 8 个完整更新，每个更新保存一次。此后每个材料点都采用自身真实的上一时层，两个分支共逐位核对 80,000 个前值。两个计算的最低步长上限均为 8.8691 µs。模型 2 的公开适用范围与根目录运行文件未改变。

|---|---:|---:|
| 全土体最低总孔压 (kPa) | −9.94357 | −8.75011 |

两解在该时刻的全土体孔压差 RMS 为 82.7124 Pa，单粒最大差为 1,975.19 Pa。最大材料位置差为 6.22×10⁻⁶ mm，速度差的向量 RMS 为 1.396×10⁻⁵ m/s。β=0.04 在本次步长下给负源压力行增加 β/Δt=8,000 m⁻¹s⁻¹，使本来已经为负的压力在这段冷启动短窗内几乎维持原值。正压材料也随相邻粒子与力学更新产生差异。这个结果说明需要保留压力响应来衡量过度抑制。准确性、长时振荡和团聚应以从相同预载持续推进的释放轨迹、前缘和实验形态来评估。旧有限 Kw 截面没有相邻 5 µs 保存，无法提供原模型的前一时层或同一短窗的逐步参考。
