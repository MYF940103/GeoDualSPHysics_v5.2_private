# C08 +2.5° TPI 自由面零表压对照

Lian 2023 第 4.4 节给出自由面渗出条件及 $p_l\leq0$，图 16 的自由面附近大体接近零色标。图像分辨率允许检验近零孔压的假设。该试验直接比较把零表压施加到所有已识别自由面土粒的效果。[Lian 2023](https://doi.org/10.1016/j.cma.2023.115967)

基准为已验收原生数据的 1.2 s TPI β=0.04 分支。对照沿用同一 +2.5° 母材预载 Part_1000、几何、5 μs、三轮 TPI、β=0.04、撤墙时钟、自由面识别及 Darcy 离散。私有 GPU 源自实际基准的 113 个链接对象，仅替换产生自由面投影内核的 CUDA 对象。在已有完整步孔压投影中保留有效正常自由面粒子与有限性判定，将符合条件的两种符号表压均写为零。撤除右墙后的新自由面由同一个 FSType=2/3 掩码选取。保存的 PorePress0 仍按材料 ID 继承。

构建和运行由 `tests/support/c08_psi25_tpi_surface_zero.py build|run` 完成。运行依赖原两组 TPI 的成功求解、完整原生检查及形态图回执。新标签 `c08_psi25_tpi_surface_zero_r1` 单独保存构建收据、日志和原生帧。新原生检查保留原材料、时钟、孔压历史及持墙/撤墙条件，并检查所有保存帧的 FSType=2/3 表压严格为零。撤墙前四个共同保存状态核对实际原生数组、上一时间步孔压和时钟。原始最右 50 个材料粒子按预载起点的坐标选取，后续按 ID 跟踪。

结果与 β=0.04 正压截断、原显式及 Lian 同时刻比较。表面零压是施加的条件。独立结果看水力影响进入土体的范围、同一批材料水平速度和位移、屈服动员、滑塌前缘及轮廓。图 16 使用论文色条，CSV 保存原生表压和实际时刻。形态验收以完整时窗的对比为据。
