# C08 正剪胀算例中式（47）的负压判号

在已有 ψ=+2.5°、HG 开启、Kw=1 GPa 的三秒轨迹中，最低的实存总孔压出现在撤墙后 0.200005 s。直接读取该时刻的原生 Part_0020 及前一保存帧 Part_0019，按原始 ID 对齐全部 5,000 个土粒。两帧相隔 2,000 个物理步。第 2,040,001 个完成步有 2,405 个土粒满足总孔压 pₙ<0，其中 149 个为自由表面，2,256 个在内部。表面 149 个土粒的负压均保留。此时刻由原三秒全程最小值记录预先确定。[全程来源](../logs/c08_h18_hg_psi2p5_full3_physical_r1.check.json) · [原设置及实际运行](../logs/c08_h18_hg_psi2p5_full3_r1.run.json)

| 作为下一步式（47）负压分支的判据 | 选中土粒 | 相对 pₙ<0 漏选 | 多选 |
|---|---:|---:|---:|
| 总孔压 pₙ<0 | 2,405 | 0 | 0 |
| pₙ<0 且属于自由表面 | 149 | 2,256 | 0 |
| pₙ<0 且累计 κ>0 | 2,285 | 120 | 0 |
| pₙ<0 且两保存帧间 κ 增加 | 0 | 2,405 | 0 |
| 固定初始参考下的超孔压 pₙ−P₀<0 | 5,000 | 0 | 2,595 |

最低压粒子 ID 7010 的总孔压为 −20,204.3203 Pa，累计 κ=0.0538373，前后两保存帧的 κ 相同。论文式（47）在考虑塑性变形的土中按已提交总孔压的符号选行，公式没有逐粒 Δκ 门槛。该帧的保存间隔约为 0.01 s，不能作为 5 µs 积分步的上一压力历史。实际自由渗流只在完成步投影正表面压力，这两帧可验证完成态的符号；投影前写回及两负压粒子的三轮端点已有单独的连续步检验。[论文第 3.5.3 节](<../../../../../src/papers/u-pw/Lian 2023 u-pl.md>) · [已存连续步与最终投影检验](c08_eq47_p3_warm_r1.md)

本次只计算有限 Kw 存档上各判据的覆盖范围。进入 β 动力对照的先决条件是先建立 C08 同模型 β=0 的相容预载与撤墙状态，核验幸存土粒连续压力历史、变渗透率与真实自由渗流，然后在相同初态和边界上比较 β=0 与 0.04。[预载末态 M0 余量](c08_pre_m0_r1.md)
