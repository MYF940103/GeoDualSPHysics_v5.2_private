# Close-pair stress-sign observation (author only)

Fresh support/upl_c08_as_pair_sign_r1.py has not been executed/imported. It needs root full-read and one explicit offline authorization. It consumes passed baseline/n3 native/run evidence, the repaired clustering CSV and n3 cohort comparison. No solver, build, decoder, raw BI4, trace scan, hash, modified field or old helper is involved.

Both windows are the same actual66 saved states, parts0..65, not the old full3s dataset. Baseline all_soil rows come from clustering_r1_history with epsilon0p2_full_r5 and part<66, protected by the existing exact native prefix evidence; n3 all_soil rows come from asn3_compare_r1_cohorts. For each group the minimum saved rNN/dp row (earliest part on ties) and actual tau=.66 row are selected from these CSVs. Only those native typed22 records are seek-read: at most four records, deduplicated if selections coincide. The unchanged12-byte header stays6805/22/66. All unique soil-soil pairs r<.7dp from each selected record are exported, not just its minimum pair; small output row count is not forced to four.

At each pair let e=(xi-xj)/r, S=sigma_eff-pI from native double SigmaState and the actual float pore pressure, and Splus the positive-eigenvalue part of the full symmetric3x3 S (native ij=xy,yz,xz). For nominal Cubic h/dp1.2 define F=.2*[w((r/dp)/1.2)/w(1/1.2)]^n, with n=2.55 or3. F already contains epsilon. Report e'(Si+Sj)e, -F*e'(Splus_i+Splus_j)e and their sum. Epsilon is not multiplied a second time. Native velocity gives dr/dt=(vi-vj).e: negative means approaching. Saved p/kappa/J/FS, both material IDs/positions/velocities and spectrum rank/minimum absolute eigenvalue are retained.

Source audit: GPU JSphGpu_ker.cu1833-1842 uses +(Vj/rho_i)*(Si+Sj)*gradW;1878-1887 adds the same positive volume/inertia factor times raw AS and its kernel ratio. CPU JSphCpu.cpp2314-2322/2357 has the matching J quadrature. These terms use the uncorrected radial kernel gradient, not Ci. For Cubic0<r<.7dp, its radial factor is negative, so a positive reported net normal stress is an attractive line-of-centers contribution, a negative value repulsive. Positive Vj/rho_i changes amplitude but not that single-pair sign. No pair force magnitude, pair conservation or complete acceleration is reconstructed.

This is a native-double eigenspectrum and smooth double kernel-ratio frozen shadow. Actual GPU stress casts, single-precision Jacobi iterations, W(dp) construction/powf and accumulation are not replayed bitwise. The script labels values within32FLT_EPS*(1+F)*max(1,sum spectral scales) Pa as near_zero_unresolved. That is a float-scale screening inherited from the local AS unit scale, not a certified bound on all GPU errors or a new physical acceptance threshold; small shadow differences cannot establish actual GPU sign changes. Raw numbers and the screening scale remain in the CSV for independent review.

Outputs, with overwrite refusal: figures/upl_c08_as_pair_sign_r1_pairs.csv (all qualifying pairs), _frames.csv (at most4 selected records), and logs/upl_c08_as_pair_sign_r1.check.json with minimum-pair details and sign counts. A tensile/attractive shadow is evidence compatible with one-pair tensile forcing, not proof of classic pairing or instability. A compressive/AS-repulsive pair can still approach through inertia, other neighbours or bulk deformation. Saved full states are not the unsaved force stages, and four records cannot prove temporal causation, global stability or that the n3 candidate solved clustering.
