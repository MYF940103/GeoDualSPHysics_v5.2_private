# 逐步压力的描述性频率

只读取已通过的 `terms_r2_window` 派生 steps.csv，不读取原生文件，不重复原读取器或求解。三 ID 分别选择实际 τ=[.619,.621)、[.625,.627)、[.635,.637) s 连续记录，使用完整步投影前压力。该选择保留 FS2 正半波，而不是把已投影数据的截断谐波当成独立模态。

RMS 取原值减各窗均值后计算；频率用同组真实时刻的平均间隔、去均值与 Hann 谱窗得到最大非零 rFFT 频率格点，不补零、不插值、不拟合特征频率。频率格点宽约500 Hz。谱窗仅用于此频率估计，不改原始数据或既有图。不同窗的 RMS 对数比只是局部增长描述，不是完整系统特征值。

另报告“假设这一主频属于孤立、无耗散纯虚模”时显式中点的每步增益与增长率，依据 `R(z)=1+z+z²/2`、`|R(iy)|²=1+y⁴/4`。这是条件估算，不是实际耦合谱、物理耗散、非正规增益或 FS/塑性切换的证明，不能据它直接修改时间步或时间积分算法。
