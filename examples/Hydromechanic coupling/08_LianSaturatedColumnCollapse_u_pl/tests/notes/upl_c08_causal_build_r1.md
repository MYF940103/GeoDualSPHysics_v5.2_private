New support/upl_c08_causal_build_r1.py mechanically derives from the reviewed stage_ponding_build_r2 helper. It has not been imported, captured, built or used to launch any executable. Root must finish/freeze/review the four-file GPU observer change before capture, then authorize one selected action at a time. Available actions are capture, DebugCPU, Debug and Release; no automatic sequence, help, solver, reader, VTK or later physical job is present.

Fresh capture is outputs/upl_c08_causal_source_r1/{source.zip,source.json,production.diff}. All current source/header files and the four authoritative VS solution/project files are archived and bound before any build, together with this owner/note and the unchanged invocation helper. Same sealed bedkeep configuration calls provide the authoritative MSBuild recipes. CPU Debug uses the default CPU solution; GPU Debug/Release use the GPU solution. x64, MSVC14.36.32532, CUDA11.7/sm86, disabled PostBuild and isolated outputs remain unchanged. Fresh program/object paths are outputs/upl_c08_causal_<conf>_r1 and no-space %LOCALAPPDATA%/Temp/upl_c08_causal_r1/<conf>/int. Existing complete/partial configurations and receipts are rejected. Expected closure is 87 CPU or 113 GPU objects including exactly one main.obj; no old object cache is copied.

CPU Debug has both C08_STAGE_TRACE and C08_CAUSAL_TRACE undefined. GPU Debug/Release append `/DC08_STAGE_TRACE /DC08_CAUSAL_TRACE` to the child CL environment and `-DC08_STAGE_TRACE -DC08_CAUSAL_TRACE` to NVCC_PREPEND_FLAGS, so both C++ and CUDA translation units receive the observer definitions. Any inherited occurrence of either dedicated macro in CL/_CL_/NVCC prepend/append flags is rejected. Capture and build receipts record each macro's enabled state and exact additions; no full environment dump is added.

The unchanged mdbc_partition_components_r3.invoke preserves actual MSBuild process identity, real Popen/native Win32 exit and original logs. After the true exit, this helper checks object/program closure, error/warning records, captured-input stability and protection. A failed build is retained without retry. Before/after protection covers the canonical four CPU/GPU Debug/Release executables, flat files in both runtime_r5 and runtime_r6, and the original r2 GPU Part_1000.bi4. It does not walk old objects/libraries, solver output series or unrelated old program directories. No canonical, runtime or PRE file is written.

This establishes only isolated compilation and observer capability if root later executes successfully.
