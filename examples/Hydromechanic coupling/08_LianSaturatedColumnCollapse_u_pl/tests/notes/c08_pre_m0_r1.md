# C08 撤墙前有限储水预载的 M0 局部余量

原生 GPU 预载的第 2,000,000 个完成步在 9.999999999706008 s 保存了 2,060 个固定粒子和 5,000 个土粒。独立 CPU 组件按照原始 ID 恢复原位置、速度、有效应力、κ、J、总孔压及表面状态，保留右墙的 255 个粒子。使用原预载设置重算一次 mDBC、动量、速度散度和变渗透率 Darcy 项。预载使用 Kw=1 GPa、Wendland H/dp=1.8、ψ=0°、阻尼 0.03，每 40 个完成步施加一次超孔压 Shepard。测量以保存的完成态为起点，未再执行平滑、撤墙或积分。[逐粒结果](../outputs/c08_pre_m0_r1/rows.csv) · [输入身份与计算记录](../logs/c08_pre_m0_r1.check.json)

这里 Rγ 包括 −γθ、变渗透率 Darcy 项及 ∇k 项，S 为压力拉普拉斯项的正对角，表中单行修正为 |Rγ/S|。以原有限 Kw 的压力变化率独立复核，所有 5,000 个源行均能按原运算顺序还原其 float32 值。由 γn/Kw 乘以该变化率反算 Rγ，最大差为 5.23×10⁻⁸ Pa/(m·s)。4,900 个非表面行的余量均高于双精度重组的舍入界，假设执行一次未投影修正，4,831 个土粒的 float32 孔压会改变。这个实验测得初始局部不平衡和修正量级，没有给三轮解误差或物理合格线。

**材料状态与交接。** 本帧 κ 全为零，J 在 0.99929384 至 0.99997708 之间，σ′zz 在 −20.933 至 −0.681 kPa 之间。最大速度为 5.81×10⁻⁶ m/s，总孔压在 0 至 19.562 kPa 之间。低速度和部分粒子的小压力修正支持保留此帧作近静态对照。旧材料预载的空间约束有可测余量，而且其压力来自储水模型。正式 M0 撤墙需要一条在相同 M0 模型和原墙上建立并核验的预载，或者有独立验证、能同时说明力学平衡、局部水力约束和材料历史的初始化。旧 PRE 的 PorePress0 为初始参考压力，取值 196.2 至 19,423.8 Pa。它不能充作上一积分步的压力。

**历史与边界。** 在同模型预载本身的首步从已核准的 p_n 冷启动，首轮外推取 pα=p_n。从下一步开始按土粒 ID 保存两个真实连续提交值。撤墙时核验每个幸存土粒的历史与步长，按新邻域重算墙、自由面、动量和水力项，末轮完成自由渗流投影后提交新历史。若采用独立平衡初值在撤墙时冷启动，应记录该启动位置及首步历史降阶。此项试验未生成前一帧 M0 历史。

非零 β 依已提交总压力 p_n<0 触发式（47），各轮沿用该判号。真压力 Dirichlet 行优先。本例固定排水关闭，自由渗流对完成步表面正压置零并保留负压。此次 PRE 的 100 个表面土粒均为零压，100 行的未投影修正均为正，因此完成步投影可吸收该部分余量。PRE 全场没有负压。已有撤墙后两帧冻结状态检验覆盖两个负压表面 ID 及三轮端点算术，其压力历史来自有限储水动力轨迹。β 的实际位移或前缘影响仍需模型内对照。[已有真实相邻两步的式（47）检验](c08_eq47_p3_warm_r1.md)
