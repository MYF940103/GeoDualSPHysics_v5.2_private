# Saved close-pair mechanism proxies (author only)

New helper `upl_c08_pair_mechanism_r1.py` and this note only, not executed. Input is the retained passed total-AS .2/n3, Shepard OFF causal90 native, not rejected Eta0/effective-AS/Shepard results. Its run/native and original r6 all22/clock prefix remain bound. One sequential90-record typed pass computes all5000 soil nearest spacing and unique pairs strictly r<.7dp at every saved time. The first saved threshold observation is retained alongside .5/.72/.9 (deduplicated); it is not continuous onset or proof of tensile instability. Detailed record copies come from that same pass, not extra decoding or payload scans.

The existing `figures/upl_c08_preload_first_frame_compare_r1_material_points.csv` contains all5000 original IDs and PRE_x_float_m/PRE_z_float_m, bound by its passed check to actual source PartFluid1000. These are float32 coordinates stored in CSV, not original double positions. No PRE is re-decoded. Existing passed velocity_stepmap `pre_yield.csv` supplies actual imported PRE double J at the same source clock, so optional detF comparison uses J_current/J_PRE. It remains a geometric-fit versus SPH-ledger description, not a conservation/error gate.

For each detailed save, local2D affine F minimizes unweighted material-neighbor position-difference residuals using fixed PRE soil neighbors within the existing2h support. Context reports F, determinant, residual RMS and reference-design conditioning. Pair prediction excludes the two endpoints' mutual link from each local fit, averages their F and compares predicted versus actual pair vector/length. This reduces direct self-fitting of the tested link. Initially distant material pairs are flagged; extrapolating a local F to such a pair does not diagnose contact/fracture. No fit radius or physical threshold is adjusted to the result.

PRE float half-ULP coordinate scales and reference-design error/sigma_min are exported. The pair roundoff value with F held fixed does not bound uncertainty in fitted F itself. All raw residuals and compression ratios remain continuous; no small residual is thresholded into an affine/physical verdict. The2D fit is relative to the settled PRE, not the undeformed t0 lattice.

Physical total stress is native sigma_eff-pI. Full3D principal values, positive counts and positive-spectrum fraction are retained; the fraction is0 by convention only for a zero stress tensor, separately flagged. Along each current pair line, report native total normal and the raw-force proxy formed from float effective-stress components followed by double absolute-pressure subtraction. This distinguishes principal tension in some direction from tension/compression along that particular pair.

Frozen force reference: `outputs/upl_c08_bedkeep_source_r1/source.zip`, JSphGpu_ker.cu645-682,1770-1779,1806-1824,2137-2138; FunSphKernel_iker.h36-80; FunSphKernel.h51-66. AS input is double sigma_eff-pI castfloat, followed here by double eigh and final R castfloat: R=-epsilon positive_spectrum, rho argument1. Epsilon is included once in R. Float Cubic W, W(dp), reciprocal, ratio and n3 power follow the archived formulas; actual GPU packed-position/FMA/powf/float Jacobi rounding is not reproduced. Nativeij is xy,yz,xz; no yy or out-of-plane spectral component is discarded. The resulting values are test-side pair proxies, not an actual GPU force.

Pair accelerations use actual positive native Vj/rhoi and Vi/rhoj, retaining J/porosity/density context. With n=(xi-xj)/r and negative Cubic fac, a positive projected tensor gives an inward/attractive radial contribution; negative is outward. Closing velocity can coexist with a repulsive pair contribution because all other neighbors, walls, AV, gravity, stress feedback and time history are absent from this pair proxy. The script does not infer that AS was inactive or that clumping is tensile from this coexistence.
