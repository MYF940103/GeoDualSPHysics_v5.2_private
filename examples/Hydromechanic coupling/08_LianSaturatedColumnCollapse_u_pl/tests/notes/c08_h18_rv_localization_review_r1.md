## Full sample localization, compact output

Each state builds one full3D `cKDTree`, recomputes nonself NN and unique pairs using strict physical distances `<.7dp`, `<.5dp`, `<.3dp`. Counts/minimum must agree with the passed window history. One PRE tree initializes the common reference. No material point, extreme/coincident pair or poor LS endpoint is filtered out. This is sparse/output-sensitive `O(91*N log N)` geometry plus actual close-pair/endpoint-neighborhood work, not an all-pairs N² force calculation. Position/tree caches avoid rebuilding trees for representative history; the complete22 payload is not duplicated into a giant particle CSV.

Every observed entry into .7/.5 is an event with actual previous/current saved time and distance, real IDs and current fields. Re-entry events remain; no interpolated exact crossing time is claimed. Every pair ever observed below.7 receives a catalog row: initial/PRE coordinates, first/minimum/last observed part and true first/minimum clocks, .7/.5 observation counts, longest consecutive **saved-observation** run/count/span, Part60–90 .5 observation count and final actual distance. Those observations do not prove continuity between saves. A dedicated onset table includes all entry events at Parts40–43; all91 events remain in the full table. The actual ~.400005–.430005s clocks are retained rather than shifted to nominal .40/.43.

Pre-registered representative rules, separately for each case: first new.5 entry in P40–43, first new.7 entry there, closest final catalog pair, and pair with most late P60–90 .5 observations. Ties use actual part/distance and IDs. The representative union is at most8 pairs, followed at **all91 times in both cases**, including times outside the threshold. Every new pair still exists in events/catalog; representative selection only limits the detailed long-history CSV and never hides other new IDs. This gives root actual P40–43 pair IDs for its separately admitted zero-advance probe without hardcoding legacy probes.

## What the native fields can identify

Pair direction is `(x_j-x_i)/r`; actual relative radial velocity is `(v_j-v_i) dot direction`, negative for approach. The distance secant uses actual consecutive saved times (Part0 uses actual PRE time), not a force or acceleration estimate. Coincident pairs remain with direction undefined, rather than borrowing a PRE direction or inventing traction.

Stress uses native double `SigmaState_kk=(xx,yy,zz)` and **`SigmaState_ij=(xy,yz,xz)`**, confirmed in frozen CPU/GPU save code. Total stress is effective stress−native p*I. Both endpoint effective/total largest principal values, normal tractions `direction·sigma·direction`, pair-mean normal and tangential total traction are recorded. Positive normal stress is tensile and negative compressive under this stored convention. Per-state .7/.5 populations record total-largest-principal positive at0/1/2 ends. Both stress state and p are retained; p alone cannot establish a reduced total positive spectrum. These raw double spectral observations are not exact reproduction of the GPU AS float-input eigensolver or AS force/activation. Native `FSType_i/j` is also recorded for boundary context; saved flags do not certify every force-substage's free-surface classification.

Each detailed event/representative row also keeps native p, native p−fixedP0, kappa, J, n, rho and k at both endpoints. Native p−fixedP0 is not established as the paper plastic excessive-pressure definition. No fields are clipped, smoothed, fitted or corrected.

The optional local descriptor is an unregularized soil-only2D xz affine LS fit to saved velocities, using all soil donors inside actual2H and weights `current V_j*(1-q/2)^4*(1+2q)` with q=full3D distance/H. It uses normalized in-plane coordinates d/H, then divides the fitted gradient by H; compression is `-trace(D)` and equivalent shear `sqrt((Dxx-Dzz)^2+4Dxz^2)`. Rank uses a declared128*epsilon scaled2×2 determinant criterion, with no ridge. Neighbor/coincident counts, condition and validity are kept. Singular/under-supported LS returns undefined rates with a false validity flag and retains the pair/ID. This is a conditional kinematic description, **not the original corrected SPH gradient or the actual eta/gradient-weighted RV fit**, particularly near walls/free surfaces. It is evaluated only for event/representative endpoints and cached.

No native force components exist here, so no exact RV acceleration, direct pair force, all-neighbor force increment or radial acceleration is reconstructed. The root audit notes the actual RV residual `rbar=dv-.5*(Li+Lj)*d`, direct force `-alpha*beta*rbar`: approaching dv_n<0 can coexist with rbar_n>0 and inward direct RV, despite globally nonpositive mechanical power. This is a possible mathematical mechanism, not a result of the diagnostic LS or current pair trajectories. Root's later same-graph frozen response must use the real RV LS and distinguish direct-pair from all-neighbor effects. Likewise, less negative p can alter total principal values and AS response, but neither pressure alone nor these raw spectral counts prove an AS-force change. No additional binary or response evaluation is introduced here.
