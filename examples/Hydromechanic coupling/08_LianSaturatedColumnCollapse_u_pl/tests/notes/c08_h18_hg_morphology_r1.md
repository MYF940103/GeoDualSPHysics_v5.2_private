# CSV-only fixed-material morphology diagnostic

Root explicitly authorized authoring and one offline execution of this bounded diagnostic. The only scientific inputs are the already generated/sealed `c08_h18_hg_cached_physical_r1_spatial.csv` (30000 rows) and `_cohorts.csv` (5000 rows), plus their original passed analysis check. No raw BI4/typed arrays, solver, decoder, VTK, build, GPU, hash scan, other psi or new physical parameter is involved. Old files are protected. New files use only `c08_h18_hg_morphology_r1` under tests/support, notes, figures and logs.

For all5000 materials at the same actual P38/P76/P90 in both trajectories, let Xi be the actual PRE x-z position and xi the saved current position. Actual PRE/current y=0 is checked. A fixed reference neighborhood contains every original material j with0<|Xj-Xi|<2H, H=float32(.072). It is identical in all six saved states, without current-position reselection. Use the predefined unnormalized positive Wendland weight wij=(1-qij/2)^4(1+2qij), qij=|Xj-Xi|/H. No weight/length is fitted to a result.

With dXij=Xj-Xi and dxij=xj-xi, compute Mi=sum wij dXij⊗dXij, Ni=sum wij dxij⊗dXij and Fi=Ni Mi^-1. The vector residual is dxij-Fi dXij and Dmin_i²=sum wij|dxij-Fi dXij|²/sum wij. Record sqrt(Dmin²)/dp with dp=.04, both singular values, detFi, reference condition/neighbor count and original pressure/J/kappa. This is a reference-neighborhood affine fit, not a solver strain update, physical constitutive Jacobian or a reconstruction of an unsaved state. No pseudo-inverse, rank truncation or new physical threshold is used. Nonpositive reference rank is retained with status and blank undefined metrics, not removed. The diagnostic checks finite arithmetic but does not claim an interval/outward certificate.

Every material's actual nearest soil ID comes from the sealed original spatial table. Its actual distance is checked against the saved NN value; a2e-13 dimensionless CSV arithmetic screen only checks that identity. Record PRE separation, membership/rank within the fixed2H reference neighborhood, Fi dX and (Fi+Fj)dX/2 predicted vector/distance, and the actual-minus-predicted vector residual. The rank uses strictly shorter reference-neighbor distances; ties are not assigned an arbitrary ID rank. If the nearest material was outside2H in PRE, membership=false and neighborhood rank stays blank. A new close contact between initially separated material regions can be physical folding/contact and is not automatically numerical mixing.

The watched pair set is the union of actual unique pairs<.5dp in any of these six states, each state's actual closest pair, and the previously discussed material pair6817/6866. Every watched pair is then evaluated in all six states, including states where it is no longer close. No grid/adjacency is inferred from ID arithmetic: reference geometry comes from actual cohort coordinates. All30000 material rows remain in nodes.csv. pairs.csv preserves matched same-ID histories; summary.csv compares both all-node and actual-NN<.5dp populations with min/q05/median/q95/max and reference-rank/negative-fit-det counts. The .5dp selection is descriptive, not a physical failure or paper acceptance gate. A single pair cannot stand for the whole field.

Jpre is not present in either allowed input CSV. Accordingly native_J_over_Jpre is blank and Jpre_available=false; the diagnostic does not read raw data to supply it. detFi is PRE-to-current geometric deformation, while native J contains the full source history. They are shown side by side only: no detFi-nativeJ equivalence error, negative stored-J claim, material inversion verdict or constitutive failure is inferred from a fitted detFi sign. A discontinuity across a real shear band, fracture or contact can produce a poor affine fit even when each stored J remains positive. Conversely a short nearest distance explained by small singular value and low vector residual can be ordered shear/compression, not disordered tensile clumping. Pressure/kinematics and the original full-field figures remain necessary context.

One new nonaffinity PNG uses all5000 current material points in each panel, shared coordinate/color limits across the six states, with red links for actual pairs<.5dp. Color is explicitly log(1+sqrt(Dmin²)/dp), a monotone display transform of the recorded diagnostic; no particle is smoothed, fitted or capped. Undefined reference fits are red crosses rather than hidden points. Independent visual QA must accompany the quantitative CSVs; a passed mathematical/CSV check is not physical acceptance.

The new check binds the original passed analysis and the two original CSV stats, then all new outputs. It preserves new solver/reader/hash counts0, all-row retention and the interpretation limits.
