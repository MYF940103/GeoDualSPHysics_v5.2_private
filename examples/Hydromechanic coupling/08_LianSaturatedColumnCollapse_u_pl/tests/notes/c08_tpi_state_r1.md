The exact existing neighbor loop includes active fixed donors and any real periodic donors; this C08 scope itself is nonperiodic. It accumulates:

`S_LP = -k_i * sum(w_ij)`

`R_gamma = -gamma*theta + k_i*lap + chain`, `gamma=rho_w*9.80665`.

R_gamma is the direct double expression using the same actual force's acceleration, variable-k product term, current correction matrices, Eta² and raw-FS branch. It is never reconstructed from the float pressure rate. **S_LP is only the raw-LP split diagonal**: the Taylor-pressure defect and pressure-chain parts are lagged explicit values from the actual guessed field. It is not the full frozen pressure matrix diagonal or coupled Jacobian. The proposal `float(p + R_gamma/S_LP)` has zero history extrapolation; it is a conditional cold fixed-state row, not a true alpha.5 TPI trajectory or an implicit solution.
