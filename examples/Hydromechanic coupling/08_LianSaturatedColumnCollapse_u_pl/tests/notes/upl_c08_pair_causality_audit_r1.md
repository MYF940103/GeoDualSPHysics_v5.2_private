# 首团聚材料点的因果观测准备

2026-11-09。AV=.15 的 .30 s 结果不足以采纳，继续原授权排查，不扩展参数扫描或其他 ψ 求解。以下是冻结源码及已有原始观察的只读审计，不是新物理候选或根因证明。

## 材料顶点并非全局 I=0

实际冻结 `FunSoilMaterial.h:127–149` 令 `I_tip=DP_kc/DP_phi`。C08 使用 DP_PS、φ=25°，所以 `I_tip=3c/tanφ`，峰值 c=5 kPa 时为 32.1676 kPa，残余 c=1 kPa 时为 6.43352 kPa；这些是应力迹，平均应力为其三分之一。只有 c=0 的相应极限才为零。不能把当前实现描述为对所有正迹统一截到零。

ψ=0 时 Smooth 返回保持应力迹；附加张力面为 `f_t=I−I_tip`、流动势 `g_t=I`，其 compliance 修复允许 `Δε_v^p=(Itrial−I_tip)/(3K)>0`。κ是偏塑性历史量，不能用κ不增长推断没有张力修复，也不能将这个材料体积量再额外加入由运动学更新的 J。

Bui 2008 本地 MD 466–492、522–550 支持先移至黏聚顶点、再缩放偏应力，并说明黏聚顶点仍位于 I>0，需要人工应力。它没有唯一规定修复的 κ、体积塑性及塑性功闭合。Lian 2023 MD 249–263 使用单势 `g=ξψI+q`，904–907 将 ψ=0 解释为无塑性体积流；附加张拉面因而是实际模型差别，尚不能据此判为程序错误。原材料点代数资格通过不等同于塌陷物理精度验收。

下一项需要观察首近对材料点的实际 trial/returned 迹、返回状态、κ和 J/θ，在时间上核对修复、压力变化与闭合，而非根据某帧 q=0 反推完整返回历史。既有 .15 s 材料7012 的正迹约13.18 kPa、q=0 与正黏聚顶点相容。

## 接触投影存在同阶段缺口，但并非完全没有反馈

冻结 bedkeep/r6 `JSphGpuSingle.cpp:813–827` 的顺序是 Pre force/Darcy → Pre 推进/固定平面投影 → 分区 → Cor force/Darcy → Cor 推进/投影。`JSphGpu.cpp:1833–1840` 已先使用 finished Ace 算 Darcy；投影随后在1607–1610及1654–1660改位移/速度，不回写同阶段 Ace/θ/J/σ或重算压力率。Pre 投影后的半步几何和速度仍进入 Cor，因此并非接触完全不反馈；mDBC 床力本身也已包含于 finished Ace。

`FunFixedPlaneContact.h:12–18` 只限位并将入壁负法向速度置零；命中可能仅改位移而δv=0。δv的单位是 m/s，比冲量；δv/阶段时长只是等效加速度代理。不能把它直接当反力，更不能只给 Darcy 加 δv/dt 而忽略既有床力与 J/θ/压力阶段的一致性。

已封口 causal 记录中，7017/5944/6814 各360000次 Pre/Cor 投影调用的命中、速度截断和累计δv均为零，只排除了这三个点自身直接投影。它们未覆盖首近对7011/7012。.15 s 时这对的保存 z 为约 .052668/.077537 m，位于床面以上且在床核支持范围内；10 ms 保存间隔之间的事件不能由这些位置推断。
