# Early fixed-material AS comparison (author only)

New helper `upl_c08_early_as_compare_r1.py` and this note only; no execution, decoder, solver or build. It reuses the passed native loaders and reviewed pair geometry/tensor/Cubic functions, with no edits to those dependencies. Root must full-read before the single `--execution-authorized` offline call.

Four real groups: total-AS epsilon.2/n3 causal90; epsilon.2/n4 **failed** native66; epsilon.5/n2.55 normal66; epsilon.2/n2.55 normal66. The latter two paths come from their actual native receipts and are checked against the passed AS05 comparison, including the AS05 r2 owner whose actual output/native remains under r1. Each epsilon/exponent is checked against its own float native metadata, not copied from the n3 helper. The common XML body/PRE is checked allowing declared AS and window controls. Observer program identities differ and are independently bound.

Each group's original typed file is read sequentially once for the actual common66 records. Preserve90/66/66/66 headers; the causal90 last24 records are not consumed or relabeled. Every matched record checks all22 finite arrays, original IDs, actual shared scalar clocks/steps and fixed P0 bits. Existing full-r6 loader is used only as a metadata/header/provenance anchor for the passed n4 loader; no formal300 payload is scanned. N4 remains solverexit1, last saved4264000/.66, reported unsaved failure step4265004; no failure time or .9 completion is invented.

Spacing CSV contains all66 common saves, including the complete first.30s curve, unique soil pairs strictly r<.7dp and first saved any-pair observation. It separately reports first saved crossing for the preregistered **same IDs7011/7012** in every group. A group's nearest-pair IDs are only onset witnesses, never substituted for these fixed material controls. These are coarse saved-time observations, not continuous onset or causal ordering within Pre/Cor.

Fixed-pair CSV records absolute p/P0/p-P0, FS, kappa, J, positions, velocities, relative normal/tangent motion, principal tension measures and radial total/AS proxies. Raw force effective stress is castfloat before projection; the separate pressure contribution is -(pi+pj), and their total is retained alongside native-double total stress. AS uses total double stress minus absolute pI, castfloat, double spectral proxy and final R castfloat, with each actual epsilon included once. Actual float exponent, Cubic ratio and native V/rho weights are used. Outside the2h support, pair acceleration proxy is zero and the support flag is false; a tensor projection by itself is not an interaction. The proxy excludes all other particles, walls, AV, gravity and real GPU packed/FMA/eigensolver effects.

Morphology at actual .15/.3/.6 saves retains all5000 coordinates/NN/p/kappa/J/FS and common raw NN color scales, close-pair links and fixed7011/7012 markers. No extra PRE-ring fitting is added; existing n3 affine evidence remains separate. No global pressure/energy analysis is repeated, no negative-pressure clipping or fitted threshold, half-step chain, physics-sign gate, accepted repair or new parameter choice is introduced.
