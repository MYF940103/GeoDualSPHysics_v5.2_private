## 根准入 JSON 与命令

prepare 和 run 各需新 JSON：`tests/logs/c08_h18_psi2p5_hg0_w03_r1.root_{prepare,run}_admission.json`。必需字段：

```text
authorized=true, allowed_stage="c08_h18_psi2p5_hg0_w03_r1", phase="prepare"或"run"
execution_script=stat(本脚本), note=stat(本说明)
template_preparation=stat(原ψ2p5 full3.prepare.json), template_run=stat(原ψ2p5 full3.run.json)
source_build=stat(groups.build.json), source_pre_file=stat(新ψ2p5 Part1000)

terminal_queue_once=false（prepare；run不通知也为false）

```

run 另需 `preparation=stat(本次prepare.json)`、`no_parallel_gpu=true`；只有 run 使用 `--notify` 时才设置 `terminal_queue_once=true` 并提供 `codex=既有full3绑定的实际当前Codex stat`。prepare 不依赖通知程序，不允许 `--notify`。

