# Cryer k=1e-6 nu030 short test, 2026-06-24

Purpose: check whether reducing `HydraulicConductivity` from `1e-5` to `1e-6`
extends the physical time scale and improves the early peak under-prediction.

Test folder:

- `refinement/k1e6_nu030_0p1Tv`

Configuration:

- Base case: formal `CaseCryerProblem_PR` (`nu=0.3`).
- `dp = 0.0025 m`.
- `HydraulicConductivity = 1e-6 m/s`.
- `HydroMechTopLoadMode = 3` (`FlexibleConfinement`).
- `HydroMechTopLoadRampTime = 0`.
- `HydroMechDrainage = 1`, `HydroMechDrainageStartTime = 0`.
- `SoilDampingCoef = 0.02`.
- `TimeMax = 0.910928571429 s`, corresponding to `T_v = 0.1` for `k=1e-6`.
- `TimeOut = 0.00910928571429 s`, corresponding to `Delta T_v = 0.001`.
- Postprocess center sampling radius: `r <= 1dp`.

Runtime outcome:

- GPU Release completed, but the run is not physically valid for peak
  comparison.
- Excluded particles: `10634` total, including `6036` due to `RhopOut`.
- Severe particle exclusion started immediately:
  - `Part_0001` at `t=0.00911 s`: `4304` particles out.
  - `Part_0002` at `t=0.01822 s`: cumulative `8307` particles out.
- Solver warnings reported more than 10% particles excluded at the first saved
  nonzero snapshot, and more than 20% by the second saved snapshot.

Postprocess results:

- `r <= 1dp` center sample count was mostly `1`, so the center value became
  unreliable after the early exclusion.
- First saved point gave a nonphysical spike:
  - `p/q0 = 5034.2532` at `T_v = 0.001`.
- Most later center samples were `0`, including at the theoretical peak window:
  - At theoretical peak `T_v = 0.046`, numerical center value was `0`.
- Rechecking with `r <= 2dp` did not fix the problem; the first point remained
  nonphysical (`p/q0 = 717.931`) and later center values still collapsed.

Comparison with the accepted `k=1e-5`, `nu=0.3` formal result:

- `k=1e-5`, `T_v <= 0.1`, `r <= 1dp`:
  - numerical peak `p/q0 = 1.21595` at `T_v = 0.049`.
  - analytical peak `p/q0 = 1.24901` at `T_v = 0.046`.
- `k=1e-6`, `T_v <= 0.1`, `r <= 1dp`:
  - invalid due to early particle exclusion and nonphysical center samples.

Conclusion:

Lowering `HydraulicConductivity` to `1e-6` while keeping the same no-ramp,
`SoilDampingCoef=0.02` setup does not provide a usable improvement of the peak
under-prediction. Instead, the more undrained early response makes the
instantaneous confinement load numerically unstable on this setup. A meaningful
`k=1e-6` test would need additional stabilization, most likely a finite load
ramp and/or stronger short-time damping, before it can be compared to Cryer's
analytical peak.
