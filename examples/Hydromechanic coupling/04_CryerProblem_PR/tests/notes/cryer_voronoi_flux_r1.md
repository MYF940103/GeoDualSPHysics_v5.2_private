# Cryer 排水面附近的守恒水通量

在 ν=0.30 的初始实际球体上，保留全部 37,173 个原材料点和 10,302 个外表面三角形。对每一对有公共面的粒子，按中垂面的真实面积与粒子距离之比求导水权重。对各向同性常渗透率，这是正交控制体上的两点通量。方向从点 i 指向点 j 时，压力通量正比于 (pᵢ−pⱼ)Aᵢⱼ/dᵢⱼ，交换 i、j 后符号相反。动力 Darcy 项在同一面使用两端平均加速度的法向分量。线性压力梯度与反向水体加速度可以在每一对粒子上直接检查抵消。[正交网格上的有限体积方法](https://arxiv.org/abs/0812.2097)

## 真实几何和算子检查

两套独立几何计算在 19,089 个内层与表层的共享面上配对，最大的面积差为 4.68×10⁻²⁰ m²。整球的 244,163 个无向粒子对都有正面面积。控制体总体积为 0.0005230086934804821 m³，与原凸包相差 1.08×10⁻¹⁹ m³。5,153 个边界控制体截断于原三角片，每个单元各面面积矢量之和的最大范数为 2.15×10⁻¹⁹ m²。[整球检查](../logs/cryer_voronoi_join_r1.json) · [外表面分片检查](../logs/cryer_voronoi_surface_r1.check.json)

在 32,020 个内点检查 Δ(r²)=6，控制体计算的最大绝对误差为 1.24×10⁻¹²。另将内点初压设为 1、实际表面设为 0，单独计算三个 Jacobi 扩散迭代。旧四面体一阶刚度矩阵在第三轮有 61 个内点超过 1，新通量在三轮各有 0 个。最靠近排水面的内层（4,588 个粒子）初始离散 Laplacian 的层内标准差从 10,799 降至 576 m⁻²，两组层均值分别为 −168,915 与 −168,890 m⁻²。这里的下降描述同一压力阶跃下的水力离散，与三维动力更新后实际孔压的变化需分别判断。[逐壳数据](../figures/cryer_voronoi_flux_interior_r1.csv) · [压力制造场和耗散量](../logs/cryer_voronoi_flux_interior_r1.json)

原粒子的惯性质量、人工黏性和内外应力虚功继续采用已实测的主峰方案。控制体体积用于这项独立水力检查，机械体应变源仍用原几何弱式的体积积分。动力检查必须同时更新压力梯度项、加速度通量和每轮迭代的行系数，然后用相同的开排水时刻复核孔压、表面位移与角向波动。
