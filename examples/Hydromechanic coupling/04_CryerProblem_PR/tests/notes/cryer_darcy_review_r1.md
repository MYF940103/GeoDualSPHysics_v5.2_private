# Cryer 封闭 Darcy 离线结果：独立复核 r1

结论分为两层，不能合并成“已经找到真实外漏或 Cryer 根因”：

1. 当前接收点单边 `C_i` 的 Darcy 离散确实不具备原生体积加权的逐对抵消性质；独立直接求和复现了此前结果。
2. 同一 FrDraw 粒子体积对**精确连续 Laplacian**求积也已明显非零。因此，不能把当前积分率的全部数值当作实际外漏，更不能仅靠零净量就直接选用对称修正算子。

本轮仅新增本说明及 `../logs/cryer_darcy_review_r1.check.json`，没有修改旧脚本/JSON、生产源码、正式输入或根目录输出，没有运行 GenCase、求解器、积分、worker 或 Git。

## 源码映射与符号

当前实际 CPU 融合循环 `JSphCpu.cpp:2318` 取接收点 `CorrMat[p1]`。矩阵由 `:735–760` 的自由表面/追踪邻域计算，定义

\[
M_i=-\sum_j V^{op}_j\,d_{ij}\otimes g_{ij},\qquad C_i=M_i^{-1}.
\]

它不是 `SoilStressRateGradCorr` 开关控制的另一套 Darcy 矩阵。核为径向 Wendland，`g=f(r)d`，所以这里的 M 和 C 对称；本次直接重建的 M 最小特征值为 0.503711786，均非奇异。

生产 `JSphCpu.cpp:2462–2484` 和 GPU `JSphGpu_ker.cu:1814–1835` 对应

\[
H_{i,ij}=\frac{d_{ij}^{T}C_i g_{ij}}{r_{ij}^{2}+\eta^{2}},\quad
\dot p_i=D\sum_j V_j^{op}(p_i-p_j)H_{i,ij},\quad
D=\frac{2(K_w/n)k}{\rho_w g}>0.
\]

交换端点时 d 和 g **都反号**，因此 H 不反号，只是采用另一个接收点的 C；压力差另反号。用原生积分权重 w、实际算子体积 u 表示，一对的总贡献为

\[
D(p_i-p_j)\left(w_i u_jH_i-w_j u_iH_j\right).
\]

本初态均匀质量/密度下，`u=s_v w`，`s_v=1.000000033131594`，故上式为 `D*s_v*w_i*w_j*(pi-pj)*(Hi-Hj)`。单边 C 一般不能抵消；raw I 和共享的对称 C 给两端相同 H，因而在本状态严格抵消至求和舍入。原始负核因子与正定 C 使 H<0，所以高压端贡献为负、低压端为正，**单端扩散方向没有写反**，问题是两端幅值不必相等。

## 独立直接求和结果

重新核对源清单内 28 个不同文件 SHA/大小均匹配；读取了绑定的 Part0：37173 个土粒子、ID 8–37180、double 坐标、rho=2100、h=0.004499999806 m。

独立实现使用每个接收点的有向邻居表，逐点重建 M、逆矩阵和三种 Darcy 率，不复用原脚本的 `batches/correction/rate` 计算函数。三种场、三种算子、两组标量共 18 行的关键率指标全部复现，最大差为约 `2.24e-8 Pa/s`，相对于约 `3e7 Pa/s` 的局部率属于浮点求和顺序差。3,392,720 个无序对的独立配对公式也给相同积分。

下文数值统一使用 CPU 标量；这里的 CPU/GPU 仅指常数不同，不是实际程序后端对照。制造压力和核距离采用 double，并非生产 float 距离、邻居顺序的位级回放。

制造场 `p=P(1-r²/R²)²`，P=10000 Pa。当前 receiver-C 得

- `sum V pdot = +978.804408 Pa·m³/s`；
- 体积平均 `pdot = +1.68518775e6 Pa/s`；
- 净量/绝对量为 13.4641%；
- raw I、对称 C 的积分仅约 `1e-13 Pa·m³/s` 舍入量。

这证明了冻结图上的加权配对非守恒，**尚不等于真实外部流量**。恒压场各算子实际直接求和都为零；整体加 10000 Pa 后率差仅约 `3.4e-7 Pa/s`。当前二次压力泛函变化为负，说明该制造场的耗散与非零均值率可以同时存在；耗散、恒压零解、零点平移不变性、守恒是不同指标。

## 精确连续 Laplacian 在同一原生体积上的求积

四次场在 r=R 的径向导数为零，且

\[
\nabla^2p=-12P/R^2+20Pr^2/R^4,\qquad
\int_{\text{ideal sphere}}\nabla^2p\,dV=0.
\]

连续压力率系数是 `kappa=D/2`，不是 D；本 CPU 常数给 `kappa=0.679810764465 m²/s`。

但原生求积给出：

| 量 | FrDraw 原生布局 |
|---|---:|
| `sum V` / m³ | 0.0005808281043 |
| `V / Vsphere` | 1.109299967 |
| 加权 `<r²>/R²` | 0.6266031125（理想球为 0.6） |
| `sum V*exact_Laplacian` / Pa·m | +1236.146831 |
| `sum V*kappa*exact_Laplacian` / Pa·m³/s | +840.345922 |
| 精确率的原生体积平均 / Pa/s | +1.44680658e6 |
| 精确率净量/绝对量 | 11.1734% |

所以当前平均率与精确连续率**同一原生求积**的差为 `+2.38381176e5 Pa/s`，而不是把 `+1.68518775e6` 全部解释为实际外漏。两个归一净量各有不同绝对量分母，不能用 13.4641%−11.1734% 当作严格误差或因果分解。

更精确地，

\[
\sum V\nabla^2p=\frac{20P}{R^2}(\sum V)\left(\langle r^2/R^2\rangle_V-3/5\right).
\]

因此非零平均值来自径向二阶矩/边界节点完整体积权重的求积偏差，**不只是总粒子体积多 10.93% 这一个标量**。统一重标全部粒子质量或体积不会改变该加权径向均值，不能让非零平均率自动消失；本轮没有进行任何质量修正。

## 同 R/dp/h 的纯内存 Cartesian 对照

为区分全局求积偏差和单边配对性质，额外只在内存中构造 `x=dp*(i,j,k)`、`i²+j²+k²<=400` 的球，使用同 R、dp、h 及单粒子体积。没有 GenCase、FSType 设置或真实计算，这不是准备好可替代的物理输入。

| 量 | 原生 FrDraw | 内存 Cartesian |
|---|---:|---:|
| 粒子数 | 37173 | 33401 |
| V/Vsphere | 1.109300 | 0.996738 |
| `<r²>/R²` | 0.626603 | 0.598691 |
| 精确连续率的原生求积平均 / Pa/s | +1.44681e6 | −7.11704e4 |
| receiver-C 平均率 / Pa/s | +1.68519e6 | +2.31934e6 |
| receiver-C 净量/绝对量 | 13.4641% | 16.3314% |
| raw I / sym C 积分 | 舍入级零 | 舍入级零 |

在总量和径向二阶矩明显接近理想球的布局上，receiver-C 的正积分仍存在，且与精确求积均值方向相反。因此配对缺陷不能只归因于 FrDraw 总体积偏大。另一方面，这两种图的截断支持域和表面邻域不同，内存 Cartesian 也没有自动实现连续 Neumann 边界，不能据此宣布某个新粒子布局已经物理通过。

## 为什么现在不能直接选 sym C

对制造场的**局部率**与同点精确连续 Laplacian 之差进行 RMS 比较：

| 算子 | FrDraw / Pa/s | 内存 Cartesian / Pa/s |
|---|---:|---:|
| receiver-C | 2.46750e6 | 4.53787e6 |
| raw I | 4.65888e6 | 2.39581e6 |
| sym C | 3.37748e6 | 2.65820e6 |

当前 C 在原生布局的点态四次场近似反而最好；raw I 在内存 Cartesian 上最好。零净量并不保证局部精度、边界一致性、耦合能量或实际 Cryer 曲线更好，不能立即把对称 C 合入生产。

本诊断还让全部表面粒子参与率演化；实际 Cryer 排水路径会省略或强置某些排水节点，二者不是同一个动态试验。这里只确定了一个值得继续审查的离散性质，同时明确了原生求积偏差；没有确定其对实际排水孔压峰值/沉降误差的因果贡献，没有提出或实施新的生产算子，也没有物理验收。
