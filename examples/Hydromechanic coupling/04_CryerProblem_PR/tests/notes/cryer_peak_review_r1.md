# Cryer 峰窗复核：稳定完成，但峰值误差尚未解决

`cryer_grad_peak_r1` 在 RTX 3050 上正常完成 131072 步，实际终止时间严格为 0.0625 s，129 个原生保存帧、37173 个土粒子 ID 均已复核。求解约 4 小时 9 分钟，终态消息成功进入原会话一次，未重启旧监控。原始结果、根目录正式输入和生产源码均未改变。

配置为 dp=.0025 m、R=.05 m、k=1e-5 m/s、q=10 kPa、阻尼系数=.02、dt=2^-21 s，应力率梯度修正开启，原始围压力保留，SPR/HG/shifting 关闭；持久应力 double、孔压 float。

`logs/cryer_grad_peak_review_r1.check.json` 独立复核 605 个显式文件哈希和全部 129×95 项历史统计，原有限/弹性/无排除/真实排水/几何/机械及孔压步长检查均通过。新旧短窗只有 t=0 和 2^-11 s 两个共享保存时刻：34 个物理、身份和时间字段逐位相同；唯一另列项为输出区间统计 dterror_s，双方仍满足原守卫。不能称全短窗前缀逐位相同，也没有本峰窗独立半步或完整耗散验收。

## 定量结果

中心始终采用初始 r<=dp+1e-12 m 的固定 18 个材料粒子。连续理论按实际保存时间计算，连续峰由同一 360 根级数在本窗内一维寻优得到。

| 指标 | 当前峰窗 | 连续点中心理论 |
| --- | ---: | ---: |
| 晚段峰 p/q | 1.213075011 | 1.249023015 |
| 峰时 t/s | .04638671875 | .042250739 |
| 峰时 Tv | .050922455 | .046382054 |

当前峰幅低 359.480 Pa，即相对理论峰低 2.8781%；峰时晚约 4.136 ms，即 9.789%。预声明 Tv>=.005 区间的中心理论 RMSE 为 367.460 Pa。窗末 p/q=1.189147，峰后保存点已转为下降，故本窗确实覆盖了该离散晚峰，而不是峰仍在窗外。

旧根目录 Part49/50 使用同一组 18 个材料 ID 重采样后，Part50 为 p/q=1.215894732，实际 t=.04554741329226484 s。新峰比该旧参考低 28.197 Pa，没有明显峰幅改善。旧 root 与旧 dp0025 refinement 的这些 BI4 哈希相同，不是独立的两组控制。旧结果同时具有 float 应力、grad0 和约 2.97877 us 的实际步长；不能把新旧差异单独归因于应力写回或 grad1。

旧脚本的动态中心半径、默认 2dp 和名义时间会改变旧图的观测值；本轮表格使用原生实际时间与固定 ID，不把旧 CSV 名义时间当原生时间。

## 启动、传载与剩余线索

新长窗自身保存点的中心最大值是启动时的 1.229502q，但其 .48828125 ms 保存间隔不能解析全部快速启动振荡。保留的相同步长短窗在 .244140625 ms 另有 1.388363q 的中心采样值；图中独立标示这些更密的启动保存点，不将晚段峰与启动峰混用。原生初态 p=0，而准静态理论的 t→0+ 极限为 p/q=1，图中保留此差别，没有平滑或删掉早期数据。

晚峰时中心孔压 12130.750 Pa、有效平均压应力 -501.291 Pa、总平均压应力 11629.459 Pa。总压缩严格等于有效压缩加孔压。因此 p/q 不是外载传递比例，不能据孔压偏低就说外力未到中心。中心是内区的子集；19527 个内区与17646个外壳才构成全域分区。

另用连续准静态球对称线弹性关系进行一致性观察：

```
M=K+4G/3, M*eps_v=p+C
sigma_rr,total=C-4G*u/r
S_center=q+(4G/(3M))*(p_center-pbar)
```

在晚峰帧，使用当前 m/rho 体积权重得到 pbar=5258.123 Pa，该关系预测中心总压应力12618.144 Pa，实际低988.685 Pa。由表面位移、体平均孔压和中心应力反推的 C 分别为 -12747.949、-12918.078、-11320.972 Pa。该观察忽略惯性、阻尼并使用有限粒子体积求积，不是生产代码错误的证明，但值得优先核对空间力—应变离散的一致性。

本分析的瞬时阻尼 virial 以几何球体积归一为 -1.693601 Pa；按原生 sum(m/rho) 归一约 -1.52828 Pa。二者分母不同，不能混用；它们都不能单独排除历史阻尼效应。
