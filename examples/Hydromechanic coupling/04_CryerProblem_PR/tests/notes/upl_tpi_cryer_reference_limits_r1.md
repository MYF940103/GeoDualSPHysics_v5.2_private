本次只做离线参考计算，不读取BI4、不启动求解器、不修改已有正式图表。A是有限Kw=2e8 Pa，B/C是共同M0模型。沿已有审核过的`support/plot_cryer_formal_four_nu_r1.py`中`Reference`数学类，固定E=2e6 Pa、n=.3、k=1e-5 m/s、a=.05 m、固定18材料点半径r0=.0025 m与q0=10000 Pa。未拟合载荷、半径或峰时。

两种参考均用物理gamma=1000×9.80665 N/m³；legacy Tv继续用已有g=9.81标记。旧类的finite=False分支刻意复刻论文legacy时间尺度，所以新离线脚本只在其局部M0实例中令Cv=H*kappa并重建decay，不修改旧类或正式结果。有限Kw采用B=Mf/(K+Mf)、A=1+H/Mf；M0取B=A=1。统一物理gamma可以避免把0.034%的时间单位差误归因于积分算法。

峰值搜索固定为legacy Tv∈[.005,.5]，报告连续理论峰及实际tau（从既定排水开启时刻起计）。360与720模态在129个对数时刻的最大差必须小于1e-7 Pa。参考均为理想球体、小应变、准静态阶跃排水伴随解，不能精确表示有限ramp、加载带、动态惯性或演化J/n。t0理论均匀压力也不等于求解器从零重力/外载启动的初态。
