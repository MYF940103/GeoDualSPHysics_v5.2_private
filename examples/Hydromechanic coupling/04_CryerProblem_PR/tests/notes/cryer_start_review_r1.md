- 5个保存帧、37173土粒子ID，有限值、无粒子排除、零塑性、double保存位置/持久应力均通过。孔压/孔压率仍是float，不是全双精度耦合。
- 每帧5153个真实FSType2排水点孔压均严格为0，初始/本短窗分类未改变；算法仍是动态自由面追踪。
- 实际外载遥测存在；非零时刻径向分布外力描述/qA约1.09623–1.09638，仿射虚功比约1.06250–1.06290。它们不是单独证明表面traction误差的严格判据，更不能据此直接乘归一化矩阵。
- 全场最大孔压在0.00025s为19820.06Pa，0.001s为12299.01Pa；本轮未计算中心材料采样/解析误差，不能把全场峰值当作中心Cryer峰。
- 初始几何不含r≈0原生粒子，最小半径0.0025m、最大0.05m；native体积/理想球体仍为1.10930。今后“球心孔压”须定义固定初始材料球平均或插值。此项未证明几何或质量需要修正。

## 不能直接进入长程的原因

现有`JSphCpu::DtVariable`（GPU同样）在FixedDt分支绕过`min(dt,dtw)`。
真实float模型常数给出配置的渗流限值dtw=2.978769919e-6s；原5us为其1.678545倍。
保存的`dterror_s`检查的是固定步长相对机械候选，不含这个渗流限制。
因此本轮通过的是原设置的**启动/状态检查**，不是PoreDtSafety或物理精度验收。
这也尚未证明原5us不稳定或构成旧误差的根因；不能省略其他离散/启动影响。

下一项先在未改物理模型的CPU Release下，用2.5/1.25us做0.5ms启动对照，
保存相同实际时间的材料孔压、位移、应力、排水和载荷。两步均低于原dtw；
独立短对照完成后才决定覆盖Tv≈.06峰值的更长窗口，不自动启动完整Tv=1。
不把Lian静态平面SPR或二维弹性HG移植到本球面，也不合入已拒绝的load-only修正。
