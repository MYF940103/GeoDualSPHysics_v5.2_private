# 三维 Cryer 压力端点的自由表面几何与 GPU 耗时

每次端点压力轮都在力计算中根据该轮的粒子位置更新过自由表面几何。私有 GPU 版本在同一轮最终压力写回后，直接按这套几何施加原有排水条件。三轮各自重新计算力和所需几何。代码仅在三维、无周期、无实体壁面、使用自由球体路径时采用这项修改。生产程序和已发服务器包均沿用各自原版本。

## 耗时

同一台 RTX 3050 上，每次从相同初态推进 65 步并保存三帧，三对运行交替安排先后顺序。每对均核对了原生数组、材料 ID、时钟及压力与步长记录。计时运行关闭了几何读回检查。下表为求解循环实测秒数。

| 对照次序 | 原实现 | 同轮几何复用 | 加速比 |
|---|---:|---:|---:|
| 原实现先 | 37.9911 | 34.8259 | 1.091× |
| 复用先 | 37.4904 | 35.8977 | 1.044× |
| 原实现先 | 37.2076 | 35.2813 | 1.055× |

配对中位加速比 1.0546×，对应循环耗时下降 5.18%。这是本机相同输出条件下的短窗测量。服务器 A6000 全峰窗或其他算例上的收益需要各自的计时。[计时数据](../logs/cryer_endpoint_geom_r1_timing.check.json)

## 数值检查

显式两步、TPI 两步和 64 步均与原程序在相同保存时刻逐位比较。几何检查在一轮内读取重新计算前后的修正矩阵、自由面类别、法向和位置散度，每次覆盖 37,181 个粒子、3,420,652 字节。短窗同时核对全部 22 个保存数组、有符号步长诊断和 TPI 的九份方法记录。[64 步核对](../logs/cryer_endpoint_geom_r1_p3_64.check.json) · [私有 GPU 实现与复现入口](../support/cryer_p3_endpoint_geometry.py)
