# Cryer 球壳耦合频响

在原始粒子球的排水平衡态上施加单位幅值的小谐波围压，固定内壳 18 点（初始半径为球半径的 5%）的孔压幅值在 3 Hz 时比连续体解低 1.20%，在 10 Hz 时低约 2.3%。这一结果表明，时间连续的空间模型已经能产生百分量级的幅值偏差。真实 P3 峰窗的孔压峰值低 1.5177%，峰时滞后 2.4955%。这两个瞬态误差的具体成因和占比仍待确定。[频响图](../figures/cryer_coupled_shell_modes_r1.png) · [实际 P3 峰窗](cryer_p3_return_causal_r1.md)

## 从粒子图构造耦合矩阵

取保存的全部 37,173 个土粒子初始材料 ID、XYZ 和单粒体积，在 Wendland 半径 2H 内得到 3,392,720 对粒子；H=4.5 mm，dp=2.5 mm，外半径 50 mm。20 个壳层各保留一个径向位移，自由孔压有 19 项。最外壳的 5,153 点指定排水孔压零，仍参与邻居求和及骨架运动。材料体积之和与解析球体积之比为 1.10930，沿用原体积做内力和体积分，不重新缩放质量、核、球半径或外载。

- 对每一组壳位移，先在原三维粒子图上计算校正梯度、体应变和各粒子线弹性应力，再用原始核梯度的成对内力计算加速度。孔压和均匀围压沿用同一原始动量核。热力学符号约定为压缩外载 q>0、压缩有效应力为负。
- Darcy 项沿用两端对称一阶修正、原距离正则项及仿射场梯度补偿。动态渗流的加速度散度来自原三维加速度，包含力学阻尼项。完成这些运算后再作壳平均，保留了同一壳上不同点的算子输出差异。
- 水力方程为 `M dp/dt = −div(v) + k/γw [Lp − grad(p)·Lx + ρw div(a)]`。取实际水力传导系数 k=10⁻⁵ m/s、骨架 E=2 MPa、ν=0.30、混合密度 2100 kg/m³，线性力学阻尼率为 0.2478993 s⁻¹。连续解同时满足动量平衡、动态渗流、外表面零孔压、单位总径向压应力及球心正则性。[组装脚本](../support/cryer_coupled_shell_modes.py) · [降维矩阵](../figures/cryer_coupled_shell_modes_r1_blocks.npz)

## 校核及适用范围

仿射膨胀散度最大绝对差为 1.78×10⁻¹⁴。单位围压与均匀骨架应力的力残余相对值为 6.34×10⁻¹⁵，均匀孔压与围压相消的差为 6.16×10⁻¹⁶。仿射 Darcy 残余最大值 6.63×10⁻¹² m⁻¹。3 Hz M0 解的壳平均径向加速度残差最大 1.04×10⁻¹⁵ m/s²；同一组位移和孔压代回所有三维材料点，单位荷载引起的切向残余 RMS 为 5.08×10⁻⁴ (m/s²)/Pa，同壳径向散布 RMS 为 2.60×10⁻⁴ (m/s²)/Pa。空间对照同时包含外表面离散、体积积分、壳平均和被截去的非径向响应，尚无依据将其中一项单独判为峰值误差根因。[原矩阵校核](../logs/cryer_coupled_shell_modes_r1.check.json)

在完全相同的矩阵上，以连续频率与隐式梯形递推的离散频率作对照，dt=1.9073486328125 µs 时两者中心复传递差的绝对值在 2.0×10⁻¹² 至 8.1×10⁻¹⁰ 之间，减半步长约缩小四倍。此处检验的是指定频率、固定空间模型的时间误差。真实 P3 使用三轮孔压迭代、分阶段加速度、运动邻居和浮点写回，并从闭排水预载切换至开排水。此频响不提供真实 P3 时间误差、Mandel 峰值预测或全程准入。计算沿用平衡态线性化和固定排水外壳，未加入单向人工黏性与受压起停时的几何变化。

连续参考另用正则球 Bessel 函数的两个径向模态逐壳复核。160 组复压力与边值解的最大绝对差为 1.01×10⁻⁹ Pa/Pa，位移为 1.29×10⁻¹⁷ m/Pa。零储水、无阻尼极限另与准静态拉氏传递关系交叉校验，20 壳四频最大绝对差 9.16×10⁻¹⁶。在 10⁻⁵ Hz 对照排水静态位移及孔压的一阶频率斜率，相对最大差分别为 6.59×10⁻⁶ 与 9.02×10⁻⁶。[独立校核程序](../support/cryer_coupled_shell_reference.py) · [连续参考校核](../logs/cryer_coupled_shell_modes_r1.reference.json)
