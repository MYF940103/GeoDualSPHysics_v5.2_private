# C04 三维几何质量与黏性体积试验

2026-11-23 的 4,160 步三维弱式试验从零态开始，实际推进耗时 54.4 s。开闸后 64 步，几何质量将中心孔压从原弱式的 12,835.18 Pa 降至 10,448.01 Pa，同钟 M0 为 10,149.51 Pa。全体材料点的壳内角向 RMS 从 585.53 Pa 升至 592.22 Pa，服务器 P3 的同钟结果是 36.33 Pa。几何体积改善了径向压力，对角向误差和表面位移没有给出一致改善。本轮完成范围为升载、保持及开闸后 64 步。

## 计算与核对

每点质量取 2100 kg/m³ 乘相邻四面体体积的四分之一之和，压缩人工黏性对邻粒使用其几何双体积。总质量由 1.219739019 kg 变为 1.098318256 kg。研究 DLL 继续使用每单位质量阻尼 0.2478992641 s⁻¹、每步三轮弱式压力、原空间梯度和力积分、原表面牵引、固定支撑 H=0.0045 m 和 dt=2⁻¹⁹ s。弱式迭代的行系数按新质量产生的压力加速度响应重新计算。质量与黏性体积本次同时改变，数据只能给出二者的联合影响。

独立 CPU 参考对 3,392,720 对邻粒中的 1,655,519 个相向粒对累计作用力与反力，再逐 ID 除以各点质量。GPU 采用有向逐行求和。逐 ID 的黏性、压力、含阻尼总加速度最大绝对差分别为 1.11×10⁻¹⁵、7.35×10⁻¹³、3.64×10⁻¹² m/s²。平移和仿射膨胀的黏性均为零。CPU 参考的逐点功率与独立粒对功率均约为 −0.00125507 W。独立压力开闭样本轮、均匀封闭 10 kPa 和非均匀压力乘子检查的最大差均为 0 Pa。原闭态判据覆盖末四个保存时钟，压力误差 RMS 为 0 Pa，总压缩应力误差 RMS 最大为 2.28×10⁻¹² Pa，最大点速为 4.39×10⁻¹⁶ m/s。[逐点校验与输入哈希](../logs/cryer_weak_geovol_open_r1.check.json) · [运行记录与闭态门限](../outputs/cryer_weak_geovol_open_r1/completed.json)
