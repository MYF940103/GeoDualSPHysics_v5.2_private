# Cryer 三维压力与端点速度的跨步耦合

本记录使用三维点云的 37,173 个原材料点、原质量、真实 5,153 个排水点和固定参考四面体。研究步长为 1.9073486328125 µs。实际私有 GPU 从零预加载的最后读取状态为步 32，孔压范围 −53.519 至 +47.894 MPa，最大速度 16.828 m/s。步 38 的预测子首次报告无效更新，材料 ID 为 35303。相应实跑记录在 `tests/outputs/cryer_pair_open_r2`。下文为独立齐次线性化，不重放物理求解。人工粘性关闭；线性阻尼保留，忽略公开场写入时的浮点量化。

## 原因判别

令 $B$ 为成对力学的散度，$W$ 为节点几何体积对角阵，$M$ 为原材料节点质量，$P=M^{-1}B^TW$ 为单位孔压加速度，$S_0$ 为原 SPH 水力行的正分母，$\beta=\gamma_w/k$。三维 Rayleigh 计算给出 $S_0^{-1}BP$ 的最大值，闭态为 0.00057996146，开态为 0.00057472646。对应 $\beta\Delta t$ 放大为 1.0848006 和 1.0750087，水惯性 $\rho_w$ 的倍数为 0.57996 和 0.57473。单个速度反馈项达到 1 的步长为 1.75825 和 1.77426 µs；整个积分器稳定界须考虑另外的耦合项。

扰动包括三维速度、六应力、当前及上一步孔压。速度乘材料纵向阻抗，使其与压力按 Pa 度量。预测、校正和三轮压力全部按实际先后构造。固定几何使 $u_{n+1}=u_n+\Delta t(v_n+v_{n+1})/2$、$J_{n+1}=J_n+\Delta t Bv_h$（线性化）独立于输入位移及 $J$；后两者贡献被动单位特征块。原格式用 $g=(3p_n-p_{n-1})/2$ 计算 $v_e$ 和 $Bv_e$，三轮均固定这一散度，只在加速度中更新 $p$。实际全状态随机扰动 28 步的范数放大为下表数值。

| 线性化处理 | 闭态 | 开态 |
|---|---:|---:|
| 原三轮、原步长 | 19,321,673 | 7,811,232 |
| 仅去掉 $-\beta Bv_e$ 反馈 | 1.349 | 0.950 |
| 仅去掉压力对轮内端点加速度的反馈 | 2.905 | 1.058 |
| 原三轮、时间步减半 | 1.254 | 1.193 |
| 原空间水力行，孔压和端点速度同步，完整闭态行绝对值和预条件 | 1.071 | 1.052 |

原步长下占优的交替方向对应近似 Ritz 值 −2.0613/−2.0370，残差 0.0225/0.0060。这些估计只补充实际计算的扰动幅值。减步长的有限步结果也不能推广到全程。

## 弱通量同步三轮

对三维弱通量方案，$K$ 为一致线性四面体 Darcy 刚度，$H_j=WD_j$，$F=[H_x^T,H_y^T,H_z^T]$ 为试函数梯度的通量积分，$P_j=M^{-1}H_j^T$，$d$ 为线性阻尼。在预测出的端点应力不再变化时，设 $v(q)=\bar v+\Delta t Pq$，$a(q)=a_0+(1-d\Delta t)Pq$，其中 $a_0$ 含有效应力、规定牵引和 $-d\bar v$。三轮均使用该轮压力算速度、散度和加速度。端点孔压方程为

$$Lq=b,\quad L=K+\rho_w(1-d\Delta t)FP+\beta\Delta t WBP,\qquad b=-\rho_w F a_0-\beta WB\bar v.$$

令 $D_{ii}=\sum_j|L_{ij}|$，在完整未删行的闭态矩阵上计算一次。每轮执行 $q\gets q+D^{-1}(b-Lq)$。开启排水后每轮固定所有排水点为零。闭态设 $g_j=H_j^T\mathbf1$，每轮加一个全局同值 $-g^Tv(q)/(\Delta t g^TP\mathbf1)$ 以满足封闭体积分量。按最终 $q$ 提交速度。只用 $K$ 行和作分母的对照也列在 CSV。

制造场按独立的应力、孔压力、惯性和体积率重新计算物理残量，闭/开与组装结果的相对差为 $2.79\times10^{-16}/2.78\times10^{-16}$。制造压力固定点误差均小于 $4\times10^{-15}$ Pa。闭态压力偏置后全域净体积率为 $-4.76\times10^{-24}$ m³/s，同一随机输入不加偏置时为 $1.97\times10^{-10}$ m³/s。开态 32,020 个自由点上满足 $FP=-WBP$ 的最大单元素差为 $4.24\times10^{-22}$，实测 $L=K+870.470567WBP$ 的相对矩阵差为 $1.14\times10^{-16}$。该开态主子阵为正定，行和给出 $D^{-1}L$ 的谱上界 1。它约束固定机械基值时的压力迭代，不给整个跨步映射或闭态非对称矩阵一个总能量证明。

从同一随机扰动起算，弱通量同步三轮的 32 步范数相对初始为 1.0022/0.9985。再把原错时格式 28 步自激后的方向归一化，向三种格式传入完全相同的速度、应力和两层压力。结果为

| 相同自激方向 | 20 步闭/开 | 128 步闭/开 |
|---|---:|---:|
| 原错时 SPH 水力行 | 1,840,343 / 1,249,632 | 只计算 20 步 |
| 原 SPH 水力行与端点速度同步 | 0.00170 / 0.00104 | 0.000201 / 0.000205 |
| 三维弱通量与端点速度同步 | 0.00684 / 0.00880 | 0.001495 / 0.001882 |

原格式该方向逐步反号（第 20 步有符号余弦 −0.99997/−0.99992）。新弱式首步出现约 1.6% 的暂时放大，随后该扰动衰减。实际加载、有限精度、AV、开边首步的中心压力和后续峰值仍须用新的短窗单独检验。
