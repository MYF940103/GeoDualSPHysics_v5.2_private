本记录仅新增分析证据，不改旧清单、源码、正式输入或验收阈值；未运行物理求解器。独立只读计算使用已保存 Part0/95、现理论根函数及邻域查询；没有调用原静态脚本重写旧结果。

## 1. 静态场和力定义

拉应力为正，总应力 `T=S-pI`。令 `M=K+4G/3`、`H=4GP/(5M)`，制造场可独立化为

```text
T=[-q-H+2H r²/a²]I-H xxᵀ/a²,
p=P(1-r²/a²).
```

其散度为 `4Hx/a²-4Hx/a²=0`，球面 `Tn=-qn` 且 `p(a)=0`；P=0退化为均匀有效应力 `S=-qI`。位移应变/Hooke公式、原点光滑极限及迹关系正确。这是静态机械制造场，不是满足全部 Darcy 演化和初值的 Cryer 耦合解。

当前A的有效应力、外载、负孔压三项分别为

```text
Σj mj (Si/rhoi²+Sj/rhoj²) gij,
Σj mj q(1/rhoi²+1/rhoj²) gij,
-Σj mj (pi+pj)/(rhoi rhoj) gij.
```

与 CPU `JSphCpu.cpp` 2385–2402 和 GPU `JSphGpu_ker.cu` 1737–1753 的代数符号和密度权重对应。离线核为同一舍入 Wendland 常数的 double 计算，不是生产 float 算术/邻居顺序的0ULP复现。B只修正外载、C接收点一致扩展、D成对负伴随扩展均改变定义，不应冒称现生产方案或完整 Zhao 方法。

另以独立多项式 `Ttilde=T+qI` 直接对18个中心节点求和，不调用原 `pair_components`，P/q=1.2时 A/B/C/D 向量RMS为 `93.64047404518 / 169.02606276427 / 73.10808231432 / 77.97467338610 m/s²`，与原CSV一致。未发现此静态线索来自力符号或权重定义错误。

## 2. 固定中心18ID的有限半径理论

初始18个固定材料ID全在 `r=dp=.0025m=.05a`，并非真正r=0。以下只校正观测解释，不改既有理论曲线、检查或门限。

球对称线弹性平衡给出 `M eps_v=p+C(t)`。固定外部压力及球面牵引给出

```text
C(t)=-Mq/K+beta pbar(t), beta=4G/(3K),
pdot+beta pbardot=cv laplacian(p),
p(a,t)=0.
```

令 `s=r/a`、`sinc(z)=sin(z)/z`，模态 `p=A f(s) exp(-xi²Tv)` 满足

```text
f(s)=sinc(xi s)-sinc(xi),
(1-eta xi²/2)sin(xi)=xi cos(xi),
eta=M/(2G)=(1-nu)/(1-2nu).
```

因此现有中心系数 `cn=eta[sin(xi)-xi]/[eta xi cos(xi)/2+(eta-1)sin(xi)]` 乘以 `f(s)/[1-sinc(xi)]` 即有限半径压力。不是直接乘单个 sinc，否则球面排水条件错误。

独立储水投影复核：定义体积平均 `bar f=3∫0¹ f(s)s²ds` 和内积 `⟨f,g⟩B=3∫0¹ fg s²ds+beta bar f bar g`。初始内部 `p/q=1` 的系数为 `an=(1+beta)bar f/⟨f,f⟩B`；数值200点 Gauss 积分前12根所得 `an f(0)` 与现中心系数最大差 `6.8e-12`。根方程又给出 `bar f=3K sinc(xi)/(4G)`，与总储水约束一致。

nu=.3、360根、现Cv=0.0027444522857366896m²/s、a=.05m：

| 观测位置 | 理论峰p/q | 峰Tv | 峰时s |
| --- | ---: | ---: | ---: |
| r=0 | 1.2490230152022 | .04638205385 | .04225073805 |
| r=.05a | 1.2478532632993 | .04603753501 | .04193690600 |

有限半径使理论峰降低仅11.697519Pa。当前固定18ID峰为1.2130750108507、t=.04638671875s；与有限半径自身峰相比仍低347.782524Pa（2.787047%）、峰时滞后10.610732%。在当前数值峰实际Tv=.050922454520505，r0理论1.2468505240415，r=.05a理论1.2453375673554，相差15.129567Pa。有限半径不解释当前主要误差。

短时必须检查级数截断：360根在Tv=1e-6的r0尚未收敛；独立2048/4096根均给内部r/a=0/.05/.2/.8的p/q约1.001289738613，趋于初始1；球面始终0。长时由首根xi=2.670214733237主导，所有位置衰减至0，r=.05a/中心首模态比=.996423561015。没有把native初始p=0偷换成连续准静态初值1。

## 3. 阻尼virial的两种体积

Part95的37173节点，GPU公式按float系数和最终float cd复算：`f_d=-m cd v`，`-Σx·f_d/3=-.0008867673917692 Pa m³`。几何体积 `.0005235987755983m³` 得 `-1.6936009653Pa`；原生 `Σm/rho=.0005802389573578674m³` 得 `-1.5282796519Pa`。体积比1.1081747788559解释两数差异，无矛盾。该瞬时标量不能证明阻尼全程影响很小，也不替代惯性和边界误差分析。

## 4. 本轮布局分解的只读点评

`cryer_radial_layout_r1` 在同一P/q=1.2场把A分为零阶项与差分项。FrDraw中心A RMS=93.640474，零阶=94.032262，差分=.416309m/s²；表明这个静态中心残差主要关联初始核梯度分割和非零，而非必须经历时间演化才产生的粒子无序。各项存在向量抵消，不能把RMS比直接称为可相加误差百分比。

虚拟裁剪Cartesian中心A约5.71484e-13m/s²，但外壳18.469945大于FrDraw的6.799470，全域12.398895也大于9.704759。其节点数33401而非37173、中心7而非18、球面节点30而非5153、离散总体积也改变；局部改善并不证明整体动态精度必然提高或单独证明shifting有效。

不建议直接删去零阶项：差分形式会丢失共同应力的边界牵引，当前sigma=p=0初始状态也会丢失均匀q加载；一般还改变成对动量平衡。继续可控的边界/布局/一致性诊断，不能据此直接合入新算子、动态布局或particle shifting。
