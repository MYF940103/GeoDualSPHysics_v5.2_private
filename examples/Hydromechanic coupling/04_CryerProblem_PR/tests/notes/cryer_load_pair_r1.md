# Cryer：冻结邻居对与既有材料点历史检查

## 范围与位置

本阶段只读旧正式 `CaseCryerProblem_PR_out`。不启动求解器，不改变源码、正式 XML/BAT、几何、质量、排水、时间步或 Git。新增脚本为 `tests/support/cryer_load_pair_r1.py`，一次性结果为 `tests/logs/cryer_load_pair_r1.check.json`；拒绝覆盖同名记录。本阶段不生成图或 CSV，也不作物理验收。

使用保留的 Lian `tests/scripts/lian_release_r1.py` 和 `tests/outputs/hydro_native_r1/ReadHydroNative.exe` 解码原生 BI4。脚本绑定这两个跨 case 依赖、reader 源码、旧 Run.out/生成 XML、各读取 BI4、当前相关 CPU/GPU/核函数源码，以及 Zhao 2019 与 u-pw 原文 PDF/MD 的 SHA256；原始文件不改写。当前源码哈希不是旧程序运行时的程序身份证据。

## 原生历史

读取 Part0、1、10、50、100、200、500、1000，并记录真实时间与 Step、完整原生 ID 哈希。若这些帧不齐全，不默默换名义时刻。中心为初态 `r<=0.0025+1e-12 m` 的固定材料 ID 集合，不是每帧重新选球；不假定存在 r=0 粒子。壳层同样由初态半径确定。

记录孔压、有效/总应力平均压缩及径向/切向分量、材料位移、速度、密度、FSType2/3 排水值和真实外载。初始权重 `m/rho_initial` 用于固定材料统计。有效应力采用代码的拉应力正号，总应力为 `sigma_effective-pI`；不能将 `p/q` 称作承载比例，也不能要求瞬态总应力处处等于 `-qI`。旧初态/后续位置和应力数组的实际单双精度标志单独记录。原生数据中没有导出的内部力，不能仅凭这组历史判定动力平衡残差或唯一根因。

## 冻结初态球的四种离散数学对照

使用同一 Part0 保存坐标、Wendland 核和原生质量。分块处理邻居对，每批最多65536对，不形成全邻居对3x3张量。矩阵为 `M_i=-sum_j V_j d_ij outer gradW_ij`，`C_i=M_i^-1`。离线全 double 只重现其数学定义，不声称与 CPU/GPU float 核、位置、质量密度除法和邻居求和次序0ULP一致。

分别使用初态均匀密度，以及按固定 ID 附着到初态几何的 Part50 保存密度。后者是隔离密度分母影响的混合离线字段，不是真实耦合轨迹。

令 `g=grad_i W_ij`，下式为接收点 i 的每邻居加速度系数，最后乘 `m_j`：

- A：当前原始形式。有效应力 `(sigma_i/rho_i^2+sigma_j/rho_j^2)g`；外载 `q(1/rho_i^2+1/rho_j^2)g`；孔压 `-(p_i+p_j)/(rho_i rho_j)g`。
- B：保留 A 的有效应力和孔压，仅把全部外载改成 `C_i a_load_i`。
- C：三项统一使用接收点 `C_i g` 及公共分母，合式为 `(sigma_i+sigma_j+2qI-(p_i+p_j)I)/(rho_i rho_j) C_i g`。这是受 Zhao 接收点修正启发的耦合扩展，不是其干土论文完整复现。
- D：有效应力 `(sigma_i C_i+sigma_j C_j)/(rho_i rho_j)g`，外载 `q(C_i+C_j)/(rho_i rho_j)g`，孔压 `-(p_i C_i+p_j C_j)/(rho_i rho_j)g`。完整合式为 `[(sigma_i+(q-p_i)I)C_i+(sigma_j+(q-p_j)I)C_j]/(rho_i rho_j)g`。质量乘回后的力统一采用 `V_i V_j` 对称权重，是修正速度梯度的负离散伴随实验扩展，不是 Zhao 原单接收点形式。它的离散守恒/功属性不自动保证连续牵引、积分稳定或准确动力学。

每种定义均分别累加有效应力、外载和孔压数组，最后实际求和。没有把任何原始残差直接赋0。报告分量 RMS、粒子向量 RMS、向量最大值，避免混用。

制造场为：`sigma=-qI,p=0`；`sigma=-0.4qI,p=0.6q`；另一个显式非均匀对称应力及非恒定孔压场。第三场的边界应力不满足均匀 q，因此其净力、矩、仿射虚功只作代数描述，不是解析误差。不能仅靠括号恰为0的常总应力场证明一般守恒。

所有变体均记录净力、力矩、径向合量、一般3D仿射虚功及各独立外载的矩。几何球体积与原生 `sum(m/rho)` 下的功归一化分别标明；D 的离散功恒等式应使用原生体积，不将其强制对齐几何球体积。体积加权内核区加速度范数比例不是实际表面牵引或承载比例，不做力归一化。

另用含非零 XYZ、剪切、旋转及散度的线性速度场检查原始/修正梯度闭合。自检包括 `C=I` 等密度下四定义退化、独立两点三项算术与 D 的换端反对称。自检通过只表示离线实现按定义执行，不表示 Cryer 或替代模型物理验收。
