# Cryer ν=0.30 三轮压力修正的本机验证

本记录针对三维球体、常渗透系数和三轮端点压力更新的私有程序。在没有显式选择 B 时，保留 A 的有限水体积模量积分。B 使用 M0 方程、α=0.5、β=0 和 Eq.40 的 Rh=1 限步。每个力学步依次计算预测、校正和三个压力端点，材料、体积比 J 及压力历史各推进一次。

## 输入与数值检查

本地沿用 `upl_cryer_freebody_short_r1_seed` 的球体，37,173 个土粒子和 8 个固定标记。服务器种子和本地种子的初始 BI4 全部字节相同。两者使用相同的材料、几何、边界和加载配置，独立输出计划记录实际保存时刻。本地 B 的 XML 仅把 `DtIni` 和 `DtFixed` 从 2⁻²⁰ s 改为 2⁻¹⁹ s。用 `-nsteps` 限定 2、64 或 4,097 步。0.00390625 s 加载完成，0.0078125 s 为排水事件。第 4,096 步保存状态仍属开启前，第 4,097 步为第一个应检查真实 FS2/3 零孔压的保存状态。

`tests/support/cryer_p3_short_run_r1.py` 运行一项指定的 GPU 短测。`cryer_p3_verify_r1.py` 读取每个真实 BI4，按材料 ID 对齐，检查全体 22 个原生数组、配置、时钟、带符号的时步误差、体积和质量关系、压力、应力、排水、半径及固定点。`cryer_p3_sidecar_review_r1.py` 检查三轮写回和五相必要时间步。跨 CPU/GPU 仍用同一时刻压力 RMS ≤5 Pa、材料位移差最大值 ≤0.005 mm。A 的同后端原生回归同时比较全部 22 个数组和带符号的时步误差字节。

## 服务器数据回传后

峰窗到 0.0703125 s，含排水前 64 个时间间隔和排水后的 0.0625 s。用实际保存时钟 τ=t−tD 及固定初始半径 r/a=0.05 的 18 个粒子。有限 Kw 的连续参照峰值为 12,439.17596 Pa，M0 为 12,478.53263 Pa。压力和峰时分别对各自的参照计算。从 legacy Tv≥0.005 开始统计 Mandel 峰，同时保存和绘制全部启动记录。下列命令示例从 case 根目录运行，最后一个参数是新的分析目录。

```powershell
python -B tests/support/cryer_p3_return_r1.py "CaseCryer_TPI_P3_nu030_peak_r1_GPU_out" "support/CaseCryer_TPI_P3_nu030_peak_r1_schedule.csv" "tests/figures/cryer_p3_returned_peak_r1"
```

输出包括原生曲线和同时刻解析值 CSV、带离散模拟点的对数 Tv 图、从施载开始的线性时间图以及峰位和峰高指标。服务器峰窗还需复核完整求解状态及真实三轮、五相记录。峰幅相对理论差控制在 1% 以内，误差相对可比 A 增幅不超过 0.10 个百分点，峰时差限值取理论峰时的 2% 与半个采样间隔中较大者。全程使用排水后的 ΔTv=0.005，由双击另一 BAT 从原初态独立计算。图表须注明球体离散、动态启动与准静态参照的差别。新程序相对于 A 的总耗时由实际设备和回传数据确定。

## 2026-11-19 本地结果

默认 A 在两个同时间保存态的材料 ID、22 个原生数组及带符号的时间步诊断逐字节一致。B 的 Debug 两步显存检查报告 0 错误。在 B64 的实际末态，CPU 与 GPU 的土粒子压力 RMS 差为 0.000019431 Pa，材料位移差最大值为 4.04×10⁻¹² mm。RTX 3050 上模拟同一物理时长时，A128 和 B64 的循环分别用时 31.81 s 和 50.95 s。B64 写出全体材料的三轮记录，较长的窗口仅导出 18 个中心点的逐轮明细。

独立 B4097 保留了 66 帧，循环用时 2,228.13 s。每步五相均满足必要时间步限制，最紧限制为 2.978756 µs。排水开启前，B 的中心孔压、土体平均孔压和平均总压应力为 10,001.53、9,999.45 和 10,001.33 Pa，对应的有限 Kw 对照为 9,976.69、9,975.92 和 10,000.85 Pa。两个方案在这一时刻的壳层向内位移分别为 0.01631 µm 和 0.23225 µm。

第 4,097 步距开排水 1.90735 µs，5,153 个实际 FS2/3 土粒子孔压都为零。其余 32,020 个粒子均压降至 8,499.15 Pa，中心仍为 10,002.33 Pa。三轮内相邻两次修正的全体最大变化由第 4,096 步的 0.295 和 0.291 Pa 升至第 4,097 步的 1,614.25 和 1,138.69 Pa。有限 Kw 对照首次排水后存盘在 122.07 µs，应分别报告两个保存时刻。将开闸瞬态与后续 Mandel 峰分别评估。见 [原生对比图](../figures/cryer_p3_drain_AB_r1.png) 和 [同时刻数据](../figures/cryer_p3_drain_AB_r1.csv)。

对同一批材料 ID 比较第 4,096 和 4,097 步，未强制排水的 32,020 点平均降压 1,500.54 Pa。按初始材料半径分层，0.8 < r₀/a ≤ 0.9 的 7,905 点平均下降 2,426.55 Pa，最外层未强制排水的 4,588 点平均下降 6,090.10 Pa。0 ≤ r₀/a ≤ 0.6 的各层均压只变化约 1–2 Pa。这确定了首步压降的空间位置，后续峰窗需要检查它是否影响峰高和相位。[分层孔压图](../figures/cryer_p3_radial_local_r1.png) · [分层数据](../figures/cryer_p3_radial_local_r1.csv)
