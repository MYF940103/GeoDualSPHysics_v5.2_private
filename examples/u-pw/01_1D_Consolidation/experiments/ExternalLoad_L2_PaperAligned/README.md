# ExternalLoad L2 Paper-Aligned 1D Consolidation

This experiment extends the L1 native `AccInput` external-load smoke toward the
u-pw paper-style 1D Terzaghi consolidation setup.

## Scope

- Geometry: `H=1.0 m`, `width=0.1 m`, `Dp=0.01 m`.
- Skeleton: linear elastic, `E=2e6 Pa`, `nu=0.3`.
- Hydraulic constants: `Kw=2e8 Pa`, `n=0.3`, `k=1e-3 m/s`.
- Drainage: top drained after the load ramp, bottom no-flux layer correction,
  periodic/laterally constrained 1D column.
- Load route: native DualSPHysics `AccInput` on the top `mkfluid=1` material
  layer. The target surcharge is `q0=-10 kPa`, mapped as
  `a_z=q0/(rho0*Dp)=-476.190476 m/s^2`.

This is still a reduced external-load route because the top load is a body
acceleration on a material layer, not a true traction plate.
