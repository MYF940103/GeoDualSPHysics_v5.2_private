# M3b MCC Parser/State Init

CPU-only parse/init smoke cases for `SoilConstitutiveModel=3`.

M3b intentionally does not connect the MCC return mapping into the SPH stress
update. The solver parses MCC parameters, initializes CPU state arrays, and
writes `SaveMccState` output fields while the model-3 stress branch remains
elastic-trial pass-through.

Cases:

- `CaseM3b_MccPc0_Init`: direct `MccInitialPreconsolidationPressure=200 Pa`.
- `CaseM3b_MccOCR_InitialStress`: `InitialEffectiveStressIso=50 Pa` and
  `MccOCR=4`, giving initial `pc=200 Pa`.

Retained CSV:

- `m3b_case_summary.csv`;
- `m3b_mcc_state_initialization_metrics.csv`.

Heavy solver outputs are regenerated by the BAT files and are not retained.
